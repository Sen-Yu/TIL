# LLM Optimization
- 학습이 끝난 LLM을 제한된 리소스에서 사용토록 개선하는 과정입니다.
- 리소스: (모델 크기, 추론속도, 메모리 사용량)
- 기법: 압축, 경량화, 재학습 

## 데이터타입
### FP32,FP16
- 실수를 비트에따라 부호,지수,가수로 나누어 표현한 부동소수점 데이터타입

### INT8,INT4
- 정수를 비트에따라 표현한 정수 데이터타입
### Mixed Precision Training
- 학습 중 연산은 16비트, 가중치 누적과 업데이트는 32비토로 섞어서 학습하는 방식

## Quantization(양자화)
- 높은 비트를 가진 부동소수점 데이터타입을 낮은 비트를 가진 정수 데이터 타입 표현으로 변환하는 경량화 기법
- 단계
	-> 1. 목적 확인: 메모리 절감, 추론 비용 절감, 추론 속도 개선,etc 
	-> 2. 변환 대상 선택: weigh, activation,KV Cache,etc
	-> 3. 정밀도 결정: INT8, INT4, W8A8, W4A16
	-> 4. 매핑 방식 선택: 대칭(Symmetric), 비대칭(Affine)
	-> 5. 적용 시점 결정: PTQ, QAT
	-> 6. 도구 적용: bitsandbytes, GPTQ, AWQ, llama.cpp
	-> 7. 성능 평가: 양자화 전후 정확도, 응답 품질, 메모리 사용량, 추론 속도 비교
	-> 8. 배포 또는 재조정: 손실 허용 범위에 따라 결정

### Affine Quantization
- Scale factor(축소 비율)와 Zero-point(영점 이동)을 사용해서 양자화하는 방식
- 사용이유:
- 구성
	- Affine: 부동소수점 범위를 정수 범위에 대응(선형변환에 평행 이동이 더해진 변환)
	- Scale factor: 부동소수점 값의 간격을 정수 한칸 비율에 맞춤(축소비율)
	- Zero-point: 부동소수점 0이 정수 범위의 어느 값에 대응되는지(영점이동) 

$$
y = ax + b
$$

$$
q = clamp(round(x / scale) + zeropoint, q_{min}, q_{max})
$$

| 기호 | 이름 | 의미 |
|------|------|------|
| `x` | 원본 값 (real value) | 양자화 이전의 실수(float) 값. 예: FP32 가중치 또는 activation 값 |
| `scale` | 스케일 팩터 | 실수 값의 범위를 정수 범위로 매핑하기 위한 비율. `scale = (x_max - x_min) / (q_max - q_min)` 로 계산되는 경우가 일반적 |
| `zero_point` | 제로 포인트 | 실수 값 `0`이 정수 도메인에서 어디에 매핑되는지를 나타내는 오프셋(offset) 값. Asymmetric(비대칭) 양자화에서 필요하며, Symmetric(대칭) 양자화에서는 보통 0 |
| `round(·)` | 반올림 함수 | `x / scale` 계산 결과(실수)를 가장 가까운 정수로 반올림 |
| `+ zero_point` | 오프셋 적용 | 반올림된 정수 값에 zero_point를 더해 실제 정수 그리드 상의 위치로 이동 |
| `clamp(·, q_min, q_max)` | 클램핑 함수 | 계산된 값이 표현 가능한 정수 범위를 벗어나지 않도록 `q_min`과 `q_max` 사이로 값을 잘라냄(saturate) |
| `q_min` | 양자화 최소값 | 정수 표현의 하한. 예: INT8 unsigned면 `0`, signed면 `-128` |
| `q_max` | 양자화 최대값 | 정수 표현의 상한. 예: INT8 unsigned면 `255`, signed면 `127` |
| `q` | 양자화된 값 (quantized value) | 최종적으로 저장/연산에 사용되는 정수 값 |

- 역양자화
	
$$
x_{approx} = (q - zeropoint) * scale
$$

$$
scale = (x_{max} - x_{min}) / (q_{max} - q_{min})
$$

$$
zero_point = round(q_{min} - x_{min} / scale)
$$

### Weight Quantization
- 가중치 + 활성화 값 양자화
- 사용이유: 저장 크기와 메모리 사용량 감소
- 종류
  - Per-tensor: 텐서 전체에 하나 scale
  - Per-channel: 출력 채널마다 별도 scale
  - Per-group: 채널보다 더 작은 수의 각 그룹마다 scale

### Activation Quantization
- 모델 추론 수행 과정의 활성화값(중간 출력 텐서)을 양자화
- 사용이유: 연산 가속 및 메모리 절감
- 방식
  - 대표데이터를 미리 넣고
- 추론시점에 입력별로

### KV Cache Quantization
- 매번 갱신되는 Query를 제외하고 재사용되는 Key, Value를 양자화
- 사용이유: GPU 연산 메모리를 감소
- 의문점: 양자화로 인한 Attention 정확도 감소하지 않는가?
	- 정확도 감소가 있지만 그 정도가 비교적 작은편, 결과가 크게 흔들리지 않음 	 


### Post-Training Quantization (PTQ)
- **학습이 끝난 시점**에 모델에 대표 데이터(캘리브레이션)를 입력 후, 값 분포를 측정하는 양자화
- 사용이유: 재학습 없이 메모리와 추론 비용 감소, 빠른 배포 가능

### Static Quantization, Dynamic Quantization
- static : **추론전**에 대표 데이터(캘리브레이션)로 미리 양자화하는 방식
	- 사용이유: 추론지연 시간 감소, 정수 연산 가속
- dynamic: **추론시점**에 입력데이터 분포를 보고 즉석으로 양자화하는 방식
	- 사용이유: 사전데이터 불필요, 입력일정하지 않은 환경에서 안정적
 - 
### 캘리브레이션
- 양자화 전 위해 활성화 값의 분포 및 범위를 측정하는 과정


### Quantization-Aware Training (QAT)
- 학습과정에서 양자화 오차를 같이 학습 
- Fake Quantization(가짜 양자화) 노드(INT 연산X)를 삽입


## 한줄정리
LLM 최적화는 학습이 끝난 LLM을 제한된 리소스에서 사용토록 개선하는 과정입니다.
양자화는 높은 비트 수를 가진 부동소수점 데이터를 낮은 비트 수를 가진 정수 데이터 타입으로 변환하는 경량화 기법입니다. Affine 양자화는 축소비율과 영점 이동을 사용해서 양자화합니다. Weight 양자화는 텐서마다, 그룹마다, 채널마다 가중치를 양자화합니다. KV 캐시 양자화는 매번 갱시뇌는 쿼리를 제외하고 연산마다 재사용되는 키와 밸류를 양자화해서 GPU 연산 메모리를 감소시키는 방식입니다. PTQ는 학습끝난 모델에 대표데이터를 입력해서 활성화함수등의 값 분포를 확인하는 양자화입니다. PTQ에서  대표데이터입니다.
