## 1. 시계열 데이터(Time Series Data) 
- 시간의 흐름에 따른 연속적인 데이터
- 시각(점,순간) vs 시간(선분,간격,구간)
- 사용이유: 미래예측, 불확실성 감소를 위해서
- 예제)
~~~
import seaborn as sns
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# 난수 생성 시드 고정
np.random.seed(42)
# 2023-01-01부터 100일간 날짜 생성
date_range = pd.date_range(start="2023-01-01", periods=100, freq="D")
# 평균이 0이고 표준편차가 1인 정규분포 난수 100개 생성, cumsum()은 배열 누적합 계산:배열의 각 요소를 앞에서부터 차례대로 더한 값을 새로운 배열로 반환
data = np.cumsum(np.random.randn(100))

df = pd.DataFrame({"Date": date_range, "Value": data})

# 그래프 크기 설정
plt.figure(figsize=(10,5))
# 시계열 선 그래프(색상, 마커 모양 설정)
sns.lineplot(x="Date", y="Value", data=df, color="blue", marker="o") 
plt.xlabel("Date")  # X축 라벨 설정
plt.ylabel("Value")  # Y축 라벨 설정
plt.title("Time Series Line Plot")
# X축 눈금 45도 회전(레이블이 길거나 간격이 좁을때 서로 겹치는 경우를 해결)
plt.xticks(rotation=45)

plt.show() 
~~~

## 2. 리샘플링(Resampling)
- 시계열 데이터에서 시간 간격을 다운샘플링(축소) 또는 업샘플링(확대)하는 과정
- 사용 이유: 불규칙한 시계열 데이터를 일정한 간격으로 정히하여 패턴과 트렌드 파악
- 문법형식    
  `df.resmaple(시간_간격).집계함수()`
  - 시간_간격: 변환할 시간 단위("d","h")
  - 집계함수: 다운샘플링 적용할 함수(`mean()`,`sum()`,`min()`,`max()`)

### 2.1. 다운샘플링(Downsampling)
- 더 긴 시간 간격으로 집계
    
### 2.2. 업샘플링(Upsampling)
- 더 짧은 시간 간격으로 데이터를 확장 -> 없는 데이터를 어떻게 생성???
- 데이터 생성 방법
#### 2.2.1 보간(Interpolation): 가진 데이터를 가지고 내부를 채움

#### 2.2.2 추정,추론,추측(Extrapolation): 기존 패턴을 기반으로 추정해서 데이터 채움

## 3. 이동평균(Moving Average)
- 시계열 데이터의 일정구간(Window:윈도우) 평균값(시간에 따라 평균값이 변화함)
- 사용이유: 데이터의 변동성을 줄이고, 장기적 패턴과 트렌드 분석을 위하여
### 3.1. 단순 이동평균(SMA, Simple Moving Average)
- 심플하지만, 최근 데이터 변화를 빠르게 반영못 할 가능성 존재    
  `df["SMA"] = df["value"].rolling(window=윈도우_크기).mean()`
  - `window`: 윈도우 크기
  - `.mean()`: 윈도우 내 데이터의 평균을 계산함수
 
### 3.2. 지수 이동평균 (EMA, Exponential Moving Average)
- 최근 데이터에 더 높은 가중치 부여(변화에 민감함)     
  `df["EMA"] = df["value"].ewm(span=윈도우_크기, adjust=False).mean()`
  - `span`: 지수 가중치의 윈도우 크기(값큼 = 변동성 줄어듬)
  - `adjust`: False는 새로운 값에 더 높은 가중치 부여
  - `.mean()`: 윈도우 내 데이터의 평균을 계산함수
### 3.3. 가중 이동평균 (WMA, Weighted Moving Average)
-ㄴㅇ 
~~~
weights = np.arange(1, 윈도우_크기 + 1)  # 가중치 배열 생성
df["WMA"] = df["value"].rolling(window=윈도우_크기).apply(lambda x: np.dot(x, weights) / weights.sum(), raw=True)
~~~
