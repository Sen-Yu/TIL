# 머신러닝

## Data Processing(데이터 전처리)
- 원본 데이터를 분석 및 모델합습을 위해 정제 및 변환하는 과정
  - 종류
    - 결측값 처리: NAN값 대체
    - 이상치 제거: 비정상적 값 제거
    - 데이터 정규화: 일정 범위(0<=x<=1)로 변환하는 과정
    - 데이터 변환: 로그 변환, 원-핫 인코딩
    - 데이터 분할: 학습과 검증으로 분리
  - 원-핫 인코딩
    - 범주형 데이터를 이진 벡터로 변환하는 기법(범주형 데이터 -> 수치형 데이터)


## Data Augmentation(데이터 증강)
- 원본 데이터를 변형하여 새로운 데이터를 생성하는 기법
  - 종류
      - 이미지 회전
        - `image.rotate(angle)` : 반시계 방향으로 angle만큼 회전
      - 이미지 크기 조절
        - `resize(width, height)` : width, height로 재조정 
      - 이미지 뒤집기
        - `ImageOps.mirror(img)`: 좌우 대칭
        - `ImageOps.flip(img)`: 상하 대칭
      - 이미지 이동
        - `np.roll(array, shift, axis)`: array를 axis 기준으로 shift 만큼 이동한다.    
      - 색상 변형: 명도,채도 조절
      - 노이즈 추가
      - 역번역
      - 속도변화
   
## Dataset Split (데이터셋 분할)
- 데이터셋을 학습(train), 테스트(test),(필요시)검증(validation)으로 분할하여 모델 성능을 평가하고 일반화 하기 위한 과정
- 사용이유: 과적합 방지, 성능 평가, 일반화 확인, 하이퍼 파라미터 튜닝, 비교 연구
- 예제코드
~~~
# 데이터셋 분리 모듈 임포트
from sklearn.model_selection import train_test_split

# 데이터셋을 학습, 검증, 테스트 세트로 랜덤 분할 (60:20:20 비율)
# 먼저 학습 데이터 분할
train_data, temp_data = train_test_split(df, test_size=0.4, random_state=42)
# 남은 데이터에서 검증 및 테스트 데이터 분할
validation_data, test_data = train_test_split(temp_data, test_size=0.5, random_state=42)  

# 각 데이터셋 크기 확인
print("학습 데이터셋 크기:", len(train_data))
print("검증 데이터셋 크기:", len(validation_data))
print("테스트 데이터셋 크기:", len(test_data))
~~~
