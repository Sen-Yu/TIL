## 1. SciPy 
- 과학 계산과 통계 분석을 위한 고급 수학 함수와 알고리즘을 제공하는 라이브러리

- 사용 이유: Numpy기반 연산과 보다 좋은 고급 기능 제공 
- 모듈
  ~~~
  import numpy as np

  import scipy

  form scipy import optimize ## 최적화 모듈
  from scipy import stats ## 통계 모듈
  from scipy import signal ## 신호 처리 모듈
  form scipy import interpolate ## 보간법 모듈
  form scipy import intergrate ## 적분 및 미분 방정식 모듈
  from scipy import linalg ## 선형대수 모듈
  ~~~
