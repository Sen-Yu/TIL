## 2. 정규 분포(Normal Distribution)
- 데이터가 **평균을 중심으로 좌우 대칭인 종모향 곡선 확률분포**
- **확률분포**: 어떤 확률 변수가 **취할 수 있는 모든 값과 그 값의 발생확률을 나타내는 함수**  
    예) 주사위 1/6 확률
- **정규 분포의 확률 밀도 함수(PDF: Probability Density Function)** 
  -  **연속형 확률 분포에서 특정 구간에 값이 나타날 가능성을 설명하는 함수**
  -  PDF 값이 큼 -> 해당 구간에 데이터가 많이 분포할 확률이 높음
  -  전체 면적: 항상 1
  -  확률(%): 특정구간의 아레 면적을 적분한 값이 해당 구역의 확률
      - 특정 지점이 확률(%)을 의미하는 것은 아님!
     - $`a <= x <= b $`$ 의 확률 = $`\int_{a}^{b} f(x) dx`$
        
  - 수학적 표현식
     
       $$f(x) = (1 / (σ * sqrt(2 * π))) * exp(- (x - μ)² / (2 * σ²))$$      
  
  | 구분 |	설명 |
  |-----|-----|
  | μ(mu) = 평균(Mean) | 데이터의 중심 위치를 결정(0이면 분포의 중심이 0) |
  | σ(sigma) = 표준 편차(Standard Deviation) | 데이터가 퍼져 있는 정도를 결정 |
  | π(pi) |	약 3.14159 |
  | exp() | 자연로그의 밑 e를 지수로 하는 함수 |
- 시각화 예제 코드
  ~~~
  import numpy as np  
  import scipy.stats as stats  # SciPy의 통계 모듈
  import matplotlib.pyplot as plt  
  import seaborn as sns  

  ## 난수를 이용한 정규분포 데이터 생성
  # 난수 생성 시드 값 설정
  np.random.seed(42)  
  # ( 평균(loc)= 50, 표준 편차(scale)= 10, 정규 분포 난수의 수(size) = 1000 )를 생성
  data = np.random.normal(loc=50, scale=10, size=1000) 
  # 생성된 데이터 배열의 상위 5개 값을 출력
  print(data[:5])

  ## 그래프 생성  
  # 그래프 크기 가로 8인치, 세로 5인치 설정
  plt.figure(figsize = (8,5))
  sns.histplot(data, bins=30, kde=True, color="skyblue", alpha=0.7)
  plt.title("Normal Distribution")
  plt.xlabel("Value")
  plt.ylabel("Frequency")
  plt.show()

  ## 상위 5개 값 출력 결과: [54.96714153 48.61735699 56.47688538 65.23029856 47.65846625]

## 3. 기술 통계(Descriptive Statistics)
- **지표를 계산하고 시각적으로 표현하는 분석 기법**(데이터를 설명 및 요약)
- 사용이유: 복잡한 데이터를 정리해서 쉽게 이해하기 위해서

- 핵심지표  
  | 종류 | 구분 |	설명 |    
  |--------|-----|-----|    
  |중앙 경향성<br>(Central Tendency)|평균(Mean) |	데이터 값의 합을 데이터 수로 나눈 값 |   
  ||중앙값(Median) |	데이터를 정렬했을 때 가운데 값 <br>이상값(Outlier)의 영향을 덜 받는 정도|  
  ||최빈값(Mode) |	데이터에서 가장 빈도수가 높은 값 <br>자료의 대표적인 값 |
  |--------|-----|-----| 
  |산포도<br>(Dispersion)|범위(Range) |	최댓값과 최솟값의 차이를 통해 자료가 흩어진 정도 |  
  ||분산(Variance) |	데이터 값들이 평균에서 얼마나 떨어져 있는지 표현한 값<br>값이 클수록 변동성 큼 |  
  ||표준 편차(Standard Deviation) |	분산의 제곱근 값<br> 데이터의 평균적 변동성을 직관적으로 파악 |  
  ||사분위 범위(IQR)	| 1사분위수(Q1)와 3사분위수(Q3)의 차이 값<br> 데이터 중간 영역의 흩어진 정도 |  
  |--------|-----|-----| 
  |분포 특성<br>(Distribution Characteristics)|왜도(Skewness) |	분포의 비대칭성을 나타내는 값<br>- 0보다 크면 오른쪽으로 치우친 분포(양의 왜도)<br>- 0보다 작으면 왼쪽으로 치우친 분포(음의 왜도) |  
  ||첨도(Kurtosis) |	분포가 뾰족한 정도를 나타낸 값<br>- 3보다 크면 정규 분포보다 뾰족한 분포(급첨)<br>- 3보다 작으면 평평한 분포(완만) |

## 4. 가설 검정(Hypothesis Testing)
- 표본을 기반으로 통계적 가설의 참과 거짓을 검정하여 결론을 도출하는 과정    
    **{ (표본) -> (가설) -> (검정) -> (결론) } 과정**
  
- 사용이유: 결과(보이는 차이)가 우연이 아닌 통계적으로 유의미한 결과(차이)인지 검증하기 위해서

- 핵심 개념
  - 귀무가설($`H_0`$): 참이라고 가정하는 가설(연구자가 반증하는 대상)
  - 대립가설($`H_1`$): 연구자가 검정하는 가설(귀무가설과 반대되는 주장)
  - 1종 오류(Type 1 Error): 귀무가설이 실제로 참이지만, 귀무가설을 기각하는 오류
  - 2종 오류(Type 2 Error): 대립가설이 실제로 참이만, 귀무가설을 기각하지 않는 오류
    
- 일반적인 절차
  1) 가설 설정: 귀무가설과 대립가설을 명확히 정의
  2) 유의수준($`a`$)결정: 가설 기각 기준 설정(default=0.05 => 5%)   
  3) 검정 통계량 계산: 적적한 검정 방법 선택 및 검정 통계량 계산
  4) p값 계산 및 해석: 검정 통계랑으로 p값 계산 및 해석(p값을 유의 수준과 비교해서 기각 결정)
  5) 결론 도출: 가설 검정 결과를 해석하고 최종 결론
  
- 가설 검정(Hypothesis Testing) vs 가설 검증(Hypothesis Verification)
  | \ | 가설 검정<br>(Hypothesis Testing) | 가설 검증<br>(Hypothesis Verification) |
  |----|----|----|
  |의미|**가설의 참,거짓 여부를 판단하는 과정**|**가설의 참,거짓를 입증하는 과정**|
  |공통주제|"신약이 구약보다 약효가 15% 상승했다!"|---|
  |가설|"이 15%라는 상승 수치가 우연히(오차 때문에) 나온 것인가, 아니면 진짜 약효가 있어서 나온 것인가?"<br> 귀무가설: "신약과 구약의 효과는 차이가 없다."<br>(15% 상승은 단순한 실험 오차나 우연) <br>대립가설: "신약의 약효가 구약보다 15% 상승했다."|"신약이 구약보다 약효가 15% 상승했다!"<br>-> "실제 임상 현장이나 현실 세계에서 정말로 똑같이 재현되고 입증되는가?"|
  |과정|환자 표본 데이터를 통계적 수식(t-test 등)계산<br>우연히 15% 차이가 날 확률(p-value)을 계산|종합적인 사실(Fact)을 추적<br>신약 개발 프로세스 전반에서 명제가 무너지지 않고 끝까지 참으로 증명되는지 모니터링|
  |결론|"신약의 약효가 15% 상승했다는 통계적 유의성이 인정된다"|"이 가설은 현실에서 타당한 사실로 검증되었다"|
