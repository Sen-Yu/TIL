# 데이터 시각화
---
- 사용이유: 데이터를 직관적으로 표현하여 패턴과 의미 분석을 쉽게하기 위해

## 1. 데이터 준비 및 변환
----
### 1-1. 정형 데이터(Structured Data):
-----
- 스키마(구조와 형식을 가진 설계도)를 가진 체계적인 데이터
- 사용이유: 수치기반 분석 가능 -> 그래프,차트 등으로 쉽게 변환 가능
- DB, excel,csv,RDBMS등에 저장됨
  ~~~
  import pandas as pd
  import sqlite3
  
  # pandas의 csv 읽는 함수
  df_csv = pd.read_csv('data.csv')
  # pandas의 xlsx 읽는 함수
  df_excel = pd.read_excel('data.xlsx)
  # sql로 DB 읽기
  conn = sqlite3.connetct('database.db')
  # pandas의 sql(질의어)와 함께 DB 읽는 함수
  df_sql = pd.read_sql("SELECT * FROM table_name", conn)
  ~~~

- 데이터 탐색
  ~~~
  # 정보 확인
  df.info()
  # 샘플 화인(맨앞데이터)
  df.head()
  # 데이터 요약 통계량
  df.describe()
  #컬럼 확인
  df.columns
  ~~~
- 데이터 필터링 및 변환
  ~~~
  # 이름, 나이, 연봉 열 선택해서 새 데이터 생성
  df_selected = df[['name', 'age', 'annual_salary']]
  # 30살 이상으로 새 데이터 생성
  df_filtered = df[df['age'] >= 30]
  # 연봉 데이터 단위(만원 -> 원)변경한 새 데이터 생성
  df['annual_salary_won'] = df['annual_salary'] * 10000
  ~~~
- 데이터 정리 및 가공
  - 결측치 처리, 중복 제거, 데이터 타입 변환
  ~~~
  # 결측치 처리
  # job 행은 '미정' , annual_salary 행은 행의 평균 값으로 결측치 처리
  df.fillna({'job': '미정', 'annual_salary': df['annual_salary'].mean()}, inplace=True)
  # 임시 중복 생성 : concat([a,b]) a,b 붙이기
  # pd.concat([a, b], axis=1) : default axis는 0, 다른차원으로 붙이고 싶을때 사용

  df_duplicate = pd.concat([df.df.iloc[0]], ignore_index=True)
  # 중복 제거
  df_unique = df_duplicate.drop_duplicates()
  ~~~
- 데이터 정렬 및 그룹화
  ~~~
  # 연봉 열을 기준 오름차순(default) 정렬
  df_sorted = df.sort_values(by='annual_salary')
  
  # 연봉 열을 기준 내림차순(default) 정렬
  df_sorted_desc = df.sort_values(by='annual_salary', ascending=False)

  # 직업 열을 기준으로 각 직업별 평균연봉값으로 그룹화
  df_grouped = df.groupby('job')['annual_salary'].mean()
  ~~~

### 1-2. 비정형 데이터(UnStructured Data):
-----
- 고정 스키마가 없는 데이터(고정 구조없는 텍스트, 이미지,영상,오디오 등 )
- 사용이유: 정형 데이터로 확인 불가능한 패턴과 의미를 해석 가능하게 만들기 위해서
- 반정형 데이터(Semi-Structured Data)
  - (키, 밸류) 형식으로 구성된 데이터(고정 스키마가 없지만 규칙은 있음)
	ex) JSON,XML,YAML,로그파일 등
		- JSON
			- self-desciptive 구조
			- 단점은 잉여(redundancy,중복)가 발생함

- 데이터 전처리
  - 텍스트: 공백제거, 특정 문자 제거
  - 이미지: 크기 변환
