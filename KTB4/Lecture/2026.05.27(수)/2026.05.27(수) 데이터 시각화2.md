## 2. Matplotlib 기초 및 활용
----
### 2-1. Matplotlib
-----
MATLAB(행렬용 수학 패키지)의 기능을 제공하는 데이터 시각화 라이브러리
사용이유: Python 환경에서 데이터를 시각적으로 표현하고, 다양한 유형의 그래프를 생성 및 조정할 수 있음
~~~
Matplotlib 임포트 plt 별칭
import matplotlib.pyplot as plt
# 샘플 데이터 생성
x = [1, 2, 3, 4, 5]  # x축 값
y = [10, 20, 15, 25, 30]  # y축 값

# 그래프 제목 및 축 레이블 설정
plt.title("Basic Line Graph")  # 그래프 제목
plt.xlabel("X-axis")  # x축 라벨
plt.ylabel("Y-axis")  # y축 라벨

# 그래프 생성
plt.plot(x, y)  # x, y 데이터를 이용한 선 그래프

# 그래프 출력(colab은 안사용해도 이전 줄에서 출력됨)
plt.show()
~~~

### 2-2. 막대 그래프(Bar Chart)
-----
- 범주형데이터(categorical data) 비교에 사용됨
- 독립적인 항목을 비교하기 위해 사용
- 초점: 범주

### 2-3. 히스토그램(Histogram)
- 연속형 데이터(수치 형데이터: numerical data)의 분포를 구간 단위(bin)로 구분해서 각 구간의 빈도수를 막대로 시각화
- 초점: 분포
  
### 2-4. 산점도(Scatter Plot)
- 연속형 데이터를 2차원 평면에 점분포로 시각화
- 사용처:선형 관계패턴과 상관관계 파악,모델 예측결과 분석

### 2-5. 박스플롯(Box Plot)
- 데이터의 분포, 중앙값(Median), 사분위수(Quartiles), 이상치(Outliers)를 시각화
- 사용처: 이상치 탐색,정규화 및 표준화 필요여부판별, 클래스 구분, 모델 성능 지표 분포

### 2-6. 고급 다중 그래프(Advanced Multiple Graphs)
- 여러 개의 그래프를 배치하여 다양한 데이터 관계를 동시에 시각(다양한 차트 유형을 조합가능)
- 사용이유: 하나의 Figure 내에서 여러 개의 그래프를 배치를 통해 서로 다른 데이터 간의 관계 비교와 다각적인 분석 가능

### 2-7. 벤 다이어그램(Venn diagram)
- 여러 집한 간의 관계를 시각화
- 사용이유: 집한 간의 공통점과 차이점을 쉽게 분석 가능
