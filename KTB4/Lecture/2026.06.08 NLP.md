# NLP

## NLP 기초
- 인간의 언어를 기계(컴퓨터)가 이용할 수 있도록 연구하는 인공지능 분야
- 목적: 언어의 문법적 구조 분석, 문장 의미 파악, 맥락 이해
- 활용 예)문서 요약, 기계 번역, 감성 분석, 질의응답 시스템, 음성 인식
- 벡터화	
	- BoW (Bag of Words)
	- 다항 나이브 베이즈 (Multinomial Naive Bayes) 	
- 구성
  텍스트 전처리 -> 텍스트 표현(벡터화) -> 모델 학습 -> 모델 평가 및 튜닝


## 언어 모델

### N-gram Language Model
- 문장에서 앞에 등장한 **N-1개의 단어를 조건**으로 두고, **다음(N 번째) 단어의 조건부 확률을 계산**하는 **통계 기반** 언어 모델
- 마르코프 가정(Markov Assumption)
  - "미래 상태는 현재 상태에만 의존하고, 과거 전체에느 의존 안한다." 라는 과정
  - "다음 단어는 바로 앞의 N-1개 단어에만 의존한다"는 가정을 전제하에 모델 계산을 단순화
 
### 형태소 분석 (Morphological Analysis)
- 문장을 형태소 단위로 나누고, 각 형태소에 품사 정보를 붙여 텍스트를 더 세밀하게 처리하는 전처리 기술
## 텍스트 표현

### 희소 표현
- 벡터의 대부분이 0인 표현 
#### 원-핫 인코딩 (One-Hot Encoding)
- 범주형 값을 {해당 범주만 1, 나머지 범주는 0}인 고정 길이 벡터로 표현하는 인코딩 방식

#### TF-IDF (Term Frequency-Inverse Document Frequency)
- 문서 집합에서 각 문서를 단어 중요도 벡터로 표현한 방식

### Word Embedding(단어 임베딩)
- 단어를 **고정차원실수벡터**로 변환, 단어간 의미적 유사성과 사용맥락의 유사성을 반영하는 표현방식
