# RAG

## RAG Evaluation(RAG평가)
- 검색품질과 생성 품질을 정량적 지표로 측정하는 과정
### RAG Evaluation(RAG평가)

#### 검색 품질
- Context Precision
  - 검색된 문서 중 실제로 관련 있는 비율(검색된 문서 실용도)
    -> 필요하지 않는 문서가 있는가?

$$
\text{Context Precision} = \frac{|\text{Retrieved} \cap \text{Relevant}|}{|\text{Retrieved}|}
$$
 
  
- Context Recall
  - 관련 문서 중 실제로 검색된 비율(문서 검색 정확도)
    -> 검색되지 못한 문서가 있는가?
$$
\text{Context Recall} = \frac{|\text{Retrieved} \cap \text{Relevant}|}{|\text{Relevant}|}
$$

#### 생성 품질
- Faithfulness
  - 답변이 검색된 문맥에 충실한 정도
   -> 답변이 질문의 지어내지 않았는가?
- Answer Relevancy
  - 답변이 질문에 관련된 정도
   -> 답변이 질문의 의도에 적합한가?
