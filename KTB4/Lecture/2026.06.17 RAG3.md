# RAG

## RAG Evaluation(RAG평가)
- 검색품질과 생성 품질을 정량적 지표로 측정하는 과정
- 생성과 검색 단계 각각 평가
### RAG Evaluation(RAG평가)

#### 검색 품질
- Context Precision
  - 검색된 문서 중 실제로 관련 있는 비율(검색된 문서 실용도)
    -> 필요하지 않는 문서가 있는가?

$$
\text{Context Precision} = \frac{|\text{Retrieved} \cap \text{Relevant}|}{|\text{Retrieved}|}
$$
 
  
- Context Recall
  - 관련 문서 중 실제로 검색된 비율(문서 검색 정확도)
    -> 검색되지 못한 문서가 있는가?

$$
\text{Context Recall} = \frac{|\text{Retrieved} \cap \text{Relevant}|}{|\text{Relevant}|}
$$


#### 생성 품질
- Faithfulness
  - 답변이 검색된 문서에 충실한 정도(환각 확인 지표)
   -> 답변이 문서에 없는 내용을 지어내지 않았는가?
- Answer Relevancy
  - 답변이 질문에 관련된 정도
   -> 답변이 질문의 의도에 적합한가?

#### 평가 데이터셋
     
| 구성 요소 | 설명 | 예시 | 생성자 | 필수 여부 |
| --- | --- | --- | --- | :----: |
| `question` | 사용자 질문 | `"어댑터즈는 무엇인가요?"` | 사람이 작성 | ✅  필수 |
| `ground_truth` | 정답 (사람이 작성한 기준 답변) | `"어댑터즈는 스타트업코드에서 제공하는 개발 책 서빙 서비스입니다."` | 사람이 작성 | ✅  필수 |
| `contexts` | Retrieval이 반환한 문맥 | `["어댑터즈는 스타트업코드에서...", "다양한 개발 분야의..."]` | RAG 파이프라인이 생성 | ✅  필수 |
| `answer` | Generation이 생성한 답변 | `"어댑터즈는 개발 책 서빙 서비스입니다."` | RAG 파이프라인이 생성 | ✅  필수 |
| `ground_truth_contexts` | 정답을 도출하는 데 실제로 필요한 "이상적인" 문서 목록 (Golden Context) | `["어댑터즈는 스타트업코드에서 제공하는 개발 책 서빙 서비스입니다."]` | 사람이 작성 | 🟡  권장 |
| `retrieved_doc_ids` | 검색된 문서의 고유 ID (원본 문서 추적용) | `["doc_0231", "doc_0589"]` | RAG 파이프라인이 생성 | 🟡  권장 |
| `relevance_labels` | 각 검색 문서가 실제로 관련 있는지 사람이 라벨링한 값 | `[1, 0, 1]` (관련=1, 무관=0) | 사람이 작성 (또는 LLM 보조 라벨링) | 🟡  권장 |
| `question_type` | 질문 유형 분류 (사실형, 추론형, 비교형, 멀티턴 등) | `"factual"`, `"multi-hop"`, `"comparison"` | 사람 또는 LLM이 작성 | 🟡  권장 |
| `difficulty` | 질문 난이도 (검색·추론 복잡도) | `"easy"`, `"medium"`, `"hard"` | 사람 또는 LLM이 작성 | ⚪   선택 |
| `metadata` | 질문 출처, 도메인, 작성일 등 부가 정보 | `{"domain": "education", "source": "FAQ_v2"}` | 사람이 작성 | ⚪   선택 |
| `negative_contexts` | 의도적으로 포함한 무관/유사 문서 (Hard Negative) | `["스타트업코드의 채용 공고 안내..."]` | 사람 또는 자동 생성 | ⚪  선택 |
| `multi_turn_history` | 멀티턴 평가 시 이전 대화 기록 | `[{"q": "어댑터즈는?", "a": "..."}]` | 사람이 작성 | ⚪  선택 |
| `latency` | 검색·생성에 걸린 시간 (성능 모니터링용) | `{"retrieval_ms": 120, "generation_ms": 850}` | RAG 파이프라인이 생성 | ⚪  선택 |
| `token_usage` | 검색 문서·답변의 토큰 사용량 (비용 추적용) | `{"context_tokens": 512, "answer_tokens": 48}` | RAG 파이프라인이 생성 | ⚪  선택 |
