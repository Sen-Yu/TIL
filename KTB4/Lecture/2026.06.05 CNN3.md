## 엔트로피
- 정보를 표현하기 위해 필요한 평균 비트(정보)수 -> 정보량
- 예시) 어느 지역의 내일 날씨 확률분포
  - $P(맑음) = 0.5$
  - $P(흐림) = 0.25$
  - $P(비) = 0.25$
    
  $$H(P) = P(맑음)\log_2 P(맑음) + P(흐림)\log_2 P(흐림) + P(비)\log_2 P(비)$$
  $$H(P) = {0.5}\log{0.5} + {0.25}\log{0.25} + {0.25}\log{0.25}$$
  $$H(P) = 0.5log{{2}^{-1}} + 0.5log{{2}^{-2}} = -1.5$$
이 날씨의 엔트로피는 1.5비트 -> 표현에 최소 1.5비트 필요

## 크로스 엔트로피
- 두개의 확퓰분포에 대한 척도
  - 머신러닝,딥러닝: **실제 데이터의 정답분포($P$)** 와 **모델이 예측한 확률분포($Q$)**

**① 엔트로피 (Entropy)**   
$$H(P) = -\sum_x P(x)\log P(x)$$

**② 크로스 엔트로피 (Cross Entropy)**   
$$H(P, Q) = -\sum_x P(x)\log Q(x)$$

**③ 다중 클래스 크로스 엔트로피 손실 (Categorical Cross Entropy)**   
$$L_m = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{M} y_{i,c}\log\hat{y}_{i,c}$$

**④ 이진 크로스 엔트로피 손실 (Binary Cross Entropy)**   
$$L_b = -\frac{1}{N}\sum_{i=1}^{N}\left(y_i\log\hat{y}_i + (1-y_i)\log(1-\hat{y}_i)\right)$$



| 기호 | 의미 |
|------|------|
| $H(P)$ | **엔트로피** — 확률분포 $P$의 불확실성(정보량) |
| $H(P,Q)$ | **크로스 엔트로피** — 실제분포 $P$와 예측분포 $Q$의 차이 |
| $P(x)$ | **실제 확률분포** — 정답 레이블 |
| $Q(x)$ | **예측 확률분포** — 모델의 출력 |
| $\sum_x$ | **모든 클래스 $x$에 대해 합산** |
| $\log$ | **로그 함수** — 보통 자연로그 $\ln$ 또는 $\log_2$ 사용 |
| $L_m$ | **다중 클래스 크로스 엔트로피 손실** (m = multiclass) |
| $L_b$ | **이진 크로스 엔트로피 손실** (b = binary) |
| $N$ | **전체 샘플 수** |
| $M$ | **전체 클래스 수** |
| $i$ | **i번째 샘플 인덱스** |
| $c$ | **c번째 클래스 인덱스** |
| $y_{i,c}$ | i번째 샘플의 c번째 클래스 **정답값** (0 또는 1) |
| $\hat{y}_{i,c}$ | i번째 샘플의 c번째 클래스에 대한 **모델 예측 확률** |
| $y_i$ | i번째 샘플의 **정답값** (0 또는 1) |
| $\hat{y}_i$ | i번째 샘플의 **모델 예측 확률** |
| $(1-y_i)$ | 정답이 0일 때 활성화되는 항 |
| $(1-\hat{y}_i)$ | 예측이 0일 확률 |


## 미분계수(Derivative)
- $x$가 $a$에 가까워질 때, 두 점 사이의 기울기가 수렴하는 값. 기하학적으로는 $a$에서의 접선의 기울기

$$\lim_{x \to a}\frac{f(x)-f(a)}{x-a} = f'(a)$$
$$**평균변화율의 극한 = 순간변화율 = $a$에서의 미분계수**$$


### 극한이 존재하는 조건 — 좌극한 · 우극한

$$\lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x)$$

좌극한(왼쪽에서 접근)과 우극한(오른쪽에서 접근)이 **같아야** 극한이 존재.

| 상황 | 의미 | 예 |
|------|------|-----|
| 좌 ≠ 우 | 극한 존재하지 않음 | 절댓값 함수 $\|x\|$의 $x=0$ |
| 불연속 | 미분 불가능 | ReLU의 $x=0$ |
| 진동 | 극한 없음 | $\sin(1/x)$의 $x=0$ |

> 딥러닝에서 **ReLU** 활성화 함수가 $x=0$에서 미분 불가능한 이유가 바로 이것.
> 실제로는 좌미분값 0을 관례적으로 사용.

---

### 미분계수와 최솟값의 관계

$$f'(a) > 0 \Rightarrow \text{오른쪽으로 갈수록 증가} \quad \therefore \text{왼쪽(반대 방향)으로 이동}$$
$$f'(a) < 0 \Rightarrow \text{오른쪽으로 갈수록 감소} \quad \therefore \text{오른쪽(반대 방향)으로 이동}$$

**최솟값을 향할 때는 미분계수의 반대 방향으로 이동**

경사하강법원리

$$\theta_{t+1} = \theta_t - \alpha \cdot f'(\theta_t)$$

---

### 4. 크로스 엔트로피와의 연결

손실함수 $L$을 가중치 $\theta$로 미분하면 **지금 위치에서의 기울기(gradient)** 를 구할 수 있음.

$$\frac{\partial L}{\partial \theta} \quad \leftarrow \text{이것이 gradient}$$

---

### 5. 전체 정리

| 단계 | 수식 | 내용 |
|------|------|------|
| ① 미분계수 정의 | $f'(a) = \lim_{x\to a}\frac{f(x)-f(a)}{x-a}$ | 순간변화율 = 접선의 기울기 |
| ② 최솟값 방향 | $-f'(a)$ 방향 | 미분계수의 **반대 방향**으로 이동 |
| ③ 경사하강법 | $\theta_{t+1} = \theta_t - \alpha\frac{\partial C}{\partial\theta}$ | 고정 학습률로 가중치 업데이트 |
| ④ 손실함수 | $L_m,\ L_b,\ \text{MSE}$ | MSE(회귀), Cross Entropy(분류)로 $L$ 정의 |
| ⑤ Adam | $W_{t+1} = W_t - \frac{\eta}{\sqrt{\hat{v}_t}+\varepsilon}\hat{m}_t$ | gradient의 방향 + 크기를 적응형으로 조절 |
