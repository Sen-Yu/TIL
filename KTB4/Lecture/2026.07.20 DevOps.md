# DevOps

## 한줄정리
DevOps란 개발과 운영의 협업을 통해 배포속도와 안정성을 높이는 개발문화이자 방법론입니다.       
  제가 했던업무에서 배포된 컨테이너들을 모니터링하고, 컨테이너가 일시중단했었거나 완정종료한경우 1차적으로 문제를 찾아 해결해었습니다. 
  코드적인 이유인 경우 해당 부분까지 최대한 좁혀 개발자들에게 전달했었습니다.      
AWS EC2는 아마존에서 제공하는 클라우드 컴퓨팅 서비스입니다. 우리는 인스턴스를 생성할때 인스턴스의 스펙을 설정하고 외부통신을 위해 인바운드 규칙을 설정해서 사용합니다. 저는 업무에서 AWS S3를 주로 확인했기에 해당부분은 처음접한다.

빅뱅배포는 변경사항을 한번에 배포하는 원초적인 배포방식입니다. 대학교 3학년때 저를 포함한 조원들이 깃허브의 존재를 몰라서 각자의 환경에서 직접 코드를 짜고 각자의 기능이 개선 또는 추가될때마다 제가 합병을 했는데, 지금 돌이켜보니 이 방식이 빅뱅배포였던것같습니다. 

Docker는 리눅스 애뮬레이터, 즉 컨테이너를 실행시키는 가상화 플랫폼입니다. 
docker image는 프로젝트 코드이며, docker image를 실행시키면 Docker Container가 됩니다.
docker daemon은 컨테이너를 관리하는 데몬이며, docker registry는 도커 이미지를 저장 및 배포하는 저장소 입니다.
저는 업무에서 docker container에러 사항 확인하고

Volume은 docker 컨테이너 정보를 보존 및 공유하는 저장소입니다.
Bridge Network는 컨테이너 끼리 통신연결해서 의사소통하게 하는 가상 네트워크입니다.
Docker Compose는 YAML 형식을 파일로 정의하고, 단일 명령어로 동시에 실행하게하는 docker의 공식 오픈소스 툴

Github Action은 GitHub에서 직접 제공하는 CI/CD(지속적 통합 및 지속적 배포) 플랫폼
