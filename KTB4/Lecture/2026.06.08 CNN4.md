# CNN

## 사전 훈련 모델 활용

### 사전 훈련 모델(Pre-trained Model)
학습이 끝난 상태의 모델
- 사용이유: 시간과 자원을 절약하며 모델을 처음부터 설계및 구현없이 사용가능(신속한 활용)
- 주의점: 성능 평가할때 정확도와 손실을 비교해서 사용해야만한다.
	- 1. VGC16
		- 13개의 CL와 3개의 FCL 구성
 		- 모든 CLD은 3x3 필터 사용
   		- Max Pooling 활용
     	- 전이 학습에 효과적 활용가능(ImageNet 데이터셋으로 사전 훈련된 가중치 제공가능)
     	- 138M의 파라미터 가진 대규모 모델 
	- 2. ResNet
   		- 잔차(입력과 출력의 차이)를 학습하는 구조가 포함된 모델 	
		- Residual connections (skip connection)
			- 같은 레이어의 입력을 출력에 추가해서 다음 레어어의 입력으로 보내는 연결
    		-> 기울기소실 발생 확률 감소
### 전이 학습(Transfer Learning)
- 학습시간 단축 및 성능을 개선을 위해서 사전 훈련된 모델에서 피처 또는 가중치를 추출하는 학습기법입니다.
  - 파인튜닝(Fin tuning): 기존 가중치를 기반으로 새로운 데이터셋으로 재학습 하는 방식
    -  사용 이유: 학습시간 단축 및 데이터 부족 문제 극복  
  - 특징추출(Feature Extraction): 합성곱 계층을 유지함으로서 (가중치,특징맵)을 그대로 사용한채로  분류기만 학습하는 방식
    -  적은 연산량과 적은 데이터 셋으로 학습가능
  - 제로샷 학습: 훈련되지 않은 정보를 학습된 내용과 연관지어 인지 및 추론하여 예측시키는 학습기벙입니다. 미리 레이블을 세팅한다.
 
### 오버피팅
  훈련데이터에 너무 학습되서 새로운 데이터에 대한 예측이 안좋음
  - 방지법 drop out
	  - 데이터증강
	  - 정규화(Regularization)
      - 손실에대 패널티항(L1,L2)을 추가하는 방식 
	  - 교차검증
	  - 조기종료
	  - 앙상블

 - 반대개념인 언더피팅이 있습니다.

### Hyperparameter Tuning
- 사전 훈련 모델의 세부 설정 변경 가능 방법
- 학습속도,배치크기,에포크,옵티마이저,모멘텀,드롭아웃비율,......
	- 활성화함수: 독자적이기때문에 초매개변수취급함
	- 초기화 : 랜덤학습이 빨리됨
