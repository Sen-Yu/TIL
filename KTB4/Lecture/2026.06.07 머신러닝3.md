# 머신러닝 기초

## K-Nearest Neighbors (K-NN, K-최근접 이웃)
- 가장 가까운 K개의 데이터를 찾고 이를 바탕으로 새로운 데이터의 레이블(분류) 또는 예측값(회귀)을 결정하는 알고리즘
- 사용이유: 학습된 모델 없이, 데이터간의 거리를 비교해서 직관적이고 유연하게 분류 및 예측 가능 
- 특징: 학습 불필요, 예측 시점에서 가장 가까운 데이터만 찾기
  - 유클리드 거리(Euclidean Distance)
    - 두 점 사이의 직선 거리 측정 방식
    - 직선적인 공간적 거리가 중요할 때, 사용
  - 맨해튼 거리(Manhattan Distance)
    - 각 좌표축(axis)따라 이동하는 합으로 거리 측정 방식
    - 데이터의 방향이 제한될때(특정 축 기준) 사용
