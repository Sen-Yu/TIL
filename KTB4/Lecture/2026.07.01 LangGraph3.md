# LangGraph

## Short-term Memory
- 동일한 세션에서 재사용 가능한 대화 이력
- 같은 thread에서의 대화 기록(state[messages]) -> thread 종료하면 메모리도 같이 사라짐
- 사용법
  - `add_messages` Reducer
    - 새 메시지 뒤에 이전 대화 메시지 결합(중복 대화 불필요)
   
## Long-term Memory
- 여러 대화에서 재사용 가능한 대화이력
- 운영홤경에서 Store(저장공간) 사용
- RAG에서 검색 재료로 활용 가능
- 사용이유: 사용자 정보,선호,패턴을 유지해서 개인화된 응답과 일관된 경험 제공을 위해서


## Architecture

### Interrupt
- 랭그래프 실행중 **일시 중단과 일시 중단 지점 재개**가 가능하게하는 **랭그래프 매커니즘**
- 멈춘 시점 checkpointer가 checkpoint를 생성해서 상태(state) 저장
- 사용이유: 자동화 실수 감소,수정                                                         
- 예시
  - 워크플로우에 직접 개입해서 수정: 이메일 초안 작성 -> 일시중지 -> 사용자가 직접 다듬음 -> 재개
  - 사용자의 응답을 기다리는 구간에서 일시 중지: 검토/답장을 기다리는 상태 -> 일시중지 -> 사용자가 검토/답장 -> 재개   

### human in the loop
- 워크플로우에 사람의 개입 단계를 배치하는 설계 패턴 
- 역할
  - 행동 승인(Approve)
  - 수정(Edit)
  - 결정 거부(Reject)
  - 정보 제공(priovide)
- 사용이유: 워크 플로우의 책임 지점에 배치해서 자동화 사고를 감소와 운영 책임 구조 명확히 하기 위해서(금융, 의료, 법률에서 특히 중요) 

### streaming
- 랭그래프 실행중에 노드결과,LLM 토큰,state 변화를 완료전에 분할해서 전달받는 실행방식
- 사용이유: 사용자의 체감 대기시간(Latency) 감소
- stream_mode
- 
~~~
# === 동기 환경: for 루프로 이벤트 받기 ===
for event in graph.stream(
    input_data,
    config,
    stream_mode="updates",  # 받는 이벤트 종류: updates / values / messages / custom
):
    handle_event(event)


# === 비동기 환경: async for로 이벤트 받기 ===
async for event in graph.astream(
    input_data,
    config,
    stream_mode="updates",
):
    await send_to_client(event)
~~~

### Plan and Execute
- 설계하고,실행한 다음 필요에따라 재설계하는 에이전트 설계패턴
- 사용이유: 중복 호출 방지
- 구조
  - Planner: 실행 계획 설계
  - Executor: 실행 계획을 단계적으로 실행
  - Replanner: 실행 결과를 통해 남은 계획 유지,수정, 최종답변 생성할지 판단
- 사용법
  Planner → Executor → Replanner 세 노드를 그래프로 연결하고, Replanner의 조건부 엣지로 다음 단계 실행과 종료를 분기

 ### Evaluator-Optimizer Pattern
 - Generator 결과를 평가하고 최적화하는 절차를 반복하는 패턴
 - 무한루프 방지를 위해서 최대 반복 횟수 설정


### subgraph
- 큰 그래프의 일부분을 맡은 작은 그래프
- 사용이유
  - 재사용성 확보  
  - invoke()로 모듈 단위 테스트 가능

### Multi Agent System
- 다수의 Agent가 역할 배분해서 협업하는 랭그래프 시스템
- 구성
	- 전문 Agent: 작업에 필요한 프롬프트, tool만 보유
	- Supervisor: Agent 업무 조율 노드
	- 공유 State: Agent들이 공유하는 상위 그래프의 State
	- 종료 조건: 그래프를 끝내는 기준
