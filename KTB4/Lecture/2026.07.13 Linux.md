# Linux

## 한줄정리
쉘(shell)은 OS와 커널사이에 존재하는 시스템프로그램입니다. crontab은 리눅스에서 스크립트를 자동실행시키는 예약 명령어입니다. 
데몬(daemon)은 알아서 자동으로 계속 실행하는 백그라운드프로세스입니다.
SSH는 서버와 원격 통신을 할때 사용합니다. 
vi는 텍스트 편집기입니다. 파이프는 2개이상의 명령어를 복합적으로 엮어 사용하게해주는 명령어입니다.
Grep 은 검색 명령어입니다. 이는 파이프와 사용해서 보다 정확한 검색을 할 수 있습니다.
두파일의 바이트를 비교해서 차이점을 확인하는 cmp ,패턴에따라 자동수정하는 sed , 라인 단위로 텍스트를 처리 분석하는 awk는 처음접했습니다. 

### 파일 관련 명령어
tar 모델 일때 자주사용
DU/DF는 새로운 추가 업데이트(모델), 프로세스 추가 실행할때 어느 서버에 프로세스를 추가할지 선택할때 사용했습니다.

### 네트워크
apt,curl,wget은 서버가 들어온 상태에서 CLI 서버에서 주로 사용해서 세팅을 마췄습니다.
