# Linux

## 한줄정리
쉘(shell)은 OS와 커널사이에 존재하는 시스템프로그램입니다. crontab은 리눅스에서 스크립트를 자동실행시키는 예약 명령어입니다. 
데몬(daemon)은 알아서 자동으로 계속 실행하는 백그라운드프로세스입니다.SSH는 서버와 원격 통신을 할때 사용합니다. 
vi는 텍스트 편집기입니다. 파이프는 2개이상의 명령어를 복합적으로 엮어 사용하게해주는 명령어입니다. Grep 은 검색 명령어입니다. 이는 파이프와 사용해서 보다 정확한 검색을 할 수 있습니다. 두파일의 바이트를 비교해서 차이점을 확인하는 cmp ,패턴에따라 자동수정하는 sed , 라인 단위로 텍스트를 처리 분석하는 awk는 처음접했습니다.apt는 패키지를 설치,업데이트,삭제를 지원하는 명령어입니다. curl wep과 통신을 지원하는 명령어입니다. wget은 다운로드 기능을 지원하는 명령어입니다. Nslookup은 도메인 조회,역조회를 하는 명령어입니다. NTP는 서버와 시스템간의 시간을 동기화하는 프로토콜입니다. SS는 소켓 상태를 확인하는 명령어입니다. jq는 json관련 출력 및 편집 명령어입니다.
