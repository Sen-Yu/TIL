# Transformer

## 입력처리 파이프라인
 자연어 문장 ->           토크나이징            ->   포지셔널 임베딩      ->   포지션 벡터
              { 문장 개별 토큰화 -> 토큰 추출 }
                                   토큰    -> { 임베딩 -> 토큰벡터 } 
### 토크나이저 (Tokenizer)
- **입력 텍스트**를 분절**규칙**에 따라 **토큰화**후 **사전** 참조해서 **정수 ID 시퀀스**로 **변환**하는 전처리 모듈(특수토큰 추가가능)
- 분절 규칙(단위)
 - 단어: 공백, 구두점으로 토큰 구분
 - 서브워드: 빈도 높은 문자열은 하나의 토큰, 빈도가 낮은 단어는 더작게 분리 -> 통계 기반
 - 문자: 한 글자가 토큰
- 특수 토큰
  - 사전에 미리 등록, 고유 정수 ID 가짐  
  - 예시) CLS, SEP, PAD, UNK, BOS, EOS
- 예시
  ~~~
     입력   ->   토큰   ->   고유 정수 ID
  입력: "어댑터즈는 스타트업코드에서 제공하는 서비스입니다."
  토큰: ['어', '##댑', '##터', ... , '서비스', '##입니다', '.']
  정수 ID: {75: '어', 1164:'##댑', 23634:'##터', ... , 673:'서비스', 512:'##입니다', 4312:'.'}
  ~~~


### 패딩
- 길이가 서로 다른 시퀀스들을 동일한 길이로 맞추기 위해 PAD 토큰으로 채우는 전처리 기법
- 사용이유: 입력 시퀀스의 길이가 같아야만 배치 단위로 학습 가능
 - 어텐션 마스크: 실제 의미 없는 PAD 토큰 위치 무시

### 토큰 임베딩
- 토큰 정수 ID를 숫자 벡터로 매핑하는 과정
- 사용이유: 모델의(계산 및 학습이 가능한) 입력값으로 바꾸기 위해서
- 예시 
  ~~~
  토큰 정수 ID    ->   임베딩
  정수 ID: {75: '어', ... , 4312:'.'}
  임베딩 75 -> [0.12, -0.34, 0.56, ..., 0.78], ... , 4312 -> [-0.2, 0.156, -0.909, ..., 0.21]
  ~~~
