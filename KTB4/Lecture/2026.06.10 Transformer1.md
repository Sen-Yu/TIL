# Transformer

##

## 파이프라인
 자연어 문장 ->           토크나이징            ->   포지셔널 임베딩      ->   포지션 벡터
              { 문장 개별 토큰화 -> 토큰 추출 }
                                   토큰    -> { 임베딩 -> 토큰벡터 } 
### 토크나이저 (Tokenizer)
- **입력 텍스트**를 분절**규칙**에 따라 **토큰화**후 **사전** 참조해서 **정수 ID 시퀀스**로 **변환**하는 전처리 모듈(특수토큰 추가가능)
- 분절 단위 : 단어(공백,구두점으로 토큰 구분), 서브워드(빈도 높은 문자열은 하나의 토큰, 빈도가 낮은 단어는 더작게 분리), 문자(한글자 토큰)
- 특수 토큰
  - 사전에 미리 등록, 고유 정수 ID 가짐  
  - CLS, SEP, PAD, UNK, BOS, EOS 
- 예시)
  ~~~
     입력   ->   토큰   ->   고유 정수 ID
  입력: "어댑터즈는 스타트업코드에서 제공하는 서비스입니다."
  토큰: ['어', '##댑', '##터', ... , '서비스', '##입니다', '.']
  정수 ID: {정수1: '어', 정수2:'##댑', 정수3:'##터', ... , 정수n:'서비스', 정수k:'##입니다', '.'}
  ~~~
