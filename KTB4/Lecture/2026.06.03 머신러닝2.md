## Data Processing(데이터 전처리)
- 원본 데이터를 분석 및 모델합습을 위해 정제 및 변환하는 과정
- 종류
  - 1)결측값 처리: NAN값 대체
  - 2)이상치 제거: 비정상적 값 제거
  - 3)데이터 정규화: 일정 범위(0<=x<=1)로 변환하는 과정
  - 4)데이터 변환: 로그 변환, 원-핫 인코딩
    - 원-핫 인코딩: 범주형 데이터를 이진 벡터로 변환하는 기법(범주형 데이터 -> 수치형 데이터) 
  - 5)데이터 분할: 학습과 검증으로 분리
    
- **전체 예제 코드**
~~~
import pandas as pd
# 0)데이터 생성(가상의 직원 급여)
data = {
    '직원': ['John', 'Anna', 'Peter', 'Linda', 'James'],
    '연봉': [50000, 60000, 55000, None, 65000],
    '근속연수': [5, 7, None, 8, 9]
}
df = pd.DataFrame(data)

# 1)결측값 처리 (중앙값으로 대체)
df.loc[:, '연봉'] = df['연봉'].fillna(df['연봉'].median())
df.loc[:, '근속연수'] = df['근속연수'].fillna(df['근속연수'].median())

# 2)이상치 제거 (연봉이 0 이하인 경우 제거)
df = df[df['연봉'] > 0]

from sklearn.preprocessing import MinMaxScaler
# 3)데이터 정규화 
scaler = MinMaxScaler()
df[['연봉', '근속연수']] = scaler.fit_transform(df[['연봉', '근속연수']])

# 4)데이터 변환: 원-핫 인코딩 (직원 이름을 카테고리 변수로 변환)
df = pd.get_dummies(df, columns=['직원'])
  
from sklearn.model_selection import train_test_split
# 5)데이터 분할 (학습용 80%, 검증용 20%)
train, test = train_test_split(df, test_size=0.2, random_state=42)
print("\n학습용 데이터셋:")
print(train)
print("\n검증용 데이터셋:")
print(test) 
~~~

## Data Augmentation(데이터 증강)
- 원본 데이터를 변형하여 새로운 데이터를 생성하는 기법
- 사용이유: 다양성증가 및 과적합 방지, 일반화 성능 햐상
  - 종류
      - 이미지 회전
        - `image.rotate(angle)` : 반시계 방향으로 angle만큼 회전
      - 이미지 크기 조절
        - `image.resize(width, height)` : width, height로 재조정 
      - 이미지 뒤집기
        - `ImageOps.mirror(image)`: 좌우 대칭
        - `ImageOps.flip(image)`: 상하 대칭
      - 이미지 이동
        - `np.roll(array, shift, axis)`: array를 axis 기준으로 shift 만큼 이동한다.    
      - 색상 변형: 명도,채도 조절
        - 명도
          - `enhancer = ImageEnhance.Brightness(image)`: images를 위한 밝기 조절 객체 생성
          - `enhancer.enhance(factor)`: 밝기 조절 객체의 images를 factor배율 만큼 밝기 조절
      - 노이즈 추가
      - 역번역
      - 속도변화

## Dataset Split(데이터셋 분할)
- 데이터를 목적에 맞게 학습(training), 테스트(test), (필요 시)검증(validation)으로 분할하는 과정
- 사용이유: 모델의 성능을 평가하고 일반화하기 위해서
  - 종류
    -  랜덤 분할 기법:
    ```
    from sklearn.model_selection import train_test_split

    # train : test = 8 : 2
    train_data, test_data = train_test_split(data, test_size=0.2, random_state=42)
    ```
