# Transformer

## 어텐션
- 입력 시퀀스의 전체 단어 중에 어떤 단어에 집중할지 가중치로 결정하는 방식
            
$$          
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) · V          
$$      

### 마스킹
- 특정 부분을 가리는 행위(이미지, 텍스, 암호, 네트워크, etc, ...)
- 어텐션에서는 특정 위치 정보를 참조하지 못하도록함
  - 예) softmax 단계에서 가중치를 0이 되게해서 참조를 차단
- 마스크 종류 
  - 패딩 마스크(Padding Mask): 동일한 길이를 맞추기 위핸 보충한 패딩토큰을 참조 못하도록 하는 마스크
  - 룩어헤드 마스크(Look-ahead Mask): 현재 위치 이후의 토큰 참조 못하도록하는 마스크,디코더 학습 중 미리 보면 안된느 미래토큰
    -> 문제를 풀어야하는 학생이 답지를 보고 문제를 푸는 행위를 방지하느 마스크 


### 잔차 연결 (Residual Connection)
- 어떤층의 입력을 출력에 그대로 직접 더하여, 다음 레이어로 넘기는 연결(우회경로:skip connection)
- 사용이유
  - 기울기 소실 문제 해결
  - 모델 학습 안정화
  - 기울기 소실(gradient vanishing): 신경망이 깊어지면서 기울기가 점점 작아져 가중치가 거의 학습되지 않는 경우
- 새로운 출력식
    
$$
Output = x + layer(x)
$$        
     
- 멀티 헤드 어텐션 

$$
Add = MHA(x) + Id(x)
$$
   
### 레이어 정규화 (Layer Normalization)
- 각 샘플의 특성 차원을 기준으로 평균과 분산을 계산해서 정규화 하는 기법
            -> 각 층의 파라미터들을 정규화하는 기법
- 사용이유: 레이어 출력 분포가 학습 도중 흔들리는 것을 막아 학습 속도와 안정성을 높이기 위해서
$$
LayerNorm(x) = \gamma \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta
$$
