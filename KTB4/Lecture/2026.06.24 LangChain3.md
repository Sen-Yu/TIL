# LangChain

## LangSmith
- **LangChain** 기반 LLM 애플리케이션의 실행과정을 추적하고, 응답 품질을 평가하며, 프롬프트를 버전관리하는 **운영 평가 플랫폼**(운영시 관찰 및 개선을 위한 도구)
  -> 블랙박스 같은 LLM 전반의 각 실행 과정을 Run 단위로 기록하고, 각 단계의 입력·출력·지연 시간·토큰 사용량을 트리 구조로 출력
- 사용이유
	- 각 단계 입력·출력·비용·지연을 자동으로 추적 및 집계
  	- 변경 사항이 답변 품질에 미치는 영향을 정량적으로 평가
 
- 플랫폼 사이트
	- https://apac.smith.langchain.com

### Tracing
-  LangChain 체인의 실행 흐름의 각 단계 입력·출력·지연 시간·토큰 사용량을 트리 구조로 보여 주는 **LangSmith의 추적 기능**( LangChain 체인이 실행될 때 내부 변화를 알기위한 기능)
- 사용이유: 답변 품질 저하, 비용 증가, 응답 지연의 원인을 찾기 위해서
- 실행기록
	- Trace: 체인 하나의 실행 전체
	- Run: Trace 내부의 하나의 실행 단위
	- Span: Run 내부의 세분화된 하나의 실행 단위   
- 사용방법
	- 세팅: LANGSMITH_TRACING = "true"
	- chain밖의 python 함수 추적도 포함시키고 싶으면 @traceable 데코레이터 사용
- 플랫폼 주 확인 항목
	- Latency : 각 단계 실행 시간
  	- Tokens: 모델 호출에 사용된 토큰 수
  	- Input/Output: 각 단계 입력값/출력값
  	- Erros: 실패한 Run 표기(실패 단계 추적 가능)  

### Dataset
- LLM 애플리케이션 **펑가 기준 데이터**
- 사용이유
	- 결과에 대한 영향을 반복 검증
 	- 실패 사례 재방지 
- 구성
	- Dataset: 평가 데이터(Example 묶음)
 	- Example: Dataset 내부의 하나의 평가 항목(inputs : outputs = 질문리스트 : 기대 답변 리스트)
  	- Version: Dataset 변경 이력

### Evaluator
- LLM 모델의 실제 출력과 기대 출력을 기준에 따라 비교하고, 점수와 코멘트를 반환하는 **평가 함수**
- 실제 출력(답변)이 기대 출력(답변)과 얼마나 일치하는지 판단
- 종류
	- LLM 평가: LLM이 비교 및 점수 평가(LLM 호출 비용 발생)
	- 휴리스틱: 사람이 작성한 코드 규칙 기반 평가
 	- 임베딩 유사도: 벡터화해서 유사도 계산 
  	- 직접적인 사람평가: LangSmith 대시보드에서 직접 점수 평가 또는 코멘트
- 주요 파라미터

| Prameate | Deafault | Description |
|---|---|---|
| target | 필수 | 평가할 대상<br>(inputs dict를 받아 outputs dict를 반환하는 함수나 Runnable을 전달) |
| data | 필수 | 평가에 사용할<br>Dataset(이름, ID, Example 리스트 등을 전달가능) |
| evaluators | None | 각 실행 결과에 적용할 Evaluator 함수 목록<br>(여러 개를 넣어 동시에 여러 기준으로 평가 가능) |
| experiment_prefix | None | 실험 이름 앞에 붙일 접두어<br>(대시보드에서 실험을 명시적 구분) |
| metadata | None | 실험에 붙일 부가 정보<br>(프롬프트 버전, 모델명, 커밋 해시 등) |
| description | None | 실험에 대한 짧은 설명 |
| max_concurrency | 0 | 동시에 실행할 평가 제한 수<br>(0: 순차 실행/정수: 동시 실행을 제한 수/None: 제한없이 실행) |
| num_repetitions | 1 | 각 Example을 반복 실행할 횟수<br>(출력이 흔들리는 경우 늘려서 평균 품질을 확인) |
| client | None | 사용할 LangSmith Client<br>(None: 환경변수 API 키 기준 기본 Client 사용) |
| blocking | True | 평가 완료까지 코드 실행을 기다릴지 여부 |

- 주요 리턴값

| Return | Deafault | Description |
|---|---|---|
| key | 필수 | 평가 차원을 구분하는 식별자<br>(같은 key는 대시보드에서 하나의 지표로 집계) |
| score | None | 수치 점수<br>(이진(0/1) 또는 연속(0.0~1.0)으로 사용) |
| value | None | 카테고리 라벨 문자열<br>(score와 함께 또는 대신 사용 가능) |
| comment | None | 점수 근거나 짧은 메모.<br>(디버깅 시 활용) |


### Prompt Management
- LangSmith Hub에서 프롬프트를 중앙 집중적으로 등록·버전 관리·공유하고, 코드에서는 이름으로 가져와 사용하도록 만드는 **LangSmith의 운영 기능**
- 프롬프트를 코드안에 고정적인 존재가 아닌 LangSmith Hub에서 독립적으로 관리
- 구성
	- Prompt: 이름이 붙은 프롬프트(본문 텍스트 또는 메시지 묶음과 입력 변수 구조
	- Version: Prompt 변경 이력(같은 이름으로 새 프롬프트를 push하면 새 버전 생성)
	- Tag: 특정 버전 지칭 라벨(운영 환경 또는 검증 단계를 구분)
	- Visibility: Prompt 공개 범위(워크스페이스 내부 오직 사용 / 공개 Hub에서 공유)
