# LangChain

## LangSmith
- **LangChain** 기반 LLM 애플리케이션의 실행과정을 추적하고, 응답 품질을 평가하며, 프롬프트를 버전관리하는 **운영 평가 플랫폼**(운영시 관찰 및 개선을 위한 도구)
  -> 블랙박스 같은 LLM 전반의 각 실행 과정을 Run 단위로 기록하고, 각 단계의 입력·출력·지연 시간·토큰 사용량을 트리 구조로 출력
- 사용이유
	- 각 단계 입력·출력·비용·지연을 자동으로 추적 및 집계
  	- 변경 사항이 답변 품질에 미치는 영향을 정량적으로 평가
 
- 플랫폼 사이트
	- https://apac.smith.langchain.com    

### Tracing
-  LangChain 체인의 실행 흐름의 각 단계 입력·출력·지연 시간·토큰 사용량을 트리 구조로 보여 주는 **LangSmith의 추적 기능**( LangChain 체인이 실행될 때 내부 변화를 알기위한 기능)
- 사용이유: 답변 품질 저하, 비용 증가, 응답 지연의 원인을 찾기 위해서
- 실행기록
	- Trace: 체인 하나의 실행 전체
	- Run: Trace 내부의 하나의 실행 단위
	- Span: Run 내부의 세분화된 하나의 실행 단위   
- 사용방법
	- 세팅: LANGSMITH_TRACING = "true"
	- chain밖의 python 함수 추적도 포함시키고 싶으면 @traceable 데코레이터 사용
- 플랫폼 주 확인 항목
	- Latency : 각 단계 실행 시간
  	- Tokens: 모델 호출에 사용된 토큰 수
  	- Input/Output: 각 단계 입력값/출력값
  	- Erros: 실패한 Run 표기(실패 단계 추적 가능)  

### Dataset
- LLM 애플리케이션을 반복적으로 펑가하기위한 기준 데이터
- 사용이유
	- 결과에 대한 영향을 반복 검증
 	- 실패 사례 재방지 
- 구성
	- Dataset: 평가 데이터(Example 묶음)
 	- Example: Dataset 내부의 하나의 평가 항목(inputs : outputs = 질문리스트 : 기대 답변 리스트)
  	- Version: Dataset 변경 이력

### Evaluator
- LLM 모델의 실제 출력과 기대 출력을 기준에 따라 비교하고, 점수와 코멘트를 반환하는 평가 함수
- 실제 출력(답변)이 기대 출력(답변)과 얼마나 일치하는지 판단
- 종류
	- LLM 평가: LLM이 비교 및 점수 평가(LLM 호출 비용 발생)
	- 휴리스틱: 사람이 작성한 코드 규칙 기반 평가
 	- 임베딩 유사도: 벡터화해서 유사도 계산 
  	- 직접적인 사람평가: LangSmith 대시보드에서 직접 점수 평가 또는 코멘트
