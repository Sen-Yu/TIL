# LangChain
- LLM과 어플리케이션을 연결해주는 에어전틱 프레임워크입니다.
->  다양한 기능을 표준화한 컴포넌트들을 개발자가 선택 및 연결해서 사용하는 프레임워크


## 한줄정리
LLM과 어플리케이션을 연결해주는 에어전틱 프레임워크입니다. 다양한 기능을 표준화한 컴포넌트들을 개발자가 선택 및 연결해서 사용하게 해줍니다. 사용이유는 표준화된 컴포넌트 조립으로 개발시간과 반복적인 기능을 줄이기위해서입니다.

LCEL 파이프(|) 연산자로 컴포넌트들을 선언적으로 구성하는 LangChain의 핵심 문법 체계입니다. 사용이유는 하드코딩은 별도 기능마다 함수 호출하는 방식이여서 새로운 기능추가시 호출순서를 분석하고 직접 삽입해야합니다. 반면 파이프 연산자만으로 코드 구조를 단순히하고 기능변경및 확장 재사용이 안정적이기때문입니다.

프롬프트 구성에 사용되는 컴포넌트에는 프로픔트에 변수를 주입하게해주는 PromptTemplate 클래스, 해당 주입 기능을 유지하면서 Chatmodel이 요구하는 메시지 구조를 같이만드는 ChatPromptTemplate 클래스, 소수의 입출력 예시를 프롬프트에 자동 삽입해서 LLM이 원하는 형식과 패턴으로 응답을 유도하는 FewShotPromptTemplate클래스 , ChatPromptTemplate 안에서 메세지 삽입 위치를 지정하는 MessagesPlaceholder 클래스가 있습니다. 

출력 구조화에 사용되는 컴포넌트에는 출력을 구조화하는 Structured Output클래스, LLM 텍스트 응답을 JSON 형태로 파싱하는 JsonOutputParser 클래스, LLM 텍스트 응답을 Pydantic모델 인스터스로 파싱하는 PydanticOutputParser 클래스가 있습니다. 
LCEL의 구성이되는 컴포넌트는 가장 기본적인 Runnable Interface, 체인안에서 입력을 변형시키지 않고 원형 그대로 통과시키는 RunnablePassthrough ,체인안에서 여러 실행을 병렬적으로 배치하는 RunnableParallel, 조건에 맞는 Runnable 하나만 사용하는 RunableBranch가 있습니다.

대화이력처리의 컴포넌트에는 LCEL 체인을 래핑해서 세션ID를 기준으로 대화 이력을 자동불러오는 RunnableWithMessageHistory가 있습니다.

문서 로당에서는 TextLoader,PyPDFLoader,WebBaseLoader,DiretoryLoader가 있습니다.
