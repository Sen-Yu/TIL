# NLP

## 전통적인 언어 모델

### 언어 모델(Language Model)
- 다음 단어가 나타날 확률을 기반으로 계산하는 모델(등장 패턴과 순서를 학습)
- 단점: 학습이 안된 새로운 단어는 출력하지 못함
- SLM: 통계적 언어모델(빈도주의)
- NNLM: 베이즈(블랙스완,없는 단어 출력가능)

### N-gram Language Model
- n-1개 단어가 주어졌을 때, n번째 단어가 나타날 확률을 빈도 기반으로 계산하는 모델
- 사용이유: 복잡하지 않은 신경망, 통계 기반

### 형태소 분석 (Morphological Analysis)
- 문장을 가장 작은 단위인 형태소로 나누는 전처리
- 사용이유: 단어의 의미와 문법 기능(조사,어미,...)을 분리해서 일관성있는 단위로 처리하기 위해서
- 예시
  먹었다 -> 먹 + 었 + 다 (동작 + 과거 + 종결)
  worked -> work + -ed (동작 + 과거) , cars -> car + -s (명사 + 복수)


## RNN 기초

### RNN (Recurrent Neural Network)
- 이전 시점(과거)의 계산 부분(hidden state)을 다음 시점(현재) 계산에 다시 사용하며, 순차 데이터를 처리하는 순화구조의 인공신경망
- 유래: 언어의 순서는 시간과 관련있음
- hidden state: 레이어의 과거 현재 미래 등 시간에 따른 상태(기억 벡터)
- 셀: RNN 레이어에서 각 시간 단위에서 한 번씩 수행되는 계산 단위
- 언롤링: 반복되는과정을 펼친 과정
- 수식

$$
h_t = f(W_h h_{t-1} + W_x x_t)
$$

- **w**: 가중치(weight)로, 입력과 이전 상태가 얼마나 반영될지를 결정하는 학습 가능한 파라미터
- **𝓧**: 입력 값(input) 또는 입력 벡터
- **t**: 시간(time) 또는 시점(time step)을 나타내는 인덱스
- x_t: 현재 시점의 입력 벡터
- h_{t-1}: 이전 시점의 hidden state
- **h_t: 현재 시점의 hidden state**
- W_h, W_x: 학습 가능한 가중치 행렬
- f: 활성화 함수
