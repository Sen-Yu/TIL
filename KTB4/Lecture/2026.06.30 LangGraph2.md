# LangGraph

## Persistence
- 랭그래프의 state 정보를 유지하는 기능(state를 실행 이후에도 유지)
- ~thread_id~: 실행흐름 구분 
- 코드 예제

~~~
## 1. 체크포인터 연결
graph = builder.compile(checkpointer=<체크포인터>)

## 2. thread_id 전달
graph.invoke(<입력>, config={"configurable": {"thread_id": "<세션 식별자>"}})

## 3. 체크포인터 그래프 실행시 config 전달
result = graph.invoke(<입력>, config)

## 4. 현재 상태와 실행 이력 조회
current = graph.get_state(config)
history = graph.get_state_history(config)

~~~

### Checkpointer
- Persistence를 동작 및 저장하는 인터페이스
