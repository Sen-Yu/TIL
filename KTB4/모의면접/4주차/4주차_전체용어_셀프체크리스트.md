## 📂 1. 머신러닝 데이터 전처리 & 품질 (17개)

- [ ] **단조 변환 (Monotonic Transformation):** "단조 변환이란 무엇이며, 왜 결정 트리는 단조 변환에 불변인가요?"  
  *(👉 대소 순서를 보존하는 변환(로그, 100 곱하기 등). 트리는 순서 기반 분할만 하므로 분할 기준점 숫자만 바뀔 뿐 트리 구조와 결과는 100% 동일)*
- [ ] **마진 (Margin):** "SVM에서 마진이란 무엇이며, 스케일링을 안 하면 왜 마진이 왜곡되나요?"  
  *(👉 결정 경계와 서포트 벡터 사이의 최단 유클리드 거리. 단위가 큰 피처가 거리를 독점하여 마진 계산을 지배함)*
- [ ] **스케일 불변성 (Scale Invariance):** "스케일 불변성을 가진 모델과 가지지 못한 모델의 대표적 예시는?"  
  *(👉 불변: 결정트리, RF, XGBoost, Naive Bayes. 종속: SVM, KNN, K-Means, PCA, 신경망, Ridge/Lasso)*
- [ ] **조건수 (Condition Number):** "경사하강법에서 손실 지형의 조건수가 크다는 것은 무엇을 의미하나요?"  
  *(👉 최대 곡률과 최소 곡률의 비율. 조건수가 클수록 손실 지형이 길쭉한 타원형 계곡이 되어 진동이 심해지고 수렴이 지연됨)*
- [ ] **정규화 (Min-Max Scaling):** "Min-Max 스케일링의 수식과, 이상치가 있을 때 발생하는 치명적 결함은?"  
  *(👉 $\frac{x - x_{\min}}{x_{\max} - x_{\min}}$. 최댓값에 극단치가 있으면 정상 데이터 99%가 0 근처 좁은 구간으로 뭉개져 변별력 상실)*
- [ ] **표준화 (Z-score Standardization):** "Z-score 공식과, 이상치가 많을 때 Z-score 역시 무력한 이유는?"  
  *(👉 $\frac{x - \mu}{\sigma}$. 평균과 표준편차 자체가 이상치 1개에 크게 왜곡되므로 정상 데이터가 여전히 한 점으로 뭉개짐)*
- [ ] **사분위수 범위 (IQR, Interquartile Range):** "IQR의 정의와 통계적 장점은?"  
  *(👉 $Q_3(75\%) - Q_1(25\%)$. 양 끝 극단치가 아무리 커져도 가운데 50% 데이터 간격은 변하지 않는 강건성)*
- [ ] **RobustScaler:** "RobustScaler가 이상치에 강건한 원리와 한계는?"  
  *(👉 중앙값(50%)을 빼고 IQR로 나눔. 극단치에 흔들리지 않으나 이상치 자체가 사라지는 것은 아니므로 별도 클리핑/처리 필요)*
- [ ] **붕괴점 (Breakdown Point):** "평균/표준편차와 중앙값/IQR의 Breakdown point는 각각 얼마인가요?"  
  *(👉 평균/최댓값: $1/N \approx 0\%$ (단 1개로 파괴). 중앙값: $50\%$, IQR: $25\%$)*
- [ ] **윈저화 / 클리핑 (Winsorizing / Clipping):** "이상치 클리핑이란 무엇인가요?"  
  *(👉 상위/하위 극단값을 특정 백분위수(예: 1%, 99%)나 IQR 1.5배 경계값으로 강제 대체하여 극단값을 완충)*
- [ ] **분산 과소추정 (Variance Underestimation):** "결측치를 평균으로 단순 대체할 때 발생하는 통계적 오류는?"  
  *(👉 동일한 평균값이 대량 복제되어 데이터의 실제 퍼짐(분산)이 인위적으로 축소되고 상관관계가 0 쪽으로 약화됨)*
- [ ] **MCAR (Missing Completely at Random):** "완전 무작위 결측(MCAR)의 정의와 행 삭제 시 편향 여부는?"  
  *(👉 결측 여부가 관측값 및 결측값과 완전히 무관(커피 쏟음). 행을 삭제해도 표본 편향이 발생하지 않음)*
- [ ] **MAR (Missing at Random):** "조건부 무작위 결측(MAR)의 정의는?"  
  *(👉 결측 여부가 결측된 값 자체와는 무관하지만, 다른 관측된 변수(예: 성별에 따른 체중 결측)로 설명 가능한 경우)*
- [ ] **MNAR (Missing Not at Random):** "비무작위 결측(MNAR)이 가장 위험한 이유와 데이터만으로 구분 불가한 이유는?"  
  *(👉 결측된 값 자체 때문에 결측 발생(고소득자의 소득 미응답). 결측된 데이터가 없으므로 데이터 자체로 검정 불가, 도메인 추론 필요)*
- [ ] **MICE (Multivariate Imputation by Chained Equations):** "MICE가 단순 단일 대체보다 우수한 통계적 이유는?"  
  *(👉 연쇄 방정식을 통해 여러 개의 대체 데이터셋을 생성하고, 데이터셋 간 분산까지 합쳐 불확실성을 정직하게 보존(다중 대체))*
- [ ] **결측 지시자 컬럼 (Missingness Indicator):** "MNAR 결측에 대응하는 가장 효과적인 실무 전처리 트릭은?"  
  *(👉 결측값을 중앙값 등으로 채우되, 옆에 결측 여부(1/0)를 기록하는 별도 지시자 컬럼을 추가하여 결측 자체의 패턴을 학습시킴)*
- [ ] **데이터 누수 (Data Leakage) & 3대 유형:** "데이터 누수란 무엇이며, 3대 유형(전처리/타겟/분할)의 차이는?"  
  *(👉 테스트셋 정보가 학습에 흘러들어가는 현상. 스케일러 전체 fit(전처리), 정답의 통계가 피처에 포함(타겟), 동일 환자 분할(분할))*

## 📂 2. 데이터 증강 & 컴퓨터 비전 기초 (18개)

- [ ] **이동 불변성 (Translation Invariance):** "이동 불변성의 정의와 분류 작업에서 이것이 중요한 이유는?"  
  *(👉 입력 객체가 이미지 내 어디로 이동하든 출력 클래스 판단이 변하지 않는 성질($f(g(x)) = f(x)$))*
- [ ] **이동 등변성 (Translation Equivariance):** "합성곱 계층이 이동 등변성을 갖는다는 것의 수학적 의미는?"  
  *(👉 입력을 이동시키면 특성 맵 출력도 정확히 같은 위치만큼 이동하여 나타남($f(g(x)) = g(f(x))$))*
- [ ] **결정 경계 평활화 (Decision Boundary Smoothing):** "데이터 증강이 과적합을 막고 일반화를 돕는 기하학적 원리는?"  
  *(👉 데이터가 희소한 빈 공간을 가상 변형 데이터로 채워 경계면이 뾰족하지 않고 둥글고 매끄럽게 형성되도록 유도)*
- [ ] **VRM (Vicinal Risk Minimization, 근방 위험 최소화):** "VRM 관점에서 데이터 증강을 정의하면?"  
  *(👉 관측된 한 점만 정답으로 보는 대신, 그 점 주변 근방(Vicinity)의 변형된 데이터도 같은 정답으로 간주하여 학습하는 이론)*
- [ ] **Mixup & CutMix:** "Mixup과 CutMix의 차이점과 공통 효과는?"  
  *(👉 Mixup은 픽셀 전체 선형 보간, CutMix는 패치 잘라붙이기(면적비 라벨). 공통으로 소프트 라벨을 통한 모델 과신 방지 및 경계 완화)*
- [ ] **레이블 보존 변환 (Label-preserving Transformation):** "증강 설계 시 가장 중요한 황금률은?"  
  *(👉 변환된 이미지를 사람이 보아도 원래의 정답 레이블과 100% 일치해야 함)*
- [ ] **의미론적 역전 (Semantic Inversion):** "숫자 인식에서 180도 회전이나 좌우 반전이 치명적인 이유는?"  
  *(👉 180도 회전 시 6이 9로 변하고, 좌우 반전 시 현실에 없는 거울 문자가 되어 레이블과 데이터의 의미가 완전히 왜곡됨)*
- [ ] **탄성 왜곡 (Elastic Distortion):** "손글씨(MNIST)에 매우 효과적인 탄성 왜곡이란?"  
  *(👉 고무판처럼 국소적으로 늘였다 줄이는 불균일 변형으로, 사람 손 떨림과 획 변형을 모사하는 안전한 레이블 보존 증강)*
- [ ] **TTA (Test-Time Augmentation):** "TTA의 작동 메커니즘과 장단점은?"  
  *(👉 테스트 이미지 1장에 여러 변환을 적용해 N개 예측 확률을 평균(Soft Voting). 1~2% 성능 향상되나 추론 연산/지연이 N배 증가)*
- [ ] **결정적 전처리 vs 무작위 증강:** "검증/테스트 데이터셋에서 꺼야 하는 것과 남겨야 하는 것은?"  
  *(👉 무작위 증강(랜덤 크롭, 반전)은 평가 재현성을 위해 끄고, 결정적 전처리(리사이즈, 중앙 크롭, 표준화)는 Train과 동일하게 유지)*
- [ ] **국소 연결성 (Local Connectivity):** "CNN이 FC 대비 파라미터를 획기적으로 줄이는 첫 번째 연결 원리는?"  
  *(👉 뉴런이 입력 전체가 아닌 필터 크기($K \times K$)만큼의 국소 영역(수용 영역)에만 연결됨)*
- [ ] **파라미터 / 가중치 공유 (Weight Sharing):** "CNN의 두 번째 파라미터 절감 원리는?"  
  *(👉 하나의 동일한 필터 가중치를 이미지 전체 공간을 슬라이딩하며 재사용함)*
- [ ] **귀납적 편향 (Inductive Bias):** "CNN이 이미지 데이터에 대해 갖는 고유한 귀납적 편향은?"  
  *(👉 가까운 픽셀끼리 강한 상관관계를 가지며(Spatial Locality), 패턴의 특징은 위치에 무관하게 동일하다(Translation Equivariance))*
- [ ] **출력 차원 산술 공식:** "입력 $W$, 커널 $K$, 패딩 $P$, 스트라이드 $S$일 때 출력 크기 $O$ 공식은?"  
  *(👉 $O = \lfloor \frac{W - K + 2P}{S} \rfloor + 1$)*
- [ ] **Same Padding vs Valid Padding:** "Same Padding의 패딩 크기 $P$ 공식과 Valid Padding의 의미는?"  
  *(👉 Same: 출력 크기를 입력과 같게 유지($P = \frac{K-1}{2}$, $S=1$ 기준). Valid: 패딩 없음($P=0$))*
- [ ] **풀링 (Max Pooling vs Average Pooling):** "두 풀링의 추출 특징 차이는?"  
  *(👉 Max: 에지, 질감 등 가장 강한 활성화 신호 추출. Average: 전반적인 배경/평균적 신호 평활화)*
- [ ] **공간 좌표 소실 & 캡슐 네트워크:** "풀링에 대한 힌튼 교수의 비판 요지는?"  
  *(👉 풀링은 위치 불변성을 얻는 대신 객체 부품들의 정밀한 공간 좌표와 상대적 기하 관계(파트-전체 관계)를 영구 파괴함)*
- [ ] **$3\times3$ 필터 적층 효과:** "$3\times3$을 3개 쌓는 것이 $7\times7$ 1개보다 우수한 2가지 이유는?"  
  *(👉 1. 동일 수용영역($7\times7$) 대비 파라미터 약 45% 절감($49C^2 \to 27C^2$), 2. 비선형 활성화 함수를 3회 중첩하여 표현력 극대화)*

## 📂 3. 최적화 기하학 & 알고리즘 (18개)

- [ ] **그레디언트 벡터 ($\nabla f$):** "다변수 함수에서 그레디언트 벡터가 가리키는 기하학적 의미는?"  
  *(👉 함수값이 가장 가파르게 증가하는 방향(최급 상승 방향, Steepest Ascent)과 그 순간 변화율 크기)*
- [ ] **최급 하강 방향 ($-\nabla f$):** "방향 미분계수 내적 식에서 왜 $-\nabla f$ 방향이 최급 하강 방향인가요?"  
  *(👉 $D_u f = \|\nabla f\|\cos\theta$에서 $\theta = \pi$일 때 $\cos\theta = -1$로 가장 작은 음의 변화율 도출)*
- [ ] **1차 테일러 선형 근사:** "경사하강법이 전제하는 수학적 가정의 한계는?"  
  *(👉 현재 위치 아주 가까운 미소 국소 영역이 평평한 평면이라는 1차 테일러 근사에 기반함)*
- [ ] **헤시안 행렬 (Hessian Matrix):** "헤시안 행렬이란 무엇이며 오차 표면에서 어떤 역할을 하나요?"  
  *(👉 모든 2차 편미분계수로 구성된 $N \times N$ 정사각 대칭 행렬로, 손실 표면의 국소적 곡률(Curvature)을 표현)*
- [ ] **과대 학습률 발산 조건:** "2차 테일러 전개 관점에서 손실이 발산하는 수리적 임계 조건은?"  
  *(👉 학습률이 헤시안 행렬 최대 고윳값의 역수 한계($\eta > \frac{2}{\lambda_{\max}}$)를 초과할 때 2차 곡률 항이 1차 감소 항을 압도하여 발산)*
- [ ] **뉴턴 방법 (Newton's Method):** "뉴턴 방법이 딥러닝에서 쓰이지 못하는 물리적 이유는?"  
  *(👉 $N$개 파라미터에 대해 $N \times N$ 헤시안 행렬의 저장 불가 및 $O(N^3)$ 역행렬 계산 비용 감당 불가)*
- [ ] **그레디언트 분산 (Gradient Variance):** "미니배치 크기 $B$와 그레디언트 추정 분산의 관계는?"  
  *(👉 분산은 배치 크기 $B$에 반비례($\operatorname{Var} \propto 1/B$). 배치가 작을수록 흔들림이 심함)*
- [ ] **안장점 (Saddle Point):** "고차원 손실 공간에서 로컬 미니마보다 안장점이 문제인 이유와 미니배치의 역할은?"  
  *(👉 기울기가 0이지만 최솟값이 아님. BGD는 멈추거나 느려지지만 미니배치의 확률적 노이즈가 안장점을 탈출시킴)*
- [ ] **Flat Minima vs Sharp Minima:** "일반화 관점에서 Flat Minima가 유리한 이유는?"  
  *(👉 Sharp는 좁은 바늘구멍이라 테스트 데이터 이동 시 오차 폭발. Flat은 완만한 대야형이라 데이터 분포 이동에 강건)*
- [ ] **Linear Scaling Rule & Warmup:** "배치를 $k$배 키웠을 때 학습률 조정 규칙은?"  
  *(👉 학습률도 $k$배 비례 증가시키고($\eta \to k\eta$), 초반 불안정성을 방지하기 위해 Warmup을 필수로 적용(Goyal 2017))*
- [ ] **Critical Batch Size:** "임계 배치 크기란 무엇인가요?"  
  *(👉 여기까지는 배치를 키우면 필요한 스텝 수가 줄지만, 이 한계를 넘으면 배치를 더 키워도 스텝 수가 줄지 않아 연산만 낭비되는 지점)*
- [ ] **LRFinder (학습률 탐색기):** "LRFinder 곡선에서 최적 기본 학습률로 선택해야 하는 지점은?"  
  *(👉 손실 최솟점이 아니라, 손실이 가장 가파르게 떨어지는 최대 하강 기울기(Steepest slope) 지점)*
- [ ] **코사인 어닐링 (Cosine Annealing):** "코사인 스케줄러의 동작 특성은?"  
  *(👉 학습률을 코사인 함수 반주기 곡선을 따라 부드럽게 감속시켜, 미세 최적점에 매끄럽게 안착시킴)*
- [ ] **지수이동평균 (EMA):** "모멘텀 및 Adam에서 최근 $N$개 평균을 반영하는 메커니즘은?"  
  *(👉 과거 값을 기하급수적으로 감쇠하며 최근 값에 가중치를 부여. 감쇠율 0.9면 약 10개, 0.999면 약 1000개 이동평균)*
- [ ] **1차 모멘트 ($m_t$, Momentum):** "Adam의 1차 모멘트 역할은?"  
  *(👉 기울기의 지수이동평균으로 관성을 부여하여 지그재그 진동을 상쇄하고 내리막 방향 가속)*
- [ ] **2차 모멘트 ($v_t$, RMSProp):** "Adam의 2차 모멘트 역할은?"  
  *(👉 기울기 제곱의 지수이동평균으로, 기울기가 큰 파라미터는 보폭을 좁히고 작은 파라미터는 넓히는 적응형 학습률)*
- [ ] **편향 보정 (Bias Correction):** "초기 편향 보정이 없을 때 Adam 스텝이 폭증하는 구체적 이유는?"  
  *(👉 $m$과 $v$를 0으로 초기화하여 $v$가 1000배, $m$이 10배 축소됨 $\to$ 비율 $\frac{m}{\sqrt{v}}$가 초반 약 3배 과대해져 스텝 폭증)*
- [ ] **AdamW (Decoupled Weight Decay):** "기존 Adam의 L2 규제 버그와 AdamW의 해결책은?"  
  *(👉 손실에 L2를 넣으면 규제항마저 2차 모멘트($\sqrt{v}$)로 나뉘어 중요 가중치 감쇠가 약화됨 $\to$ 가중치 감쇠를 모멘트 계산에서 완전히 분리해 직접 차감)*

## 📂 4. 신경망 역전파 & 학습 안정화 (16개)

- [ ] **오차 신호 ($\delta$, Error Signal):** "역전파에서 오차 신호 $\delta_l$의 수학적 정의는?"  
  *(👉 손실 $L$의 $l$번째 층 선형 결합 입력 $z_l$에 대한 편미분 벡터 ($\delta_l = \frac{\partial L}{\partial z_l}$))*
- [ ] **아다마르 곱 (Hadamard Product, $\odot$):** "역전파 수식에서 아다마르 곱이 쓰이는 곳은?"  
  *(👉 역전파 오차 신호에 활성화 함수의 미분계수를 원소별로 곱할 때 ($\delta_l = (W_{l+1}^T \delta_{l+1}) \odot \sigma'(z_l)$))*
- [ ] **외적 (Outer Product, $\delta a^T$):** "가중치 행렬 기울기 계산에 외적이 쓰이는 이유는?"  
  *(👉 $\frac{\partial L}{\partial W} = \delta a^T$. 오차 신호 벡터와 이전 층 활성값 벡터의 외적으로 전체 가중치 행렬 차원 도출)*
- [ ] **활성화 캐싱 (Activation Caching):** "역전파를 위해 순전파 시 메모리에 반드시 저장해 두어야 하는 값은?"  
  *(👉 각 층의 선형 결합 $z$와 활성화 출력 $a$. 이 값들이 없으면 연쇄 법칙의 미분계수를 계산할 수 없음)*
- [ ] **기울기 소실 (Vanishing Gradient):** "역전파 연쇄곱 관점에서 기울기 소실이 발생하는 수학적 수식 형태는?"  
  *(👉 $\prod_{j=l+1}^L W_j^T \operatorname{diag}(\sigma'_j(z_j))$. 1보다 작은 미분계수와 가중치가 수십 번 거듭제곱되어 앞단 기울기가 0으로 소멸)*
- [ ] **기울기 폭주 (Exploding Gradient):** "기울기 폭주 현상의 원인과 RNN 등에서의 주요 대응책은?"  
  *(👉 가중치 행렬의 고윳값이 1보다 커서 연쇄곱 결과가 무한대로 발산 $\to$ 기울기 노름 상한을 두는 기울기 클리핑(Gradient Clipping))*
- [ ] **기울기 포화 (Gradient Saturation):** "시그모이드 활성화 함수의 양 극단에서 발생하는 현상은?"  
  *(👉 입력 $z$가 너무 크거나 작을 때 곡선이 평평해져 미분계수 $\sigma'(z) \to 0$으로 수렴하는 현상)*
- [ ] **Dying ReLU:** "ReLU 활성화 함수에서 뉴런이 영구히 비활성화되는 현상의 원인은?"  
  *(👉 입력이 음수($z \le 0$)가 되면 출력이 0이고 기울기도 0이 되어, 해당 뉴런의 가중치가 더 이상 갱신되지 않고 영구 정지)*
- [ ] **Xavier (Glorot) 초기화:** "Xavier 초기화의 분산 공식과 적합한 활성화 함수는?"  
  *(👉 $\operatorname{Var}(W) = \frac{2}{n_{in} + n_{out}}$ (또는 $\frac{1}{n_{in}}$). 시그모이드, Tanh 등 원점 대칭 선형 영역 활성화에 적합)*
- [ ] **He (Kaiming) 초기화:** "He 초기화 분산이 $\frac{2}{n_{in}}$인 이유는?"  
  *(👉 ReLU가 음수 신호를 절반 버려 출력 분산이 반토막 나는 것을 보상하기 위해 분자 계수를 2로 설정)*
- [ ] **배치 정규화 (Batch Normalization):** "배치 정규화의 미니배치 차원 정규화 방식과 소배치에서의 한계는?"  
  *(👉 동일 미니배치 내 샘플들을 채널별로 평균 0, 분산 1 정규화. 배치 크기가 16 이하로 작으면 통계량이 극도로 흔들려 성능 저하)*
- [ ] **레이어 정규화 (Layer Normalization):** "배치 정규화와 레이어 정규화의 통계량 계산 축 차이는?"  
  *(👉 BN은 배치 축을 따라 샘플 간 통계 계산, LN은 단일 샘플 내부의 피처/채널 축 전체에 걸쳐 통계 계산(NLP/Transformer 표준))*
- [ ] **잔차 연결 (Residual / Skip Connection):** "ResNet 잔차 블록이 기울기 소실을 물리적으로 방지하는 수식 원리는?"  
  *(👉 $H(x) = F(x) + x \implies \frac{\partial H}{\partial x} = \frac{\partial F}{\partial x} + I$. 가중치 미분이 0이어도 항등 행렬 $I(=1)$이 기울기 고속도로를 보장)*
- [ ] **기울기 클리핑 (Gradient Clipping):** "기울기 클리핑 공식의 동작 방식은?"  
  *(👉 전체 그레디언트 벡터의 L2 노름이 임계값 $c$를 초과하면 $g \leftarrow g \times \frac{c}{\|g\|}$로 방향을 유지한 채 크기만 $c$로 강제 축소)*

## 📂 5. 손실 함수 & 확률/정규화 이론 (17개)

- [ ] **평균 제곱 오차 (MSE, Mean Squared Error):** "MSE의 물리적 의미와 가우시안 MLE 간의 관계는?"  
  *(👉 유클리드 거리 오차 제곱의 평균. 오차가 정규분포(가우시안)를 따른다고 가정한 MLE와 정확히 일치하는 회귀 손실 함수)*
- [ ] **크로스 엔트로피 (Cross-Entropy):** "크로스 엔트로피의 정보이론적 의미와 베르누이 MLE 간의 관계는?"  
  *(👉 정답 확률분포 $P$와 예측 확률분포 $Q$ 간의 불일치도 측정. 데이터가 베르누이/다항 분포를 따른다고 가정한 음의 로그 우도(NLL))*
- [ ] **시그모이드 미분계수 성질:** "시그모이드 미분계수를 자기 자신 $\hat{y}$로 표현한 수식은?"  
  *(👉 $\sigma'(z) = \hat{y}(1 - \hat{y})$)*
- [ ] **MSE + Sigmoid 학습 마비:** "분류에 MSE를 썼을 때 심각한 오답 확신($\hat{y}=0.001, y=1$)에서 생기는 문제는?"  
  *(👉 $\frac{\partial L}{\partial z} = (\hat{y}-y)\hat{y}(1-\hat{y})$. 뒤의 미분계수가 $0.000999$가 되어 최종 기울기가 $0.000998$로 소실, 가중치 갱신 마비)*
- [ ] **약분 소거 (Cancellation):** "BCE 미분 시 시그모이드 미분계수가 사라지는 수리적 과정은?"  
  *(👉 $\frac{\partial L}{\partial \hat{y}} = \frac{\hat{y}-y}{\hat{y}(1-\hat{y})}$에 $\frac{\partial \hat{y}}{\partial z} = \hat{y}(1-\hat{y})$가 곱해져 분모-분자가 완벽히 약분 소거되고 최종 오차 $\mathbf{\hat{y}-y}$만 남음)*
- [ ] **손실 곡면 볼록성 (Convexity):** "로지스틱 회귀에서 MSE와 BCE의 곡면 차이는?"  
  *(👉 MSE는 수많은 로컬 미니마와 안장점을 지닌 비볼록(Non-convex) 지형 형성, BCE는 전역 최적점이 보장되는 볼록(Convex) 지형 형성)*
- [ ] **최대우도추정 (MLE, Maximum Likelihood Estimation):** "우도(Likelihood)와 최대우도추정의 개념은?"  
  *(👉 주어진 파라미터 하에서 관측된 표본들이 발생할 결합 확률을 최대화하는 파라미터를 찾는 통계적 추정법)*
- [ ] **음의 로그 우도 (NLL, Negative Log-Likelihood):** "왜 우도에 음의 로그를 취해 손실 함수로 바꾸나요?"  
  *(👉 결합 확률의 곱셈 연산을 덧셈 연산으로 변환해 언더플로우를 방지하고, 우도 최대화 문제를 경사하강법 최소화 문제로 변환)*
- [ ] **KL 발산 (Kullback-Leibler Divergence):** "크로스 엔트로피 최소화가 KL 발산 최소화와 동치인 이유는?"  
  *(👉 $H(P, Q) = H(P) + D_{KL}(P \parallel Q)$. 실제 정답의 엔트로피 $H(P)$는 고정된 상수이므로 크로스 엔트로피를 최소화하는 것은 두 분포 사이의 KL 거리를 0으로 좁히는 것과 동일)*
- [ ] **LogSumExp 트릭:** "PyTorch `nn.CrossEntropyLoss`가 Softmax와 NLLLoss를 합쳐 연산하는 수치적 이유는?"  
  *(👉 큰 입력의 지수 오버플로우와 $\log(0)$ 언더플로우를 방지하기 위해 최댓값을 감산하는 Log-Softmax 트릭 적용)*
- [ ] **L1 정규화 (Lasso):** "L1 정규화의 손실 함수 페널티 수식과 가중치 갱신 식은?"  
  *(👉 $\lambda \sum |w_i|$, 갱신: $w_{t+1} = w_t - \eta \nabla L - \eta\lambda\operatorname{sign}(w)$ (상수 감산))*
- [ ] **L2 정규화 (Ridge / Weight Decay):** "L2 정규화의 손실 함수 페널티 수식과 가중치 갱신 식은?"  
  *(👉 $\frac{1}{2}\lambda \sum w_i^2$, 갱신: $w_{t+1} = w_t(1 - \eta\lambda) - \eta \nabla L$ (비례 감쇠))*
- [ ] **희소성 (Sparsity) & 피처 선택:** "L1이 변수 선택(Feature Selection) 효과를 내는 기작은?"  
  *(👉 가중치가 작든 크든 일정한 크기($\eta\lambda$)를 계속 빼주므로 불필요한 가중치가 정확히 0으로 수렴하여 피처 자동 제거)*
- [ ] **제약 영역 기하학:** "왜 L1만 축 위에서 접하고, L2는 0이 되지 않는가?"  
  *(👉 L1 제약 영역은 축 위에 뾰족한 꼭짓점을 가진 마름모(다포체)라 등고선 타원이 꼭짓점과 만날 확률이 압도적. L2는 매끄러운 구라 특정 축 위에서 접할 편향이 없음)*
- [ ] **라플라스 사전분포 vs 가우시안 사전분포:** "베이지안 관점(MAP)에서 L1과 L2의 차이는?"  
  *(👉 L1은 0 지점에서 뾰족한 첨도를 가진 라플라스 사전분포 가정. L2는 원점 중심의 완만한 가우시안 사전분포 가정)*
- [ ] **다중공선성 (Multicollinearity) 시 L1 vs L2 동작:** "상관관계가 매우 높은 두 변수가 있을 때 두 모델의 거동은?"  
  *(👉 L1은 둘 중 무작위로 하나만 선택하고 나머지를 0으로 날려 통계적 불안정 초래. L2는 두 가중치를 동일한 크기로 균등하게 축소)*
- [ ] **ElasticNet:** "ElasticNet이 고안된 배경과 수식 형태는?"  
  *(👉 L1의 희소성(피처 선택)과 L2의 다중공선성 안정성을 결합하기 위해 두 규제를 모두 더함 ($\lambda_1 \|w\|_1 + \lambda_2 \|w\|_2^2$))*
