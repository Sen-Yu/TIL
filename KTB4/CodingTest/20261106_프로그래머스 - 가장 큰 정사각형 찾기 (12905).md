# 프로그래머스 - 가장 큰 정사각형 찾기 (12905) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12905

## 문제 요약
- 1과 0으로 채워진 표 `board`가 주어진다. (행, 열의 크기는 각각 최대 1,000)
- 표에서 **1로만 이루어진 가장 큰 정사각형**을 찾아 그 **넓이**를 반환한다.
- 가로·세로가 평행한 정사각형만 대상이며, 대각선(다이아) 모양은 제외한다.
- 행과 열의 크기가 서로 다를 수 있다.

## 아이디어

### 시도 1: 완전탐색 — 시간초과
- 값이 1인 칸을 시작점으로 잡고, 오른쪽·아래·오른쪽 아래 칸을 확인한다.
- 전부 1이면 정사각형을 한 칸씩 키워가며 같은 방식으로 반복한다.
- 다음 확장이 표 범위를 벗어나거나 0을 만나면 거기까지를 정사각형 크기로 기록한다.
- 정사각형 한 변의 최대 크기는 `min(행, 열)`로 제한되지만, 표가 최대 1000×1000이라 모든 칸에서 확장 검사를 하면 효율성 테스트에서 시간초과가 난다.

### 시도 2: 방향을 반대로 — DP
- 완전탐색은 "시작점(왼쪽 위)에서 오른쪽·아래로 뻗어나가는" 방향이었다.
- 반대로 각 칸을 **정사각형의 오른쪽 아래 꼭짓점**으로 보고, **왼쪽·위쪽·왼쪽 위** 세 칸의 값을 확인하면 이미 계산된 결과를 재사용할 수 있다.
- `board[i][j]`를 "이 칸을 오른쪽 아래 꼭짓점으로 하는 가장 큰 정사각형의 한 변 길이"로 정의한다.
- 점화식 (`board[i][j] == 1`이고 `i > 0`, `j > 0`일 때):

```
board[i][j] = min(위, 왼쪽, 왼쪽 위) + 1
```

- 세 칸 중 하나라도 작으면 그 값이 정사각형 크기의 한계를 정하므로 `max`가 아니라 `min`을 쓴다.
- 칸을 채우면서 최댓값(`answer`)을 갱신하고, 마지막에 제곱해서 넓이를 반환한다.

## 처리한 경계 조건
- 첫 행, 첫 열: `i > 0 and j > 0` 조건으로 범위 밖 접근을 막는다. 이 칸들은 원래 값(0 또는 1)이 그대로 한 변 길이가 된다.
- 값이 0인 칸: 정사각형을 만들 수 없으므로 그대로 0을 유지한다.
- 표 전체가 0이면 `answer`가 0이라 `0 ** 2 = 0`을 반환한다.
- 정답은 한 변의 길이가 아니라 **넓이**이므로 마지막에 `** 2`를 해준다.

## 복잡도
- 시간복잡도: 모든 칸을 한 번씩만 보므로 **O(행 × 열)**
- 공간복잡도: 입력 `board`를 그대로 DP 표로 재사용하므로 추가 공간 **O(1)**

## 배운 점
- 완전탐색이 시간초과일 때 "시작점에서 뻗어나가는 방향"을 "끝점에서 이미 계산한 값을 모으는 방향"으로 뒤집으면 DP로 풀리는 경우가 있다.
- 정사각형 문제는 `min(위, 왼쪽, 왼쪽 위) + 1`이라는 점화식 하나로 정리된다. 세 이웃 중 가장 작은 값이 만들 수 있는 정사각형의 한계를 정한다.
- 입력 배열을 DP 표로 직접 재사용하면 별도 배열 없이 공간을 아낄 수 있다. 다만 입력이 변경되므로 원본이 필요하면 복사해서 써야 한다.
- 코드에서 `row = len(board[0])`, `column = len(board)`로 이름을 붙였는데, 실제로는 `row`가 열의 개수이고 `column`이 행의 개수라 의미가 뒤바뀌어 있다. 결과에는 영향이 없지만 `n = len(board)`, `m = len(board[0])`처럼 헷갈리지 않는 이름이 낫다.

## 최종 코드

```python
"""
다이아 제외, row와 column은 작을 수 있다.

사각형크기 시작점: row와 column 작은 값
board 값의 루트값, 버림값


값이 1이라면 현재위치기준 오른쪽과 하단, 오르쪽하단 확인하기 -> 전부 1이면 방문한곳전부 동일하게 시도 
-> 다음시도가 크기를 벗어나거나 0이면 현재까지 정상 방문한곳은 전부 방문걸음으로 지정
-> 완전탐색법 -> 1000*1000 초과뜸

완전탐색과 반대로 
값이 1이라면 왼쪽,상단,왼쪽상단 값 확인하기 -> dp 사용가능

"""
def solution(board):
    answer = 0
    row = len(board[0])
    column = len(board)
    
    for i in range(column):
        for j in range(row):
            if board[i][j] == 1 and i > 0 and j > 0:
                board[i][j] = min(board[i-1][j], board[i][j-1], board[i-1][j-1]) + 1
            answer = max(answer, board[i][j])
    return answer ** 2
```
