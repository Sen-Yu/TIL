# 프로그래머스 - n진수 게임 (17687) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/17687

## 문제 요약
- `0`부터 시작해서 `1, 2, 3, ...`을 차례로 `n`진법으로 표현한 뒤, 그 숫자들을 이어붙여서 하나의 긴 문자열을 만든다.
- 이 문자열을 `t`명이 순서대로 한 글자씩 돌아가며 읽는다.
- `m`번째 사람(`p`)이 자신의 순서마다 말하게 되는 글자들을 순서대로 이어붙여서 반환한다.

## 아이디어
- 먼저 `n`진법으로 변환된 숫자들을 계속 이어붙여서, `p`번째 사람이 몇 번째 턴까지 필요로 할지에 해당하는 만큼의 충분히 긴 문자열(`zins`)을 미리 만들어 둔다.
- 필요한 최소 길이는 `total_len = m * (t-1) + p`로 계산한다. 이는 전체 사람 수(`t`)만큼 라운드가 돌고, 그중 `p`번째 사람이 말하는 마지막 턴까지의 위치를 나타낸다.
- `0`은 `n`진법 변환 함수 없이 미리 `'0'`으로 넣어두고, `1`부터는 `zinsu` 함수로 `k`진법 변환을 반복하며 문자열을 채운다.
- 문자열이 충분히 길어지면, `p`번째 사람의 턴에 해당하는 인덱스들(`range(p-1, total_len+1, m)`)만 뽑아서 이어붙여 반환한다.

## `zinsu` 함수 — 10진수를 n진법 문자열로 변환
- `n % k`로 나머지를 구하고, `n //= k`로 몫을 갱신하는 과정을 `n`이 0이 될 때까지 반복하는 전형적인 진법 변환 로직이다.
- `10` 이상의 나머지가 나올 수 있는 경우(진법이 11 이상일 때)를 대비해, `10~15`에 해당하는 나머지를 `'A'~'F'` 문자로 매핑해준다.
- 나머지를 구하는 순서상 낮은 자릿수부터 문자열에 쌓이므로, 마지막에 `reversed()`로 뒤집어 올바른 자릿수 순서로 만든다.

## 발생했던 문제
없음. 디버깅을 위해 중간에 값을 확인해본 것 외에는 로직 자체는 처음부터 정확하게 구현되어 바로 통과했다.

## 복잡도
- `zins` 문자열을 `total_len`만큼 채우는 데 필요한 반복 횟수는 최대 `total_len`에 비례하며, 각 반복에서 `n`진법 변환은 값의 자릿수(로그 스케일)만큼의 시간이 걸린다.
- 이후 `p`번째 사람의 턴을 뽑아내는 과정은 `total_len / m`에 비례하는 시간이다.
- 전체적으로 `total_len`에 선형적으로 비례하는 시간복잡도를 가진다.

## 배운 점
- "여러 사람이 순서대로 돌아가며 무언가를 하는" 문제는, 전체를 하나의 순차적인 시퀀스로 먼저 만들어두고, 특정 사람에 해당하는 인덱스만 규칙적인 간격(`range(start, stop, step)`)으로 뽑아내는 방식으로 깔끔하게 표현할 수 있다.
- 진법 변환에서 10 이상의 자릿값을 문자로 매핑하는 처리는, `if/elif` 대신 딕셔너리나 문자열 인덱싱(`"0123456789ABCDEF"[rest]`)으로도 더 간결하게 구현할 수 있는 부분이라 참고할 만하다.

## 최종 코드

```python
def zinsu(n, k):
    zin = ""
    rest = 0
    while n > 0:
        rest = n % k
        if rest == 10:
            rest = 'A'
        elif rest == 11:
            rest = 'B'
        elif rest == 12:
            rest = 'C'
        elif rest == 13:
            rest = 'D'
        elif rest == 14:
            rest = 'E'
        elif rest == 15:
            rest = 'F'
        zin += str(rest)
        n //= k

    return "".join(reversed(zin))

def solution(n, t, m, p):
    answer = ''
    total_len = m * (t - 1) + p
    zins = '01'
    k = 2

    while len(zins) < total_len:
        zins += zinsu(k, n)
        k += 1

    for turn in range(p - 1, total_len + 1, m):
        answer += zins[turn]

    return answer
```
