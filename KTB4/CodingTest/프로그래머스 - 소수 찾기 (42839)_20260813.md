# 프로그래머스 - 소수 찾기 (42839) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42839

## 문제 요약
- 숫자가 적힌 종잇조각을 나타내는 문자열 `numbers`가 주어진다 (예: `"17"`).
- 종잇조각을 몇 장 골라서 순서를 바꿔 만들 수 있는 모든 수 중에서, **소수인 것의 개수**를 구한다.

## 사용한 기법 3가지
이번 풀이는 크게 세 가지 도구를 조합해서 만들어졌다.

1. `itertools.permutations`로 가능한 모든 숫자 조합(순열)을 생성
2. 그 순열들을 정수로 변환한 뒤 최댓값까지 **에라토스테네스의 체**로 소수 맵을 만듦
3. 만들어진 소수 맵으로 각 숫자가 소수인지 O(1)에 판별

## 1. `itertools.permutations`로 순열 생성

```python
from itertools import permutations

pices = [int(n) for n in numbers]
length = len(pices)

all_perms = []
for i in range(length, 0, -1):
    perms = list(permutations(pices, i))
    pers = [int(''.join(map(str, p))) for p in perms]
    all_perms += pers
```

- `numbers`의 각 문자를 숫자로 변환해 `pices` 리스트를 만든다. 예를 들어 `"17"`이면 `pices = [1, 7]`이다.
- `permutations(pices, i)`는 `pices`에서 **순서를 고려해서 i개를 뽑는 모든 경우**를 튜플로 반환한다. 예를 들어 `permutations([1,7], 2)`는 `(1,7)`과 `(7,1)`을 만든다. `permutations([1,7], 1)`은 `(1,)`, `(7,)`을 만든다.
- 이 문제에서는 "몇 장을 골라도 되는" 문제이므로, `i`를 전체 길이(`length`)부터 `1`까지 **거꾸로** 돌리면서 모든 길이의 순열을 다 만들어야 한다. `range(length, 0, -1)`이 그 역할을 한다.
- `''.join(map(str, p))`로 튜플 `(1,7)`을 문자열 `"17"`로 합친 뒤 `int()`로 정수 `17`로 바꾼다. 이렇게 각 길이별 순열을 전부 숫자로 변환해 `all_perms`에 모은다.
- 주의할 점: 앞자리가 `0`인 조합(예: `(0,7)` → `"07"`)도 `int("07")`을 거치면 자동으로 `7`이 되어, 앞자리 0이 자연스럽게 제거된다.

이 단계가 끝나면 `all_perms`에는 만들 수 있는 모든 숫자 조합(중복 포함)이 정수 형태로 모두 담긴다.

```python
all_perms = list(set(all_perms))
all_perms.sort(reverse=True)
```

- 같은 숫자가 여러 경로로 중복 생성될 수 있으므로(`"011"`에서 `1`이 두 번 나오면 `(0,1)`과 `(0,1)`이 서로 다른 위치에서 뽑혀 같은 결과가 나올 수 있음) `set`으로 중복을 제거한다.
- 내림차순으로 정렬해서, `all_perms[0]`이 만들 수 있는 **가장 큰 수**가 되도록 한다. 이 값이 다음 단계에서 에라토스테네스의 체를 만들 때 상한값으로 쓰인다.

## 2. 에라토스테네스의 체(Sieve of Eratosthenes)로 소수 맵 생성

```python
sieve = [True] * (all_perms[0] + 1)
sieve[0] = sieve[1] = False

for i in range(2, int(all_perms[0] ** 0.5) + 1):
    if sieve[i]:
        for j in range(i * i, all_perms[0] + 1, i):
            sieve[j] = False
```

에라토스테네스의 체는 "N 이하의 모든 소수를 한 번에 찾는" 대표적인 방법이다. 숫자 하나하나를 나눠보며 소수인지 확인하는 대신, **배수를 지워나가는 방식**으로 훨씬 빠르게 판별한다.

- `sieve`는 `0`부터 `all_perms[0]`(만들 수 있는 최댓값)까지 크기의 불리언 배열이다. 처음엔 전부 `True`(소수라고 가정)로 채운다.
- `0`과 `1`은 소수가 아니므로 미리 `False`로 지정한다.
- `i`를 `2`부터 `√(최댓값)`까지만 돌리는 이유는, 어떤 수 `N`이 합성수라면 반드시 `√N` 이하의 약수를 하나는 갖기 때문이다. 그보다 큰 `i`는 이미 더 작은 `i`에서 배수 처리가 끝나 있어서 다시 검사할 필요가 없다.
- `sieve[i]`가 아직 `True`(소수로 남아있음)라면, `i`의 배수들(`i*i, i*i+i, i*i+2i, ...`)을 전부 `False`로 지운다. `i*i`부터 시작하는 이유는, `i*2, i*3, ..., i*(i-1)`은 이미 더 작은 소수(`2, 3, ...`)를 처리할 때 지워졌을 것이기 때문이다.
- 이 과정이 끝나면 `sieve[n]`이 `True`인 `n`은 전부 소수, `False`인 `n`은 합성수(또는 0, 1)가 된다.

**왜 이 방식이 빠른가**: 숫자 하나씩 `n % 2 == 0`, `n % 3 == 0`, ... 식으로 나눠보며 소수 판별을 하면, `all_perms`에 있는 수마다 매번 O(√n)의 검사가 필요하다. 반면 에라토스테네스의 체는 **한 번만 O(N log log N)에 전체 구간의 소수 여부를 미리 계산**해두고, 이후에는 배열 조회 한 번(O(1))으로 소수 여부를 알 수 있다. `all_perms`에 같은 수가 여러 번 등장하거나 확인해야 할 수가 많을수록 이 방식이 훨씬 유리하다.

## 3. 소수 개수 세기

```python
prime_numbers = [num for num in all_perms if sieve[num]]
answer = len(prime_numbers)
```

- 만들어진 `sieve` 배열을 이용해, `all_perms`에 있는 각 숫자가 소수인지 바로 조회한다.
- `sieve[num]`이 `True`인 것만 골라서 `prime_numbers`에 담고, 그 개수를 세어 반환한다.

## 전체 흐름 요약
1. 종잇조각으로 만들 수 있는 모든 길이의 순열을 `itertools.permutations`로 생성하고 정수로 변환
2. 중복 제거 후 최댓값을 구해, 그 최댓값까지의 소수 여부를 에라토스테네스의 체로 한 번에 계산
3. 생성된 숫자들 중 소수 맵에서 `True`로 표시된 것의 개수를 세어 반환

## 복잡도
- 순열 생성: 길이 `length`인 조합에서 나올 수 있는 순열의 총 개수는 `length`가 커질수록 급격히 늘어나지만(최대 `length!`에 비례), 이 문제의 `numbers` 길이 제한이 작아 실질적으로 감당 가능한 수준이다.
- 에라토스테네스의 체: 최댓값을 `M`이라 하면 O(M log log M)으로, 개별 판별(O(√M))을 숫자마다 반복하는 것보다 훨씬 효율적이다.
- 소수 여부 조회: 체를 미리 만들어두었기 때문에 각 숫자당 O(1)이다.

## 배운 점
- "여러 개의 값에 대해 반복적으로 같은 종류의 판별(소수 여부)을 해야 할 때"는, 값 하나하나를 매번 계산하기보다 **한 번에 전체 구간을 전처리해두는 방식**(에라토스테네스의 체)이 훨씬 효율적이다. 이는 이전에 봤던 "매번 전체를 다시 계산하지 않고 상태를 재사용한다"는 최적화 패턴과 같은 맥락이다.
- `itertools.permutations`는 길이를 지정해서 순열을 만들 수 있어서, "몇 개를 뽑을지"가 고정되지 않은 문제에서는 가능한 길이를 전부 반복하며 순열을 누적하는 방식으로 활용할 수 있다.
- 숫자를 문자열로 합친 뒤 `int()`로 변환하면, 앞자리 0이 자동으로 사라지는 부수 효과가 있다는 점도 활용 포인트였다.

## 최종 코드

```python
from itertools import permutations

def solution(numbers):
    answer = 0
    pices = [int(n) for n in numbers]
    length = len(pices)

    all_perms = []
    for i in range(length, 0, -1):
        perms = list(permutations(pices, i))
        pers = [int(''.join(map(str, p))) for p in perms]
        all_perms += pers
    all_perms = list(set(all_perms))
    all_perms.sort(reverse=True)

    sieve = [True] * (all_perms[0] + 1)
    sieve[0] = sieve[1] = False
    for i in range(2, int(all_perms[0] ** 0.5) + 1):
        if sieve[i]:
            for j in range(i * i, all_perms[0] + 1, i):
                sieve[j] = False

    prime_numbers = [num for num in all_perms if sieve[num]]
    answer = len(prime_numbers)
    return answer
```
