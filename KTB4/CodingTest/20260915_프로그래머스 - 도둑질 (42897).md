# 프로그래머스 - 도둑질 (42897) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42897

## 문제 요약
- 집들이 **원형**으로 배치되어 있고, 각 집에는 돈(`money`)이 있다.
- 인접한 두 집을 동시에 털면 경보가 울리므로, **서로 인접하지 않은 집들만** 털 수 있다.
- 원형이라 첫 번째 집과 마지막 집도 서로 인접하다.
- 털 수 있는 돈의 최댓값을 구한다.

## 아이디어 — 원형을 두 개의 직선 문제로 분리
이 문제의 핵심 난관은 원형 배치 때문에 첫 번째 집과 마지막 집이 인접하다는 점이다. 둘을 동시에 털 수 없으므로, 다음 두 경우로 나누면 각각은 원형이 아닌 **직선 배열 문제**가 된다.

- **경우 0 (`dp0`)**: 첫 번째 집을 터는 시나리오 → 마지막 집은 털 수 없다. `money[0 .. m-2]` 범위만 고려한다.
- **경우 1 (`dp1`)**: 첫 번째 집을 안 터는 시나리오 → 마지막 집을 털 수 있다. `money[1 .. m-1]` 범위를 고려한다.

두 경우 모두 "인접한 집은 못 터는 직선 배열"의 최대 합 문제이므로, 전형적인 DP 점화식으로 풀 수 있다.

```
dp[n] = max(dp[n-1], dp[n-2] + money[n])
```
- `dp[n-1]`: 현재 집(n)을 안 터는 경우 → 바로 이전까지의 최적값
- `dp[n-2] + money[n]`: 현재 집(n)을 터는 경우 → 인접한 n-1은 못 터므로 n-2까지의 최적값에 현재 집의 돈을 더함

두 경우의 최종값 중 큰 쪽(`max(dp0[m-2], dp1[m-1])`)이 답이다.

## 초기화가 중요한 이유
- `dp0[0] = money[0]`, `dp0[1] = money[0]`: 첫 집을 터는 시나리오라, 인덱스 1까지 봤을 때 0번과 1번은 인접해서 둘 다 못 털므로 "첫 집만 턴 것"이 최선이다.
- `dp1[0] = 0`, `dp1[1] = money[1]`: 첫 집을 안 터는 시나리오라, 0번은 0이고 1번부터 시작한다.

이 초기 조건이 "첫 집 포함 / 제외"라는 두 시나리오를 정확히 갈라주는 핵심이다.

## 발생했던 문제
없음. 원형 제약을 두 직선 문제로 분해하는 아이디어를 처음부터 정확히 잡아 해결했다. 집이 3개인 경계 케이스(`m == 3`)만 따로 처리했는데, 이 경우 세 집이 모두 서로 인접해 하나만 털 수 있으므로 `max(money)`가 정답이다.

## 복잡도
- `dp0`, `dp1`을 각각 한 번씩 순회하며 채우므로 O(n)
- 전체 시간복잡도: **O(n)**
- 공간복잡도: O(n) (`dp0`, `dp1` 배열)

## 배운 점
- "원형(순환) 구조에서 첫 원소와 끝 원소가 서로 얽혀 있는" 제약은, **"첫 원소를 포함하는 경우"와 "포함하지 않는 경우"의 두 직선 문제로 분리**해서 각각 풀고 최댓값을 취하는 방식으로 깔끔하게 해결할 수 있다. 이는 원형 DP 문제의 대표적인 접근법이다.
- 인접한 원소를 동시에 선택할 수 없는 최대 합 문제는 `dp[n] = max(dp[n-1], dp[n-2] + value[n])`라는 정형화된 점화식으로 풀린다. 이번엔 이 직선 점화식을 원형 상황에 맞게 두 번 적용한 것이다.
- DP는 초기 조건(base case)을 어떻게 설정하느냐가 전체 정확성을 좌우한다. 이 문제에서도 두 시나리오의 `dp[0]`, `dp[1]` 초기값이 "첫 집 포함/제외"를 정확히 구분하는 열쇠였다.

## 최종 코드

```python
"""
첫집,두번째집 경우 나누자
첫집은 마지막집을 못감
"""
def solution(money):
    answer = 0
    m = len(money)

    if m == 3:
        return max(money[0],money[1],money[2])

    dp0 = [[] for _ in range(m)]
    dp1 = [[] for _ in range(m)]

    dp0[0] = money[0]
    dp0[1] = money[0]
    dp1[0] = 0
    dp1[1] = money[1]

    for n in range(2, m-1):
        dp0[n] = max(dp0[n-1], dp0[n-2] + money[n])
        dp1[n] = max(dp1[n-1], dp1[n-2] + money[n])
    dp1[m-1] = max(dp1[m-2], dp1[m-3]+money[m-1])

    return max(dp0[m-2], dp1[m-1])
```
