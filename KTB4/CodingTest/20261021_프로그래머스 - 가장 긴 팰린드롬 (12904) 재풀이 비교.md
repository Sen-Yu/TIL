## 1. 과거 풀이 (2026.08) - 슬라이싱 기반 완전 탐색

```python
from collections import deque

def solution(s):
    answer = len(s)
    length = len(s)
    
    while answer > 1:
        for n in range(length - answer + 1):
            now = s[n:n + answer] 
            # 문자열 전체를 매번 뒤집어서 일치 여부 확인
            if now == now[::-1]:
                return answer
        answer -= 1

    return answer
```

### 🧐 과거 풀이의 한계점
- **시간 복잡도 $O(N^3)$**: 바깥 `while`(길이) $O(N)$, 안쪽 `for`(시작점) $O(N)$, 그리고 매번 부분 문자열을 슬라이싱하고 뒤집는 비교 연산(`now == now[::-1]`) $O(N)$이 곱해져 최악의 경우 $O(N^3)$이 된다.
- 슬라이싱(`[::-1]`)이 C 레벨로 최적화되어 있어 간신히 통과했으나, 문자열 길이가 길어지거나 더 엄격한 테스트 케이스에서는 **시간 초과**가 날 수밖에 없는 구조였다.

## 2. 오늘 푼 풀이 (2026.10.21) - 중심 확장(Expand Around Center)

```python
"""
현재 위치에서 중앙값을 기준으로 양쪽 같은지 확인
홀수: [mid-1] == [mid+1]
짝수: [mid-1] == [mid]
"""

def solution(s):
    answer = 1
    length = len(s)
    
    def check(mid):
        # 1. 홀수 길이 팰린드롬 (중심이 1글자: mid)
        i = 0
        while mid - 1 - i >= 0 and mid + 1 + i < length:
            if s[mid - 1 - i] != s[mid + 1 + i]:
                break
            i += 1
        now = (i * 2) + 1     
        
        # 2. 짝수 길이 팰린드롬 (중심이 2글자: mid-1, mid)
        i = 0        
        while mid - 1 - i >= 0 and mid + i < length:
            if s[mid - 1 - i] != s[mid + i]:
                break
            i += 1
                
        return max(now, i * 2)
    
    # 모든 위치를 중심점으로 가정하고 최대 팰린드롬 길이 탐색
    for idx in range(0, length, 1):
        answer = max(check(idx), answer)      

    return answer
```

## 3. 핵심 발전 포인트 비교

| 구분 | 과거 풀이 (2026.08) | 오늘 푼 풀이 (2026.10.21) |
| :--- | :--- | :--- |
| **알고리즘 접근법** | 바깥에서 안으로 뒤집기 (`[::-1]`) | **안에서 밖으로 퍼져나가기 (중심 확장)** |
| **시간 복잡도** | **$O(N^3)$** (문자열 복사/뒤집기 반복) | **$O(N^2)$ (이상적인 최적화 달성)** |
| **공간 복잡도** | $O(N)$ (부분 문자열 복사본 생성) | **$O(1)$ (추가 메모리 생성 제로)** |
| **조기 탈출(Early Exit)** | 불가능 (매번 전체 뒤집어봐야 함) | **글자가 다르면 즉시 `break` ($O(1)$ 판별)** |

### 🌟 오늘 풀이의 훌륭한 점
1. **완벽한 복잡도 개선 ($O(N^3) \to O(N^2)$)**:
   - 문자열을 잘라내어 새로운 메모리를 만드는 작업을 완전히 없애고, 인덱스 연산만으로 대칭 여부를 판별하여 속도를 극적으로 끌어올렸습니다.
2. **홀수 / 짝수 케이스의 정확한 분리**:
   - 홀수 중심(`(i * 2) + 1`)과 짝수 중심(`i * 2`)을 정확히 수식화하여 놓칠 수 있는 엣지 케이스를 완벽하게 방어했습니다.

## 4. 💡 가독성을 높이는 투 포인터(Two Pointers) 리팩토링 팁

현재 작성하신 `mid - 1 - i` 방식도 훌륭하지만, `left, right` 투 포인터 변수를 직접 사용하면 인덱스 계산식과 길이를 구하는 공식이 훨씬 직관적으로 변합니다!

```python
def solution(s):
    length = len(s)
    
    # left와 right에서 시작해 밖으로 벌려나가는 헬퍼 함수
    def expand(left, right):
        while left >= 0 and right < length and s[left] == s[right]:
            left -= 1
            right += 1
        # while문을 빠져나온 시점은 left와 right가 각각 1칸씩 더 나간 상태이므로:
        # 길이는 (right - 1) - (left + 1) + 1 = right - left - 1
        return right - left - 1

    answer = 1
    for i in range(length):
        odd_len = expand(i, i)       # 홀수 팰린드롬 (중심: i)
        even_len = expand(i, i + 1)  # 짝수 팰린드롬 (중심: i, i+1)
        answer = max(answer, odd_len, even_len)

    return answer
```

## 5. 결론 및 배운 점
- 팰린드롬 문제를 만났을 때 문자열을 통째로 뒤집는 방식은 구현은 쉬우나 $O(N^3)$의 함정에 빠지기 쉽다.
- **"중심점(홀수: 1개, 짝수: 2개)을 잡고 좌우로 벌려나가는 투 포인터 확장법"**은 공간 복잡도 $O(1)$과 시간 복잡도 $O(N^2)$을 보장하는 팰린드롬의 가장 대표적이고 우아한 정석 풀이법이다!
