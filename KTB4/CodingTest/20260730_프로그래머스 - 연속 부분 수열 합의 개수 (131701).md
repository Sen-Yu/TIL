# 프로그래머스 - 연속 부분 수열 합의 개수 (131701) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/131701

## 문제 요약
- 원형으로 이어진 정수 배열 `elements`가 주어진다.
- 이 배열에서 **연속된 부분 수열**을 만들 수 있는 모든 길이(1 ~ length-1)에 대해, 가능한 모든 시작 위치에서의 합을 구한다.
- 그 합들 중 **서로 다른 값의 개수**를 반환한다.

## 아이디어
길이가 커지는 방향으로 DP를 쌓아가는 방식이다.

- `dp[0][n] = elements[n]` — 길이 1짜리 부분 수열의 합은 그 원소 자체
- `dp[1][n] = dp[0][n] + elements[n+1]` — 길이 2짜리는 길이 1짜리 합에 다음 원소를 더함
- 일반화하면 `dp[k][n] = dp[k-1][n] + elements[n+k]`

즉, 이전 길이의 합에 새로 포함되는 원소 하나만 더하면 다음 길이의 합을 구할 수 있다. 매번 부분 수열을 처음부터 다시 더할 필요가 없다.

원형 배열이기 때문에 인덱스가 배열 길이를 넘어가면 앞으로 돌아가야 한다. `length = len(elements)`일 때 `n + k`가 `length`를 넘으면 `n + k - length`로 순환시켜 처리한다.

각 길이(`k`)에서 나온 모든 합을 `set`에 누적시키면 중복 없이 저장되고, 마지막으로 전체 길이(원소 전부를 더한 값)는 시작 위치와 무관하게 하나뿐이므로 따로 `sum(elements)`를 더해 넣는다.

## 발생했던 문제
없음. 점화식과 원형 인덱스 처리 아이디어를 한 번에 정리하고 코드로 옮겨서, 세 번의 실행 만에 바로 해결됐다.

## 배운 점
- 부분 수열의 합처럼 "이전 결과에 원소 하나만 더하면 다음 결과가 나오는" 구조는 매번 처음부터 다시 계산하지 않고 DP로 누적하면 계산량을 크게 줄일 수 있다.
- 원형 배열 문제에서는 인덱스가 배열 길이를 넘어갈 때 `(인덱스 - length)` 또는 `% length` 방식으로 순환시키는 처리가 핵심이 된다.
- 중복 제거가 필요한 경우 `set`에 결과를 계속 누적시키는 방식은 최종적으로 개수만 세면 되는 문제에서 간단하고 효과적이다.

## 최종 코드

```python
"""
dp[0][n] = elements[n]
dp[1][n] = dp[0][n] + elements[n+1]
dp[2][n] = dp[1][n] + elements[n+2]
dp[k][n] = dp[k-1][n] + elements[n+k]
length = len(elements)
if(n+k >= length-k)
    n+k = n + k - length
"""
def solution(elements):
    answer = 0
    length = len(elements)
    k = 0
    n = 0
    dp = []

    dp.append(elements)
    set_e = set(dp[0])
    for k in range(1, length - 1):
        dp.append([])
        for n in range(length):
            if (n + k >= length):
                dp[k].append(dp[k - 1][n] + elements[n + k - length])
            else:
                dp[k].append(dp[k - 1][n] + elements[n + k])
        set_e = set_e | set(dp[k])
    set_e.add(sum(elements))

    return len(set_e)
```
