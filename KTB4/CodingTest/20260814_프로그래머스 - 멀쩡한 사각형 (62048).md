# 프로그래머스 - 멀쩡한 사각형 (62048) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/62048

## 문제 요약
- 가로 `W`, 세로 `H` 크기의 직사각형 종이가 1×1 격자로 나뉘어 있다.
- 이 종이를 대각선(한 꼭짓점에서 반대쪽 꼭짓점까지)으로 자르면, 대각선이 지나가는 칸들은 "잘린 칸"이 되고 나머지는 "멀쩡한 칸"이 된다.
- 가로/세로 방향과 평행하게 1×1로 잘라 쓸 수 있는, 즉 **온전히 남아있는(멀쩡한) 칸의 개수**를 구한다.

## 아이디어
- 전체 칸 수(`W*H`)에서 대각선이 지나가는(잘린) 칸의 개수를 빼면 정답이 된다.
- 대각선이 지나가는 칸의 개수를 구하는 게 이 문제의 핵심이다.

## 시도 1: 단일 나눗셈으로 접근 — 실패
처음엔 큰 값을 작은 값으로 나눈 몫을 올림(ceil)해서 곱하는 방식(`ceil(큰값/작은값) * 작은값`)으로 접근했다. 이 방식은 `3:2`처럼 작은 쪽이 `2`인 특정 케이스에서는 맞아떨어졌지만, 일반적인 비율(예: `5:3`)에서는 검증되지 않은 접근이었다. 답을 알려주지 않고 직접 검증해보도록 안내받은 뒤, 실제로 이 방식이 모든 경우를 설명하지 못한다는 걸 스스로 확인하게 됐다.

## 격자와 대각선을 직접 그려보며 이해한 과정
- `W × H` 격자를 손으로 그리고, 한쪽 모서리에서 반대쪽 모서리까지 대각선을 그었다.
- 대각선은 세로 격자선을 넘을 때, 또는 가로 격자선을 넘을 때마다 새로운 칸으로 이동한다는 걸 확인했다.
- 여기서 핵심 관계를 도출했다: **대각선이 지나가는 칸의 개수 = 교차점(세로선+가로선을 넘는 횟수)의 개수 + 1** (시작 칸을 1개로 치고, 그 이후 이동할 때마다 칸이 하나씩 늘어나므로)
- 만약 세로선과 가로선을 **동시에** 넘는 지점이 있다면 그 순간은 칸 이동이 한 번만 일어나므로 교차점 개수가 줄어든다. 이 "동시 교차" 여부가 계산을 복잡하게 만드는 요인이었다.
- `gcd(w,h)`로 `w`, `h`를 약분하면 두 값이 **서로소**가 되는데, 서로소인 격자에서는 대각선이 세로선과 가로선을 동시에 넘는 경우가 절대 생기지 않는다는 걸 확인했다. 즉 약분된 상태에서는 "동시 교차" 걱정 없이 세로선 교차 횟수와 가로선 교차 횟수를 단순히 더하기만 하면 된다.

## 해결 방법 (직접 유도한 점화식)
1. `gcd = math.gcd(w, h)`로 최대공약수를 구하고, `w //= gcd`, `h //= gcd`로 약분해 서로소로 만든다.
2. 약분된 격자에서 내부 세로선은 `w-1`개, 내부 가로선은 `h-1`개이므로, 대각선이 넘는 총 교차점 수는 `(w-1) + (h-1)`이다.
3. "칸 개수 = 교차점 개수 + 1" 관계를 적용해 `k = (w-1) + (h-1) + 1`을 구한다. 이것이 **약분된 격자에서** 대각선이 지나가는 칸의 개수다.
4. 약분 전 원래 스케일로 되돌리기 위해 `k * gcd`를 계산하면, 실제 `W × H` 격자에서 대각선이 지나간 칸의 개수가 된다.
5. 전체 칸 수(`w*h`, 약분 전 원본 기준)에서 `k * gcd`를 빼면 멀쩡한 칸의 개수가 된다.

## 검증 사례
- **19 × 19 (정사각형)**: `gcd(19,19) = 19`이므로 약분하면 `w=h=1`. `k = (0+0)+1 = 1`. 정사각형의 대각선은 세로선과 가로선을 항상 동시에 넘으며 계단 없이 정직하게 지나가기 때문에, 약분하면 항상 `1×1`(칸 1개)로 귀결된다는 걸 확인했다. 최종적으로 `19*19 - 1*19 = 342`.

## 복잡도
- `math.gcd`는 유클리드 호제법 기반으로 O(log(min(w,h)))이다.
- 나머지 연산은 모두 O(1)이므로 전체 시간복잡도는 사실상 O(log(min(w,h)))이다.

## 배운 점
- "단일 나눗셈으로 패턴을 대표하려는 접근"은 특정 케이스에서만 우연히 맞을 뿐, 일반적인 경우를 설명하지 못할 수 있다. 작은 예시 하나로 검증하고 넘어가기보다, 조건이 다른 여러 케이스(예: 서로소가 아닌 경우, 정사각형인 경우)로 직접 검증해보는 습관이 필요하다.
- "칸의 개수를 세는 문제"를 "교차점(경계를 넘는 횟수)을 세는 문제"로 바꿔서 생각하면 훨씬 다루기 쉬워진다. 이 둘 사이엔 "칸 개수 = 교차점 개수 + 1"이라는 간단한 관계가 성립한다.
- 두 수를 gcd로 약분해서 서로소로 만들면, "동시에 일어나는 경우"(동시 교차) 자체가 원천적으로 사라진다는 성질을 활용하면 문제를 훨씬 단순화할 수 있다. 이는 유클리드 호제법과 맞닿아 있는 수론적 성질이다.
- 격자와 대각선을 직접 손으로 그려보고 교차점을 세어보는 과정이, 추상적인 점화식을 스스로 유도하는 데 실질적으로 도움이 됐다.

## 최종 코드

```python
"""
gcd로 몫연산해수 기약 분수화 시키기
8:12 => 2:3
"""
import math
def solution(w, h):
    gcd = math.gcd(w, h)

    answer = w * h
    ## 약분화
    w //= gcd
    h //= gcd
    ## 세로선 가로선 마주치는 선분 수
    ## +1해서 칸이 됨
    k = (w - 1 + h - 1) + 1

    answer -= k * gcd
    return answer
```
