# 프로그래머스 - 분수의 덧셈 (120808) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/120808

## 문제 요약
- 두 분수 `numer1/denom1`, `numer2/denom2`가 주어진다.
- 두 분수를 더한 결과를 **기약분수**(더 이상 약분되지 않는 분수) 형태로, 분자와 분모를 배열로 반환한다.

## 아이디어
분수의 덧셈은 통분 → 더하기 → 약분의 순서로 진행한다.

```
numer1        numer2       numer1*(lcm/denom1) + numer2*(lcm/denom2)
------  +  ------   =   -----------------------------------------------
denom1        denom2                    lcm(denom1, denom2)
```

- 먼저 두 분모의 **최소공배수(lcm)**를 구해 공통分모로 삼는다.
- 각 분자를 `lcm // 분모` 배수만큼 늘려서 통분한 뒤 더하면 새로운 분자가 나온다.
- 마지막으로 새 분자와 분모(lcm)의 **최대공약수(gcd)**로 각각을 나눠 기약분수로 만든다.

## 발생했던 문제
처음 제출했을 때는 통분과 덧셈까지는 정확히 구현했지만, **마지막에 기약분수로 약분하는 과정을 빠뜨렸다.** 그 결과 분자/분모가 약분되지 않은 상태로 반환되어 오답이 나왔다. 예를 들어 결과가 `4/8`이어야 할 걸 약분 안 된 `8/16` 형태로 반환하는 식의 문제였다.

## 해결 방법
계산된 분자(`numer`)와 분모(`lcm`)의 최대공약수(`gcd`)를 구해서, 두 값을 그 `gcd`로 나눠주는 약분 단계를 추가했다.

```python
gcd = math.gcd(lcm, numer)
numer //= gcd
lcm //= gcd
```

이 단계를 추가한 뒤 두 번째 시도에서 정답을 맞혔다.

## 복잡도
- `math.lcm`, `math.gcd` 모두 내부적으로 유클리드 호제법 기반이라 O(log(min(a,b)))로 매우 빠르다.
- 전체 연산이 상수 시간에 가까운 O(1) 수준의 계산이다.

## 배운 점
- 분수 계산 문제에서는 "계산 결과를 구하는 것"과 "그 결과를 요구된 형식(기약분수)으로 정리하는 것"이 별개의 단계라는 걸 놓치기 쉽다. 문제가 요구하는 최종 형태(기약분수, 정렬 순서, 반올림 등)를 계산 로직과 별도로 항상 체크리스트처럼 확인하는 습관이 필요하다.
- 분수의 통분/약분처럼 최대공약수와 최소공배수를 함께 쓰는 문제에서는, 최근에 직접 구현해본 유클리드 호제법 원리가 그대로 적용된다 — `math.gcd`/`math.lcm`을 쓰든 직접 구현하든 원리는 동일하다.

## 최종 코드

```python
import math

def solution(numer1, denom1, numer2, denom2):
    lcm = math.lcm(denom1, denom2)
    numer = numer1 * (lcm // denom1) + numer2 * (lcm // denom2)

    gcd = math.gcd(lcm, numer)
    numer //= gcd
    lcm //= gcd

    answer = [numer, lcm]
    return answer
```
