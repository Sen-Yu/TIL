# 프로그래머스 - 호텔 방 배정 (64063) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/64063

## 문제 요약
- 방이 `1`번부터 `k`번까지 있는 호텔에서, 고객들이 원하는 방 번호(`room_number`)를 순서대로 요청한다.
- 원하는 방이 비어 있으면 그 방을 배정한다.
- 이미 차 있으면, 그 번호보다 크면서 비어 있는 방 중 **가장 작은 번호**를 배정한다.
- 각 요청에 실제로 배정된 방 번호를 순서대로 반환한다.

## 아이디어
- 해시 테이블(딕셔너리)로 "각 방에서 다음으로 시도해볼 방 번호"를 관리한다. `rooms[n]`은 "n번을 요청받았을 때 다음으로 가봐야 할 방"을 가리킨다.
- 원하는 방이 비어 있으면(`n not in rooms`) 바로 배정하고, `rooms[n] = n+1`로 "이 방은 이제 찼으니 다음엔 n+1을 보라"고 기록한다.
- 이미 차 있으면 `rooms[chain]`을 따라가며 빈 방을 찾는다.

## 발생했던 문제 — 효율성 테스트 전부 실패
첫 시도(경로 압축 없음)는 **정확성 테스트는 전부 통과했지만 효율성 테스트는 전부 실패**했다.

원인은 빈 방을 찾을 때마다 매번 체인을 처음부터 끝까지 따라가야 했기 때문이다. 예를 들어 `1, 2, 3, ..., 1000`이 순서대로 다 찬 상태에서 다시 `1`을 요청하면 `1 → 2 → 3 → ... → 1001`까지 전부 훑어야 한다. 이런 요청이 반복되면 최악의 경우 O(n²)에 가까워져 시간초과가 발생했다.

## 해결 방법 — 경로 압축(path compression)
빈 방을 찾아가는 도중 거쳐온 방들을 `stack`에 모아뒀다가, 빈 방을 배정한 뒤 **그 방들이 다음엔 곧바로 최종 목적지 근처를 가리키도록 갱신**했다.

```python
chain = n
stack = list()

while chain in rooms:      # 빈 방을 찾을 때까지 체인을 따라감
    stack.append(chain)    # 거쳐온 방들을 기록
    chain = rooms[chain]

rooms[chain] = chain+1     # 빈 방 배정
answer.append(chain)

while stack:               # 거쳐온 방들이 다음엔 바로 점프하도록 갱신
    back = stack.pop()
    rooms[back] = chain+1
```

이것은 유니온-파인드(Union-Find)의 **경로 압축** 기법과 동일하다. 한 번 긴 체인을 따라간 뒤에는, 그 경로상의 방들이 다음 요청 때 한두 번 만에 빈 방으로 점프하게 되어, 각 요청의 평균 비용이 거의 상수 시간에 가까워진다. 이 압축 덕분에 효율성 테스트를 통과했다.

## 복잡도
- 경로 압축을 적용하면 각 요청은 분할 상환(amortized) 관점에서 거의 O(1)에 가깝게 처리된다.
- 요청 수를 `q`라 하면 전체적으로 거의 O(q)에 가까운 시간복잡도를 가진다.
- 공간복잡도는 O(배정된 방의 수)이다.

## 배운 점
- "정확성은 맞지만 효율성에서 막힌다"는 상황은, 알고리즘의 방향은 맞았지만 **반복되는 탐색을 재사용하지 못하고 매번 처음부터 다시 하는 것**이 원인인 경우가 많다.
- "이미 지나간 경로를 다음 탐색을 위해 미리 지름길로 갱신해두는" 경로 압축은, 체인을 따라가며 무언가를 찾는 유형의 문제에서 시간복잡도를 극적으로 줄여주는 핵심 기법이다. 유니온-파인드에서 익힌 원리가 이런 방 배정 문제에도 그대로 적용된다.
- 딕셔너리를 "다음에 봐야 할 곳을 가리키는 포인터"처럼 활용하면, 배열 없이도 희소한(sparse) 상태를 효율적으로 관리할 수 있다. `k`가 매우 커도 실제로 요청된 방만 딕셔너리에 담기기 때문이다.

## 최종 코드

```python
"""
해시 테이블 체이닝
첫시도: 정확성 전부 통과, 효율성 전부 붙통
두번째시도: 체이닝 스택넣으니 통과
"""
def solution(k, room_number):
    answer = []
    rooms = dict()

    for n in room_number:
        if n not in rooms:
            rooms[n] = n+1
            answer.append(n)
        else:
            chain = n
            stack = list()

            while chain in rooms:
                stack.append(chain)
                chain = rooms[chain]

            rooms[chain] = chain+1
            answer.append(chain)

            while stack:
                back = stack.pop()
                rooms[back] = chain+1

    return answer
```
