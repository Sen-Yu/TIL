# 프로그래머스 - 디스크 컨트롤러 (42627) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42627

## 문제 요약
- 하드디스크가 작업을 수행하고 있지 않을 때에는 먼저 요청이 들어온 작업부터 처리한다.
- 각 작업의 요청부터 종료까지 걸린 시간의 평균을 가장 줄이는 방법을 찾아야 한다.
- 작업의 처리 시간(소요 시간)이 짧은 것을 우선적으로 처리하는 **SJF(Shortest Job First) 스케줄링** 기법을 우선순위 큐로 구현하는 문제이다.

## 아이디어
- **두 개의 큐(이중 큐)**를 사용하여 해결한다.
    1. **대기 큐 (`waits`)**: 요청 시간(`request_time`)이 빠른 순으로 힙을 구성. `(request_time, spent_time, index)`
    2. **우선순위 큐 (`prioritys`)**: 현재 시점(end)에서 실행 가능한 작업 중 소요 시간(`spent_time`)이 짧은 순으로 힙을 구성. `(spent_time, request_time, index)`
- `end` 변수를 통해 현재 작업이 완료되는 시간을 관리한다.
- 모든 작업이 끝날 때까지(`waits` 또는 `prioritys`에 작업이 있는 동안) 아래 과정을 반복한다:
    1. **작업 이관**: 대기 큐(`waits`)에서 현재 시간(`end`) 이전에 요청된 모든 작업을 우선순위 큐(`prioritys`)로 옮긴다. (만약 우선순위 큐가 비어있다면, 다음 대기 작업을 옮기기 위해 조건에 묶임)
    2. **작업 실행**: 우선순위 큐에 작업이 있다면, 소요 시간이 가장 짧은 작업을 빼내어 실행하고 `end` 시간을 증가시킨다. 이때 총 대기 및 처리 시간(`end - request_time`)을 `answer`에 누적한다.
    3. **유휴 상태 점프**: 우선순위 큐는 비어있고 대기 큐에만 작업이 있다면, 하드디스크가 쉬고 있는 유휴 상태이므로 `end`를 다음 작업의 요청 시간으로 점프시킨다.

## 배운 점 및 회고
- 파이썬의 `heapq`를 2개(하나는 요청 시간 기준, 하나는 소요 시간 기준) 사용하여 타이밍 이슈를 해결하는 훌륭한 힙 응용 방법이다.
- 조건문 `while (not prioritys and waits) or (waits and waits[0][0] <= end):` 로 큐가 비어 교착상태에 빠지거나 붕 뜨는 것을 방지하는 로직이 깔끔하게 작성되었다.

## 최종 코드
```python
import heapq

def solution(jobs):
    answer = 0
    
    waits = list()
    prioritys = list()
    
    ## init waits
    for index, value in enumerate(jobs):
        # request_time, spent_time, index
        heapq.heappush(waits, [value[0], value[1], index])

    end = waits[0][0]
    
    while waits or prioritys:
        ## 우선순위큐는 비었지만, 대기중인작업이 있는경우 / 대기중인작업이 있으면서 현재 시간보다 일찍 요청된 작업 있음
        while (not prioritys and waits) or (waits and waits[0][0] <= end):
            request_time, spent_time, index = heapq.heappop(waits)
            heapq.heappush(prioritys, [spent_time, request_time, index])  
        
        ## 우선순위큐에 작업대기중
        if prioritys:
            spent_time, request_time, index = heapq.heappop(prioritys)
            
            if end >= request_time:
                end += spent_time
            else:
                end = request_time + spent_time
            answer += end - request_time
            
        ## 우선순위큐에 없지만 작업이 있음 -> 유휴상태  -> 다음 작업 점프 필요
        elif waits:
            end = waits[0][0]
            
    return answer // len(jobs)
```
