# 프로그래머스 - 체육복 (42862) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42862

## 문제 요약
- 체육복을 도난당한 학생들에게 여벌의 체육복을 빌려주어 최대한 많은 학생이 체육수업을 듣게 하는 문제.
- 학생들의 번호는 체격 순으로 매겨져 있어, 바로 앞번호의 학생이나 바로 뒷번호의 학생에게만 체육복을 빌려줄 수 있다.
- 여벌 체육복을 가져온 학생이 체육복을 도난당했을 수 있으며, 이때는 남에게 빌려줄 수 없고 자신이 입어야 한다.

## 아이디어
- **그리디(Greedy)** 알고리즘의 기초 문제.
- 우선 `lost`와 `reserve` 배열을 정렬(`sort()`)하여 앞번호부터 순차적으로 탐색한다.
- 배열을 순회하며 다음 순서대로 확인한다:
  1. 자신이 잃어버렸지만 여벌이 있는 경우 (`l in reserve`): 본인이 입어야 하므로 `reserve`에서 제외.
  2. 앞번호(`l-1`)에게 빌릴 수 있는 경우: 앞번호의 여벌을 사용하고 `reserve`에서 제외.
  3. 뒷번호(`l+1`)에게 빌릴 수 있는 경우: 단, 뒷번호 학생이 **자신의 체육복을 잃어버리지 않은 상태(`l+1 not in lost`)**여야만 빌릴 수 있다! (이 문제의 가장 큰 함정 방어)

## 배운 점
- 체육복을 도난당한 학생과 여벌이 있는 학생의 교집합 처리가 핵심인 문제다. 
- 작성하신 코드처럼 조건문 `l+1 not in lost`를 통해 남의 여벌을 뺏어오지 못하게 막는 논리도 아주 훌륭하다. 
- (참고) 애초에 반복문을 돌기 전에 집합(`set`)을 이용해 `real_lost = set(lost) - set(reserve)` 형태로 순수하게 빌려야 하는 학생과 빌려줄 수 있는 학생을 완전히 분리하고 시작하면 조건문이 훨씬 단순해질 수 있다.
- 정렬(`sort`)을 하지 않으면 빌려주는 순서가 꼬여 최적해를 찾지 못할 수 있으므로, 그리디 문제에서는 정렬이 필수적인 경우가 많다는 점을 기억하자.

## 최종 코드
```python
def solution(n, lost, reserve):
    answer = n - len(lost)
    lost.sort()
    reserve.sort()

    for l in lost:
        if l in reserve:
            reserve.remove(l)
            answer += 1
        elif l > 0 and l-1 in reserve:
            reserve.remove(l-1)
            answer += 1
        elif l < n and l+1 in reserve and l+1 not in lost :
            reserve.remove(l+1)
            answer += 1    
        # print(f"l:{l}, reserve:{reserve}")
    return answer
```
