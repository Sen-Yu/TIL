# 프로그래머스 - 섬 연결하기 (42861) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42861

## 문제 요약
- $N$개의 섬과 다리를 짓는 비용이 주어질 때, 최소의 비용으로 모든 섬이 서로 통행 가능하도록(하나의 컴포넌트로) 연결하는 문제.
- 대표적인 **최소 신장 트리(Minimum Spanning Tree, MST)**를 구하는 문제다.

## 아이디어
- **프림(Prim) 알고리즘**을 활용한 완벽한 정석 풀이.
- 딕셔너리(`bridges`)를 활용하여 각 노드에서 갈 수 있는 도착지들과 그 비용을 연결 리스트 형태로 저장한다.
- 0번 노드부터 시작하여, 갈 수 있는 모든 간선을 우선순위 큐(`primary_que`)에 넣는다.
- 우선순위 큐(최소 힙)에서 가장 비용이 저렴한 간선을 하나씩 빼면서 다음 로직을 반복한다:
  1. 도착지 노드(`b`)가 이미 방문한 노드라면(`visited[b] == True`), 사이클이 발생하므로 버리고 다음으로 싼 간선을 꺼낸다.
  2. 방문하지 않은 노드라면 방문 처리(`visited[b] = True`)를 하고 비용(`cost`)을 정답에 더한다.
  3. 방금 새로 연결된 노드(`b`)에서 뻗어나가는 모든 간선들을 다시 우선순위 큐에 집어넣어 다음 탐색 범위를 넓힌다.
- 모든 섬을 방문할 때까지(`False in visited`가 없을 때까지) 반복한다.

## 배운 점
- 그리디 알고리즘의 꽃이라 불리는 프림(Prim) 알고리즘을 최소 힙(`heapq`)을 이용해 아주 깔끔하게 구현했다!
- **[효율성 개선 팁 1]**: `while False in visited:` 조건문은 파이썬 내부적으로 리스트 전체를 훑어야 하므로 매 루프마다 $O(N)$의 시간이 걸린다. $N$이 100이라 가뿐히 통과했지만, 만약 $N$이 10만 개라면 시간 초과가 날 수 있다. 대신 맨 처음에 `visited_count = 1`을 두고, 노드를 방문할 때마다 `visited_count += 1`을 한 뒤 `while visited_count < n:` 으로 검사하면 $O(1)$로 최적화할 수 있다.
- **[효율성 개선 팁 2]**: 애초에 `bridges[a]`에 값을 넣을 때 `heappush`를 하고, 나중에 `heappop`으로 꺼내서 다시 `primary_que`에 `heappush`를 하고 있다. 어차피 `primary_que` 안에서 최솟값이 정렬되므로, 초기에 `bridges[a]`에 값을 넣을 때는 단순 리스트로 묶어 `bridges[a].append([cost, b])`만 한 뒤, 나중에 `for cost, b in bridges[num]: heappush(primary_que, [cost, b])` 형태로 통째로 넣는 것이 시간 복잡도 면에서 유리하다.

## 최종 코드
```python
import heapq

def solution(n, costs):
    answer = 0
    bridges = dict()
    
    # 1. 인접 리스트 초기화 (그래프 그리기)
    for a, b, cost in costs:
        if not a in bridges:
            bridges[a] = list()
        if not b in bridges:
            bridges[b] = list()
            
        heapq.heappush(bridges[a], [cost, b])
        heapq.heappush(bridges[b], [cost, a])
    
    # 방문 배열 초기화 및 0번 노드 방문 처리
    visited = [False] * n
    visited[0] = True
    primary_que = list()
    
    # 특정 노드의 간선들을 우선순위 큐에 쏟아붓는 함수
    def insert_primary(num):
        for _ in range(len(bridges[num])): 
            now = heapq.heappop(bridges[num])
            heapq.heappush(primary_que, now)
            
    # 0번 노드의 간선부터 시작
    insert_primary(0)
    
    # 모든 노드를 방문할 때까지 반복
    while False in visited:
        # 가장 비용이 적은 간선 꺼내기
        cost, b = heapq.heappop(primary_que)
        
        # 이미 연결(방문)된 노드라면 스킵
        while visited[b]:
            cost, b = heapq.heappop(primary_que)
        
        # 방문하지 않은 노드 연결
        answer += cost
        visited[b] = True 
        insert_primary(b)
     
    return answer
```
