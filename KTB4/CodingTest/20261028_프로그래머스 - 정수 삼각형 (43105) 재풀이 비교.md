## 1. 과거 풀이 - 2차원 DP 테이블 & 3단 분기

```python
def solution(triangle):
    answer = -1
    height = len(triangle)
    
    # 2차원 삼각형 형태의 DP 테이블 새로 생성 (O(N^2) 메모리)
    sum = []
    for h in range(1, height + 1):
        sum.append([0] * h)
    sum[0][0] = triangle[0][0]
    
    for y in range(1, height):
        for x in range(y + 1):
            if x == 0:
                sum[y][x] = triangle[y][x] + sum[y - 1][x]
            elif x == y:
                sum[y][x] = triangle[y][x] + sum[y - 1][x - 1]
            else:
                sum[y][x] = triangle[y][x] + max(sum[y - 1][x - 1], sum[y - 1][x])
                
            # 매 루프마다 최댓값 갱신
            answer = max(answer, sum[y][x])
    
    return answer
```

### 🧐 과거 풀이의 특징 및 한계점
1. **공간 복잡도 $O(N^2)$**:
   - 입력과 똑같은 크기의 2차원 리스트 `sum`을 새로 만들어 메모리 낭비가 발생했다.
2. **장황한 3단 조건 분기**:
   - 왼쪽 끝(`x == 0`), 오른쪽 끝(`x == y`), 중간 위치를 일일이 `if/elif/else`로 나누어 계산했다.
3. **불필요한 반복 갱신**:
   - 매번 좌표마다 `answer = max(answer, sum[y][x])`를 호출하여 연산량이 많았다.

## 2. 오늘 푼 풀이 (2026.10.28) - 1차원 롤링 배열 (Rolling Array) DP

```python
"""
h |. leafs
0 -> 0
1 -> 01
leafs[0] = before[0] + triangle[1][0]
leafs[1] = before[0] + triangle[1][1]
...
leafs[x] = before[x] + triangle[h][x]
leafs[x] = before[x-1] + triangle[h][x]
"""
def solution(triangle):
    answer = 0
    height = len(triangle)
    leafs = [0] * height  # 1차원 배열 단 1개만 사용 (공간 압축)
    
    for h in range(0, height):
        befores = leafs.copy()  # 직전 층의 결과만 복사
        for x in range(h + 1):
            if x - 1 >= 0:
                leafs[x] = befores[x - 1] + triangle[h][x]
            leafs[x] = max(leafs[x], befores[x] + triangle[h][x])

    # 맨 마지막 바닥 층의 최댓값만 한 번에 추출
    answer = max(leafs)
    
    return answer
```

## 3. 핵심 발전 포인트 비교

| 구분 | 과거 풀이 | 오늘 푼 풀이 (2026.10.28) |
| :--- | :--- | :--- |
| **공간 복잡도** | **$O(N^2)$** (2차원 삼각형 리스트) | **$O(N)$ (1차원 롤링 배열, 극적 최적화)** |
| **조건 분기** | `if / elif / else` 3단 분기 | **`if x - 1 >= 0` 단 1개로 통합** |
| **점화식 구현** | 층마다 별도 인덱스 추적 | **`befores[x-1]`과 `befores[x]` 비교로 단 2줄 압축** |
| **정답 추출 시점** | 매 원소 계산 시마다 `max` 갱신 | **바닥 층 완성 후 단 한 번 `max(leafs)`** |
| **코드 가독성** | 테이블 초기화 루프 포함 25줄 | **단 11줄의 컴팩트한 로직** |

## 4. 🌟 오늘 풀이의 뛰어난 설계 디테일

### 1) 1차원 공간 압축 (Rolling Array 기법)
- 삼각형 DP에서 다음 층을 계산할 때 필요한 데이터는 **오직 바로 위층(`h-1`)의 값뿐**입니다. 2개 층 위의 데이터는 더 이상 필요하지 않습니다.
- 이를 간파하고 전체 2차원 테이블 대신 `leafs` 1차원 리스트 하나와 `befores = leafs.copy()`를 활용해 **공간 복잡도를 $O(N^2) \to O(N)$으로 극단적으로 압축**했습니다.

### 2) 우아한 인덱스 예외 처리 통합
- `x - 1 >= 0`일 때만 왼쪽 대각선 위(`befores[x-1]`)를 먼저 반영하고,
- 이어서 바로 위(`befores[x]`)와 `max` 비교를 수행하도록 설계하여,
  - `x == 0`일 때는 자연스럽게 `befores[0]`만 반영되고,
  - `x == h`일 때는 `befores[h]`가 0이므로 왼쪽 대각선 위의 값이 그대로 유지되는 마법 같은 효과를 만들어냈습니다.

## 5. 💡 참고: 역발상 바텀업(Bottom-Up) In-place 코드

바닥에서 위로 올라가는 방식도 함께 눈에 익혀두시면 좋습니다. 추가 메모리가 아예 **$0$**이 되고 조건문이 완전히 사라집니다!

```python
def solution_bottom_up(triangle):
    # 맨 밑에서 두 번째 줄부터 꼭대기(0층)까지 거꾸로 올라감
    for y in range(len(triangle) - 2, -1, -1):
        for x in range(len(triangle[y])):
            # 내 아래 두 개 중 더 큰 값을 골라 나에게 누적
            triangle[y][x] += max(triangle[y + 1][x], triangle[y + 1][x + 1])
            
    # 최종 정답은 꼭대기 [0][0]에 저절로 모임
    return triangle[0][0]
```

## 6. 결론 및 배운 점
- 이전에는 2차원 테이블을 만들어 모든 경로를 기록했지만, 이번 풀이에서는 **"이전 층만 기억하면 된다"는 슬라이딩 윈도우 원리를 적용하여 $O(N)$ 롤링 배열 DP를 완벽하게 구현**했습니다.
- 인덱스 조건을 단 1개의 `if`문으로 압축한 점과, 마지막 층에서만 `max`를 취하는 방식 모두 알고리즘의 성숙도를 보여주는 훌륭한 리팩토링입니다!
