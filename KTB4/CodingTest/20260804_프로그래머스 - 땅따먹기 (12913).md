# 프로그래머스 - 땅따먹기 (12913) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12913

## 문제 요약
- `N × 4` 크기의 땅(`land`)이 주어진다. 각 행에서 칸 하나를 밟아 점수를 얻는다.
- 단, **바로 이전 행에서 밟았던 칸과 같은 열은 이번 행에서 밟을 수 없다.**
- 모든 행을 다 밟았을 때 얻을 수 있는 **최대 점수 합**을 구한다.

## 아이디어
행 단위로 최적값을 누적해가는 DP 문제다.

- `dp[y][x]`를 "y행의 x열을 밟았을 때, 0행부터 y행까지 얻을 수 있는 최대 점수"로 정의한다.
- 첫 행은 이전 행이 없으므로 `dp[0][x] = land[0][x]` 그대로 초기화한다.
- 그 다음 행부터는, 이전 행에서 **같은 열만 제외한 나머지 3개 열 중 최댓값**을 가져와 현재 칸의 점수에 더한다: `dp[y][x] = land[y][x] + max(dp[y-1][열 x 제외한 나머지])`
- 마지막 행(`N-1`)의 `dp` 값 4개 중 최댓값이 정답이 된다.

## 발생했던 문제

**1. 처음 문제 해석을 잘못함**
처음엔 "바로 아래 행에서는 인접한 열로만 이동할 수 있다"고 착각했다. 실제 규칙은 "같은 열만 아니면 그 행의 나머지 열 어디로든 이동 가능"이라, 인접 여부와는 무관하다는 걸 뒤늦게 파악했다. 이 오해를 바로잡고 나서 `dp[y-1][:x] + dp[y-1][x+1:]`(같은 열 x만 제외한 나머지 전부)로 점화식을 다시 세웠다.

**2. `land` 값을 넣어야 할 자리에 실수로 다른 값을 넣음**
누적된 `dp[y-1]` 값을 참조해야 하는 자리에서, 한 번 `land`를 그대로 참조하는 실수가 있었다. DP 문제에서는 원본 입력값(`land`)과 누적된 최적값(`dp`)을 혼동하지 않고 정확히 구분해서 참조하는 게 중요하다는 걸 다시 확인했다.

두 가지를 바로잡은 뒤로는 막힘없이 풀렸다.

## 복잡도
- 각 행(N개)마다 4개 열을 순회하고, 각 열에서 나머지 3개 중 최댓값을 구하는 연산은 상수 시간이다.
- 전체 시간복잡도: **O(N)**
- 공간복잡도: O(N) (`dp` 테이블, 필요하면 이전 행만 유지해 O(1)로도 줄일 수 있다)

## 배운 점
- "이전 상태에서 특정 조건(같은 열)만 제외하고 나머지는 전부 가능"이라는 규칙은, 상태를 이웃 관계로 좁혀서 생각하면 오히려 더 복잡하게 꼬일 수 있다. 문제의 제약 조건을 있는 그대로("이것만 안 된다") 다시 확인하는 습관이 필요하다.
- DP 점화식을 세울 때 원본 입력 배열과 DP 누적 배열을 헷갈리지 않도록, 변수명이나 접근 시점을 한 번 더 확인하는 게 좋겠다.
- 행 단위로만 최적값을 이어받는 DP는 전체 히스토리를 보관할 필요 없이 이전 행 하나만 있으면 되므로, 공간 최적화 여지가 있는 전형적인 패턴이다.

## 최종 코드
~~~
"""
land = (N,4)

start = 0

que = [[0][0]~[0][4]]
dp[1][0] = max ([0][-1],[0][2])
dp[y][x] = max (dp[y-1][x-1]+dp[y][x], dp[y-1][x+1]+dp[y][x]) 
-> 아래행은 이웃 아래 만 가능한줄 착각
-> 아래행은 자기 밑에 빼고 전부 가능

"""
def solution(land):
    answer = 0
    N = len(land)
    dp =[[0] * 4 for _ in range(N)]

    
    for idx in range(4):
        dp[0][idx] = land[0][idx]
    
    
    for y in range(0, N) :   
        for x in range(4):
            dp[y][x] = land[y][x]+ max(dp[y-1][:x]+dp[y-1][x+1:])    
                  
        
    for idx in range(4):
        answer = max(answer, dp[N-1][idx])
    
    return answer
~~~
