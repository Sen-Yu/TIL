# 프로그래머스 - 최대공약수와 최소공배수 (12940) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12940

## 문제 요약
- 두 수 `n`, `m`이 주어질 때, 두 수의 **최대공약수(GCD)**와 **최소공배수(LCM)**를 배열로 반환한다.

## 아이디어
`math.gcd`, `math.lcm` 같은 표준 라이브러리 함수로도 바로 풀 수 있지만, 이번엔 원리를 직접 확인해보기 위해 **유클리드 호제법**으로 두 함수를 직접 구현했다.

### 최대공약수 — 유클리드 호제법
```python
def gcd(a, b):
    while b > 0:
        a, b = b, a % b
    return a
```
`a`를 `b`로 나눈 나머지를 구하고, `(a, b)`를 `(b, 나머지)`로 계속 갱신해 나가는 방식이다. 나머지가 0이 되는 순간의 `a`가 두 수의 최대공약수다. 매 반복마다 나머지가 이전 값보다 반드시 작아지기 때문에 빠르게 수렴하며, 시간복잡도는 O(log(min(a,b)))로 매우 효율적이다.

### 최소공배수 — 최대공약수를 이용한 공식
```python
def lcm(a, b):
    return a * b // gcd(a, b)
```
"두 수의 곱을 최대공약수로 나누면 최소공배수가 된다"(`lcm(a,b) = a*b / gcd(a,b)`)는 수학적 공식을 그대로 구현했다. `a*b`는 항상 `gcd(a,b)`로 나누어떨어지므로, 정수 나눗셈(`//`)을 써도 정확한 값이 나온다.

## 두 가지 방식 비교

| 구분 | 라이브러리 방식 (`math.gcd`, `math.lcm`) | 직접 구현 방식 |
|---|---|---|
| 원리 | 내부적으로 C로 구현된 유클리드 호제법 | 동일한 유클리드 호제법을 파이썬으로 직접 구현 |
| 속도 | 매우 빠름 (C 레벨 구현) | 원리는 동일하지만 파이썬 레벨이라 상대적으로 느릴 수 있음 (이 문제 규모에선 차이 없음) |
| 버전 제약 | `math.lcm`은 파이썬 3.9부터 지원 | 버전 제약 없이 어디서든 동작 |
| 학습 효과 | 원리를 몰라도 바로 사용 가능 | 유클리드 호제법의 동작 원리를 직접 확인 가능 |

두 방식 모두 정답이며 결과도 동일하다. 이번엔 라이브러리 방식을 주석 처리하고 직접 구현 방식으로 제출했다.

## 발생했던 문제
없음. 유클리드 호제법과 최소공배수 공식을 정확히 알고 있어서 바로 구현해 해결했다.

## 배운 점
- 유클리드 호제법은 "두 수의 최대공약수는, 큰 수를 작은 수로 나눈 나머지와 작은 수의 최대공약수와 같다"는 성질을 반복 적용하는 알고리즘이다. 재귀로도 구현 가능하지만, 반복문(`while`)로 구현하면 별도의 재귀 깊이 걱정 없이 간단하게 처리할 수 있다.
- 최소공배수를 직접 반복문이나 배수 나열로 찾으려 하면 비효율적일 수 있는데, `lcm(a,b) = a*b / gcd(a,b)` 공식을 알고 있으면 이미 구한 `gcd`를 그대로 재사용해 O(1)에 추가로 계산할 수 있다.
- 표준 라이브러리가 있더라도, 원리를 직접 구현해보는 과정이 유클리드 호제법 같은 기본 수학 알고리즘을 확실히 이해하는 데 도움이 된다.

## 최종 코드

```python
def gcd(a, b):
    while b > 0:
        a, b = b, a % b
    return a

def lcm(a, b):
    return a * b // gcd(a, b)

def solution(n, m):
    answer = [gcd(n, m), lcm(n, m)]
    return answer
```
