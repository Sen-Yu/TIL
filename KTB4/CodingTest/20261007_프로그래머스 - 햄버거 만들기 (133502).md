## 1. 1차 시도 (문자열 슬라이싱 방식) 및 시간 초과 원인
초기에는 배열을 문자열로 묶어(`join`) 슬라이싱으로 잘라내고 인덱스를 뒤로 돌리는 논리적인 백트래킹을 구상했다. 

```python
def solution(ingredient):
    answer = 0
    ingredient_str = ''.join(map(str,ingredient))
    hamburger = "1231"
    length = len(ingredient_str)
    l = 0
    while l <= length-4:
        if ingredient_str[l:l+4] == hamburger:
            answer+=1
            ingredient_str = ingredient_str[:l] + ingredient_str[l+4:]
            l -= 3
            length -= 4
        l+=1
    
    return answer
```

- **문제점:** 로직 자체는 훌륭했지만, 파이썬의 특성상 문자열 중간을 도려내고 앞뒤를 다시 더하는(`ingredient_str[:l] + ingredient_str[l+4:]`) 연산은 남은 문자열 전체를 복사해야 하므로 매번 $O(N)$의 시간이 걸린다. 
- 입력이 최대 100만 개이므로, 반복문 안에서 매번 문자열을 복사하면 최악의 경우 $O(N^2)$이 되어 **시간 초과(Time Limit Exceeded)**가 발생한다.

## 2. 최종 해결 코드 (스택 활용)
시간 초과를 해결하기 위해 **스택(Stack)** 자료구조를 꺼내 들어 완벽하게 최적화에 성공한 코드다.

```python
def solution(ingredient):
    answer = 0
    stack = list()
    
    for i in ingredient:
        stack.append(i)
        
        # 스택의 끝부분 4개가 햄버거 패턴(1-빵, 2-야채, 3-고기, 1-빵)이라면
        if stack[-4:] == [1,2,3,1]:
            answer+=1
            # 햄버거를 만들었으니 스택에서 4개를 뺀다
            for _ in range(4): stack.pop()
    
    return answer
```

## 3. 배운 점
- 중간 데이터를 도려내고 앞뒤를 이어 붙이는 연산을 할 때, 단순 슬라이싱을 쓰면 속도가 매우 느려진다.
- **"데이터가 순차적으로 들어오고, 특정 모양이 완성되면 펑 터트린다" (예: 크레인 인형뽑기 게임, 짝지어 제거하기, 올바른 괄호 등)** 류의 문제는 무조건 **스택(Stack)**이 1순위 정답이다!
- 배열에 순서대로 넣으면서(`append`) 리스트의 끝부분(`[-4:]`)만 검사하고, 패턴이 일치하면 맨 뒤에서만 제거(`pop`)하는 방식은 복사나 데이터 이동이 발생하지 않아 전체 시간 복잡도를 $O(N)$으로 극단적으로 낮춰준다.
