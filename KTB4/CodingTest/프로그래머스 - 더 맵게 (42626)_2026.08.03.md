# 프로그래머스 - 더 맵게 (42626) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42626

## 문제 요약
- 모든 음식의 스코빌 지수를 담은 배열 `scoville`과 목표 지수 `K`가 주어진다.
- 가장 맵지 않은 두 음식(최솟값 두 개)을 `min1 + min2 * 2` 공식으로 섞어 새로운 음식을 만드는 과정을 반복한다.
- 모든 음식의 스코빌 지수를 `K` 이상으로 만들 수 있는 **최소 섞기 횟수**를 구한다.
- 만들 수 없는 경우 `-1`을 반환한다.

## 아이디어
"모든 값을 특정 값 이상으로 만들되, 매번 최솟값을 갱신해야 한다"는 조건은 **최소 힙(min-heap)**으로 접근하기 좋은 전형적인 패턴이다.

- `scoville`을 최소 힙으로 만든다(`heapq.heapify`).
- 힙에서 최솟값(`min1`)을 하나 꺼낸다. 이 값이 이미 `K` 이상이면 더 섞을 필요가 없으므로 반복을 끝낸다.
- 아니라면 두 번째로 작은 값(`min2`)도 꺼내서 `now = min1 + min2 * 2`를 계산하고, 이 값을 다시 힙에 넣는다. 섞기 횟수(`turn`)를 늘리고, 다시 힙에서 최솟값을 꺼내 다음 반복을 준비한다.
- 이 과정을 반복하다가 힙이 완전히 비었는데도 마지막으로 꺼낸 값이 `K` 미만이면, 더 섞을 재료가 없는 채로 목표를 못 채운 것이므로 `-1`을 반환한다.

## 발생했던 문제
**"섞을 음식이 하나만 남았는데, 그 하나조차 `K` 미만인 경우"**를 처음엔 놓쳐서 틀렸다.

`while scoville and min1 < K:` 조건은 힙이 비면(`scoville`이 빈 리스트가 되면) 바로 거짓이 되어 루프를 빠져나온다. 문제는 루프를 빠져나오는 이유가 두 가지라는 점이다.
1. `min1 >= K`가 되어서 목표를 달성한 경우
2. `scoville`이 완전히 비어서(더 이상 섞을 재료가 없어서) 강제로 빠져나온 경우

이 둘을 구분하지 않으면, 2번처럼 재료가 바닥나서 빠져나온 상황에서도 그냥 지금까지의 `turn` 값을 반환해버려 오답이 발생한다.

## 해결 방법
루프가 끝난 직후, "힙이 비어 있는 상태에서 여전히 `min1`이 `K` 미만인지"를 별도로 확인하는 조건을 추가했다.

```python
if (len(scoville) == 0) and min1 < K:
    return -1
```

이 조건으로 루프를 빠져나온 두 가지 경우를 구분해서, 재료 부족으로 목표를 못 채운 경우에만 정확히 `-1`을 반환하도록 했다.

## 복잡도
- 힙의 pop/push는 각각 O(log n)
- 최악의 경우 모든 원소를 한 번씩 섞으므로 반복 횟수는 최대 n회
- 전체 시간복잡도: **O(n log n)**
- 공간복잡도: O(n) (힙 자체가 입력 크기만큼 차지)

## 배운 점
- `while` 루프의 종료 조건에 등장하는 변수(`min1`)가, 루프를 빠져나온 직후에도 항상 같은 의미를 갖는 건 아니다. "조건을 만족해서 끝났다"와 "자원이 바닥나서 강제로 끝났다"가 하나의 `while` 조건 안에 섞여 있을 때는, 루프 종료 후 후처리로 그 둘을 구분해줘야 한다.
- 이런 유형은 "루프를 빠져나온 이유가 두 가지 이상일 수 있는 경우"로 일반화해서 기억해두면, 비슷한 특수 케이스가 나올 때 미리 대비할 수 있을 것 같다.

## 최종 코드

```python
"""
모든값 특정값 이상으로 -> 최소값 갱신 -> 최소힙
"""
import heapq
def solution(scoville, K):
    answer = 0

    heapq.heapify(scoville)
    now = -1
    min1 = heapq.heappop(scoville)
    min2 = -1
    turn = 0

    while scoville and min1 < K:
        turn += 1
        min2 = heapq.heappop(scoville)
        now = min1 + (min2 * 2)

        heapq.heappush(scoville, now)
        min1 = heapq.heappop(scoville)

    if (len(scoville) == 0) and min1 < K:
        return -1

    return turn
```
