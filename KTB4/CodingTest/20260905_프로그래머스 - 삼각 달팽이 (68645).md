# 프로그래머스 - 삼각 달팽이 (68645) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/68645

## 문제 요약
- 정수 `n`이 주어질 때, `n`행짜리 삼각형을 달팽이 모양(아래로 내려가고, 오른쪽으로 가고, 대각선으로 왼쪽 위로 올라가는 순서를 반복)으로 `1`부터 채운다.
- 채워진 삼각형을 위에서부터 순서대로 1차원 배열로 반환한다.

## 아이디어
- 삼각형을 `triangle[y][x]` 형태의 2차원 리스트로 표현하되, `y`행은 `y+1`개의 칸만 갖도록(`[0]*i for i in range(1, n+1)`) 만들어 삼각형 모양을 유지한다.
- 이동 방향을 `dx = [0,1,-1,0]`, `dy = [1,0,-1,0]`로 정의한다. 이는 순서대로 "아래로 내려가기(`d=0`)", "오른쪽으로 이동(`d=1`)", "대각선으로 왼쪽 위로 이동(`d=2`)"을 의미하며, `d=3`은 실제로는 쓰이지 않는 여분의 방향이다.
- `1`부터 `length`(`n*(n+1)//2`)까지 순서대로 값을 채우면서, 매 칸마다 "현재 방향으로 계속 갈 수 있는지"를 확인하고, 막히면 다음 방향으로 전환한다.
- 이동 가능 여부는 세 가지 조건으로 확인한다.
  - `0 <= y+dy[d] < n`: 행 범위를 벗어나지 않는지
  - `0 <= x+dx[d] <= y+dy[d]`: 삼각형 모양(열 번호가 행 번호를 넘지 않음)을 벗어나지 않는지
  - `triangle[y+dy[d]][x+dx[d]] == 0`: 아직 채워지지 않은 칸인지
- 세 조건을 모두 만족하면 그 방향으로 이동하고, 아니면 `d = (d+1) % 4`로 다음 방향을 시도한다. 한 칸에서 방향 전환을 최대 4번(`turn < 4`)까지만 시도하도록 제한해서 무한 루프를 방지한다.
- 마지막으로 2차원 `triangle`을 리스트 컴프리헨션(`[item for row in triangle for item in row]`)으로 1차원 배열로 펼쳐서 반환한다.

## 발생했던 문제
없음. 방향 배열과 삼각형 경계 조건(`x <= y`)을 처음부터 정확히 설계해서 막힘없이 풀렸다.

## 복잡도
- 전체 칸 수는 `n(n+1)/2`개이고, 각 칸마다 방향을 확인하는 내부 `while`이 최대 4번만 반복되므로, 전체 시간복잡도는 **O(n²)**이다.
- 공간복잡도도 삼각형 전체를 저장하므로 O(n²)이다.

## 배운 점
- 정사각형이 아닌 삼각형처럼 각 행의 길이가 다른 격자를 다룰 때는, 이동 가능 여부를 확인하는 조건에 "그 모양만의 제약"(여기선 `x <= y`)을 별도로 추가해야 한다. 단순히 상하좌우 범위(`0 <= x < n`, `0 <= y < n`)만 확인하면 삼각형의 대각선 경계를 넘어갈 수 있다.
- 나선형(달팽이) 순회 문제는 "현재 방향으로 갈 수 있는 만큼 가고, 막히면 다음 방향으로 전환한다"는 동일한 패턴으로 처리할 수 있으며, 방향 배열(`dx`, `dy`)과 방향 전환 조건만 그 도형의 모양에 맞게 조정하면 된다.
- 방향 인덱스를 순환시킬 때 `d = (d+1) % 4`처럼 나머지 연산을 쓰면 `if d+1 > 3: d=0 else: d+1` 같은 조건문보다 더 간결하게 표현할 수 있다.

## 최종 코드

```python
def solution(n):
    answer = []

    triangle = [[0] * i for i in range(1, n + 1, 1)]
    length = n * (n + 1) // 2

    dx = [0, 1, -1, 0]
    dy = [1, 0, -1, 0]
    x, y = 0, 0
    d = 0
    for k in range(1, length + 1, 1):
        triangle[y][x] = k

        ## 진행방향 찾기
        turn = 0
        while k < length + 1 and turn < 4:
            if 0 <= y + dy[d] < n and 0 <= x + dx[d] <= y + dy[d] and triangle[y + dy[d]][x + dx[d]] == 0:
                x += dx[d]
                y += dy[d]
                break
            else:
                d = (d + 1) % 4
            turn += 1

    return [item for row in triangle for item in row]
```
