# 프로그래머스 - 공원 산책 (172928) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/172928

## 문제 요약
- 격자 형태의 공원(`park`)에서 로봇 강아지가 시작 지점 `S`에서 출발한다.
- 이동 명령(`routes`)이 `["방향 거리", ...]` 형태로 주어진다. 방향은 동/서/남/북(E/W/S/N)이다.
- 각 명령마다 그 방향으로 지정된 거리만큼 이동하되, 다음 두 경우 중 하나라도 해당하면 **그 명령 전체를 무시**한다.
  - 이동 도중 공원의 경계를 벗어나는 경우
  - 이동 경로 중간에 장애물(`X`)이 있는 경우
- 모든 명령 수행 후 강아지의 최종 위치를 `[행, 열]`로 반환한다.

## 아이디어
- 방향 문자(E/W/S/N)를 인덱스로 바꾸기 위해 `"EWSN"` 문자열에서 위치를 찾아 델타 배열(`dx`, `dy`)의 인덱스로 매핑하는 `direction_word2numer` 함수를 만들었다.
- 먼저 `park`를 순회하며 시작 지점 `S`의 좌표를 찾는다. 각 행 문자열에 `.find("S")`를 써서 열 위치를 얻는다.
- 각 명령마다 두 단계로 처리한다.
  1. **경계 확인**: 목적지(`시작 + 거리 × 방향`)가 공원 범위 안에 있는지 먼저 확인한다. 벗어나면 그 명령은 건너뛴다.
  2. **장애물 확인**: 한 칸씩 실제로 이동하면서, 도중에 `X`를 만나면 이번 명령에서 이동한 만큼(`count`)을 정확히 되돌려 원위치시키고 명령을 중단한다.

## 장애물을 만났을 때 정확히 되돌아가는 방법
```python
count = 1
while count <= distance:
    y += dy[dn]
    x += dx[dn]
    if park[y][x] == "X":
        y -= count*dy[dn]
        x -= count*dx[dn]
        break
    count += 1
```
`count`는 이번 명령에서 지금까지 실제로 전진한 칸 수를 추적한다. 장애물을 만나는 순간, 그 `count`만큼 방향 델타를 곱해서 빼주면 이번 명령을 시작하기 직전 위치로 정확히 복귀한다. 경계 확인은 이미 명령 시작 전에 목적지 기준으로 한 번에 처리했기 때문에, 이 반복문 안에서는 장애물만 신경 쓰면 된다.

## 발생했던 문제
없음. 경계 확인(명령 시작 전 목적지 검사)과 장애물 확인(한 칸씩 이동하며 검사)을 분리해서 설계한 덕분에, 공식 예제 3개를 모두 정확히 통과했다.

## 복잡도
- 시작점 탐색: O(행 × 열)
- 각 명령마다 최대 `거리`만큼 한 칸씩 이동하며 확인하므로, 명령 수를 `r`, 최대 이동 거리를 `d`라 하면 O(r × d)
- 이 문제의 격자와 명령 규모가 작아 전체적으로 매우 가볍게 동작한다.

## 배운 점
- 이동 명령을 처리할 때 "경계 이탈"과 "중간 장애물"이라는 두 가지 실패 조건을, 각각 다른 단계에서 확인하도록 분리하면 로직이 단순해진다. 경계는 목적지 하나만 미리 검사하면 되고, 장애물은 경로 전체를 훑어야 하므로 성격이 다르기 때문이다.
- 어떤 동작을 중간에 취소하고 원래대로 되돌려야 할 때는, "지금까지 진행한 양"을 별도 변수(`count`)로 정확히 추적해두면 그만큼을 그대로 역산해서 깔끔하게 복구할 수 있다.
- 방향 문자를 델타 배열 인덱스로 바꾸는 매핑(`"EWSN"`의 위치 = `dx`/`dy`의 인덱스)은, 방향 기반 이동 문제에서 자주 쓰이는 정형화된 처리 방식이다.

## 최종 코드

```python
"""
retrun [y,x]
"""
dx=[1,-1,0,0]
dy=[0,0,1,-1]

def direction_word2numer(word):
    direction_word = "EWSN"
    dn = -1
    for idx, dw in enumerate(direction_word):
        if dw == word:
            dn = idx
            break
    return dn

def solution(park, routes):
    y_lenthg = len(park)
    x_length = len(park[0])
    y, x = -1, -1
    ## find S
    for y_park, x_park in enumerate(park):
        xf = x_park.find("S")

        if xf > -1:
            y, x = y_park, xf
            break

    ## move
    for r in routes:
        direction, distance = r.split(" ")
        distance = int(distance)
        dn = direction_word2numer(direction)

        ## 범위 확인
        if 0 <= y+(distance*dy[dn]) < y_lenthg and 0 <= x+(distance*dx[dn]) < x_length:
            count = 1
            while count <= distance:
                y+=dy[dn]
                x+=dx[dn]
                if park[y][x] == "X":
                    y-=count*dy[dn]
                    x-=count*dx[dn]
                    break
                count+=1

    return [y,x]
```
