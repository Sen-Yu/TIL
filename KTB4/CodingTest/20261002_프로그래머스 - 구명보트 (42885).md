# 프로그래머스 - 구명보트 (42885) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42885

## 문제 요약
- 무인도에 갇힌 사람들을 구명보트를 이용하여 구출해야 한다.
- 구명보트는 한 번에 **최대 2명**씩 탈 수 있고, 무게 제한(`limit`)이 있다.
- 구명보트를 최대한 적게 사용하여 모든 사람을 구출하는 문제.

## 아이디어
- **투 포인터(Two Pointers)와 그리디(Greedy)** 알고리즘의 훌륭한 조합.
- 가장 가벼운 사람과 가장 무거운 사람을 짝지어 태우는 것이 구명보트를 최소화하는 핵심이다.
- 먼저 몸무게 배열 `people`을 오름차순으로 정렬한다.
- 왼쪽 포인터(`left`)는 가장 가벼운 사람을, 오른쪽 포인터(`right`)는 가장 무거운 사람을 가리킨다.
- `people[left] + people[right] <= limit` 라면 두 명이 같이 탈 수 있으므로 `left`를 증가시킨다.
- 같이 탈 수 있든 없든, 제일 무거운 사람(`right`)은 무조건 이번 보트를 타고 가야 하므로 `right`는 항상 감소시킨다.
- 배 한 대를 보냈으므로 `answer`를 1 증가시킨다.

## 배운 점
- 최적화 문제에서 양 극단의 값을 짝지어보는 '투 포인터' 패턴을 익히기 좋은 정석적인 문제다.
- '최대 2명'만 탈 수 있다는 조건이 있기 때문에 이와 같은 양끝 투 포인터 접근이 완벽하게 들어맞는다.
- 리스트에서 직접 `.pop()`이나 `.remove()`를 쓰면 원소들이 당겨지면서 시간 초과(O(N))가 발생하기 쉬운데, `left`, `right` 인덱스만 조작(O(1))하여 시간 효율성을 극대화한 아주 완벽한 코드다.

## 최종 코드
```python
def solution(people, limit):
    answer = 0
    people.sort()
    left, right = 0, len(people) - 1
    
    while left <= right:
        # 가벼운 사람과 무거운 사람이 같이 탈 수 있는 경우
        if people[left] + people[right] <= limit:
            left += 1
        
        # 무거운 사람은 무조건 탄다
        right -= 1    
        answer += 1    
    
    return answer
```
