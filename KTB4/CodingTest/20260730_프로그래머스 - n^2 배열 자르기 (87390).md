# 프로그래머스 - n^2 배열 자르기 (87390) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/87390

## 문제 요약
- n행 n열 배열이 있고, `array[i][j] = max(i, j) + 1` 규칙으로 채워져 있다.
- 이 배열을 1차원으로 쭉 이어붙였을 때(행 우선), `left`번째부터 `right`번째까지의 구간을 잘라서 반환해야 한다.
- n이 매우 크기 때문에 실제로 n×n 배열을 만들면 안 되고, 좌표를 직접 계산해야 한다.

## 아이디어 / 점화식
n×n 배열에서 `(x, y)` 좌표의 값은 "그 좌표가 속한 정사각형 테두리의 한 변 길이"로 결정된다.

- `a[0][0] = 1`
- `a[0][1] = a[1][0] = a[1][1] = 2`
- `a[0][2] = a[1][2] = a[2][0] = a[2][1] = a[2][2] = 3`

즉 `base = max(x, y)`일 때 `a[x][y] = base + 1`. 좌표만 알면 값은 바로 구해지는 구조다.

**핵심은 1차원 인덱스 `z`를 2차원 좌표 `(x, y)`로 되돌리는 것**이다. n×n 배열을 행 우선으로 폈을 때:

```
0 1 2
3 4 5
6 7 8
```

인덱스 `z`와 좌표의 관계는 `n*x + y = z` (0-indexed, n=3 예시). 여기서:
- `y = z % n`
- `x = (z - y) / n`

이 두 식만 있으면 `left`부터 `right`까지 각 인덱스 `z`에 대해 `(x, y)`를 구하고, `max(x, y) + 1`을 답 배열에 채우면 된다.

## 구현 방식
- `right - left + 1` 길이의 결과 배열을 미리 만든다.
- `idx`를 0부터 길이만큼 돌면서, 실제 배열 상의 위치 `z = idx + left`를 구한다.
- `z`로부터 위 점화식을 이용해 `y = z % n`, `x = (z - y) // n`을 계산한다.
- `answer[idx] = max(x, y) + 1`로 채운다.

전체 배열을 만들지 않고 필요한 구간만 O(right - left) 시간에 직접 계산하기 때문에, n이 커도 시간/공간 문제 없이 동작한다.

## 발생했던 문제
이번엔 알고리즘 자체보다 변수명 철자 문제만 있었고, 로직 설계와 점화식 유도는 처음부터 막힘없이 진행됐다.

## 배운 점
- 2차원 배열을 1차원으로 펼쳤을 때의 인덱스 변환(`z = n*x + y`)은 나눗셈과 나머지 연산(`x = z // n`, `y = z % n`)으로 자연스럽게 역산할 수 있다.
- 배열의 규칙성을 좌표만으로 수식화(`max(x, y) + 1`)할 수 있다면, 실제로 배열을 구성하지 않고도 필요한 구간만 계산해서 메모리와 시간을 모두 절약할 수 있다.
