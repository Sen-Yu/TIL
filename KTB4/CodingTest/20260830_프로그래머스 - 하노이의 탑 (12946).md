# 프로그래머스 - 하노이의 탑 (12946) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12946

## 문제 요약
- 크기가 서로 다른 원판 `n`개가 1번 기둥에 큰 것부터 작은 것 순으로 쌓여 있다.
- 한 번에 원판 하나만 옮길 수 있고, 큰 원판을 작은 원판 위에 올릴 수 없다.
- 모든 원판을 3번 기둥으로 옮기는 **이동 순서**(`[출발, 도착]` 쌍의 배열)를 반환한다.

## 처음 접근 — 짝수/홀수로 패턴을 나누려던 시도
초기 아이디어는 원판 개수(`n`)의 짝수/홀수 여부에 따라 이동 패턴이 다르다고 보고, 각각을 따로 규칙화하려 했다.
```
n 짝수: now->2번, now->3번, 2번->3번
n 홀수: now->3번, now->2번, 3번->2번
```
이 방향으로도 접근할 수는 있지만, 케이스를 나눠서 규칙을 일반화하려다 보니 복잡해지는 측면이 있었다.

## 점화식으로 재정리
직접 작은 경우(`n=1,2,3,4`)를 손으로 풀어보면서 점화식을 재정리했다.

- `n=1`: `[[1,3]]` — 원판 하나를 그냥 옮기면 끝 (기저 조건)
- `n=2`: `[[1,2]]`(작은 원판을 보조 기둥으로) + `[[1,3]]`(큰 원판 이동) + `[[2,3]]`(작은 원판을 마저 도착지로)
- `n=3`, `n=4`도 같은 방식으로, **"n-1개 이동" 한 번 + "가장 큰 원판 이동" 한 번 + "n-1개 이동" 한 번**의 3단계로 항상 쪼개진다는 규칙을 확인했다.
- 이동 횟수에 대한 점화식도 함께 정리했다: `T(n) = 2·T(n-1) + 1`, `T(1) = 1`. 이를 풀면 `T(n) = 2^n - 1`이 된다.

이 규칙을 확인한 뒤, 짝수/홀수로 나누는 방식 대신 **재귀 함수 하나로 통일**해서 구현했다.

## 최종 아이디어 (재귀 점화식)
```
move(start, end, tmp, N) = move(start, tmp, end, N-1)   # N-1개를 시작→보조로 옮김
                          + [[start, end]]                # 가장 큰 원판을 시작→도착으로 이동
                          + move(tmp, end, start, N-1)    # 옮겨둔 N-1개를 보조→도착으로 마저 이동
```
- 재귀 호출마다 인자 자리(`start`, `end`, `tmp`)가 서로 바뀌어 들어가는데, 이는 매 단계마다 "지금 누가 도착지 역할이고 누가 보조 기둥 역할인지"가 달라지기 때문이다.
- `N == 1`일 때는 더 쪼갤 필요 없이 `[[start, end]]` 하나만 반환하는 기저 조건이다.

## 발생했던 문제
없음. 처음엔 짝수/홀수로 패턴을 나누려 했지만, 작은 예시들을 직접 손으로 풀어보면서 스스로 하나의 재귀 점화식으로 정리해 바로 구현에 성공했다.

## 복잡도
- 전체 이동 횟수가 `2^n - 1`개이므로, 그 이동들을 전부 리스트에 담아 반환하는 이 풀이의 시간복잡도와 공간복잡도는 모두 **O(2^n)**이다.
- `n`이 커질수록 이동 횟수 자체가 기하급수적으로 늘어나므로, 문제의 `n` 제약 조건이 큰 경우에는 경로 전체 대신 이동 횟수만 구하는 방식으로 접근해야 할 수 있다.

## 배운 점
- 규칙을 조건 분기(짝수/홀수)로 나눠서 일반화하려다 막히면, 아주 작은 경우들을 손으로 직접 풀어보고 그 안에서 공통된 구조를 찾아내는 게 오히려 더 간단한 점화식으로 이어질 수 있다.
- "큰 문제를 두 개의 작은 동일 문제 + 한 번의 처리"로 쪼개는 구조(`T(n) = 2·T(n-1) + 1`)는 하노이의 탑의 전형적인 분할 정복 패턴이며, 재귀 호출 시 인자의 역할(시작/도착/보조)을 정확히 스왑해서 넘기는 것이 핵심이다.
- 이동 횟수에 대한 점화식(`T(n) = 2^n - 1`)과 실제 이동 경로를 생성하는 재귀 코드는 서로 다른 것을 계산하지만, 구조적으로 완전히 대응된다는 것을 확인했다.

## 최종 코드

```python
"""
이동할려는 곳 이동할려면
현재 빈기둥이 1개이상이다.
    n  짝수
        now->2번 now->3번
        2번->3번
    n 홀수
        now->3번 now->2번
        3번->2번
## 점화식 풀이
n=1
[ [1,3] ] 1개 이동
n=2
[ [1,2] ] 1개 이동(큰판과 같은 start -> 큰판과 다른 end)
[ [1,3], [2,3] ] 큰판 이동,1개 이동(큰판과 다른 start-> 큰판과 같은 end)
n=3
[ [1,3] ] 1개 이동
[ [1,2], [3,2] ] 큰판 이동,1개 이동
[ [1,3], [2,1], [2,3], [1,3] ] 큰판 이동,1개 이동, 큰판 이동,1개 이동
n=4
[ [1,2] ]
[ [1,3], [2,3] ]
[ [1,2], [3,1], [3,1], [3,2]]
[ [1,2], [1,3], [2,3], [2,1], [3,1], [2,3], [1,2], [1,3], [2,3]]
접시 1개 이동 = 1개이동
접시 2개 이동 = 접시1개 이동 1번, 큰판의 1번 이동, 접시 1개이동 1번
접시 3개 이동 = 접시2개 이동 1번, 큰판의 1번 이동, 접시 2개이동 1번 = 1개이동 4번 = 총 2^3 -1   번
...
접식 n개 이동 = n-1개이동 2번 -> 1개이동 2^(n-1)번  = 총 2^n - 1 번
start -> end
"""
from collections import deque
def solution(n):

    def move(start, end, tmp, N):

        if N == 1:
            return [[start, end]]

        return move(start, tmp, end, N-1) + [[start, end]] + move(tmp, end, start, N-1)

    return move(1, 3, 2, n)
```
