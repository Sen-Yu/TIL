# 프로그래머스 - N으로 표현 (42895) 재풀이 비교 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/42895

## 문제 요약
- 숫자 `N`과 목표 숫자 `number`가 주어진다.
- `N`과 사칙연산(`+`, `-`, `*`, `/`), 그리고 `N`을 이어 붙인 수(`NN`, `NNN`, …)만 사용해 `number`를 만든다.
- `N`을 사용한 횟수의 **최솟값**을 반환한다. 8회를 넘으면 `-1`을 반환한다.
- 나눗셈에서 나머지는 무시한다.

## 핵심 아이디어 (두 풀이 공통)
- `dp[k]` = "`N`을 정확히 `k`번 사용해서 만들 수 있는 모든 수의 집합". 같은 값이 여러 방식으로 나오므로 중복 제거를 위해 `set`을 쓴다.
- `dp[k]`는 `dp[i]`와 `dp[k-i]`(`1 <= i < k`)의 모든 조합에 사칙연산을 적용하고, `N`을 `k`번 이어 붙인 수(`NN…N`)를 추가해서 만든다.
- `k = 1`부터 8까지 차례로 채우다가 `number`가 처음 등장하는 `k`가 정답이다. 끝까지 없으면 `-1`.
- `N == number`이면 바로 `1`을 반환한다.

## 과거 풀이 (Java)

```java
import java.util.HashSet;
class Solution {
    int N;
    int number;
    HashSet<Integer>[] dp;
    public int solution(int N, int number) {
        int answer = -1;
        this.N = N;
        this.number = number;
        if(N == number){
            return 1;

        }else{
            this.dp = new HashSet[9];
            dp[1] = new HashSet<>();
            dp[1].add(N);

            for(int i = 2 ; i < 9 ; i++){
                calculate(i);
                if(dp[i].contains(number)){
                    answer = i;
                    break;
                }

            }
        }

        return answer;
    }
    public void calculate(int index){
        dp[index] = new HashSet<>();
        for(int i = 1 ; i < index; i++){
            int j = index-i;

            for(int a : dp[i]){
                for(int b : dp[j]){

                    dp[index].add(a+b);
                    dp[index].add(a*b);
                    if(a-b>0)
                        dp[index].add(a-b);
                    if(b > 0)
                        dp[index].add(a/b);

                }
            }
        }
        int duplicate = 1;
        for(int i = 1 ; i < index ;  i++){
            duplicate = (duplicate *10) +1;
        }
        dp[index].add(N*duplicate);
    }
}
```

당시 메모:
```
N+N, N-N, N/N, NN, NN
현재 회차 행렬 크기 = 이전 회차 행렬 크기4+1
중복되는 결과값이 있기에 -> SET 이용
dp[1] = N
dp[2] = dp[1] +,-,/, dp[1] or NN
dp[3] = dp[1] ○ dp[2], dp[2] ○ dp[1], NNN
dp[4] = dp[1] ○ dp[3], dp[2] ○ dp[2], dp[3] ○ dp[1], NNNN
```

## 오늘 풀이 (Python, 직접 풀이 후 수정본)

```python
"""
[0] = 0
[1] = n*1
[2] = [1] +-*/ n , n*10+n = n*11
[3] = [2] +-*/ n , n*100+n*10+n = n*111
[4] = [3] +-*/ n ,[2] +-*/ [2], n*100+n*10+n = n*1111
[k] = [k-1] +-*/ [1], [k-2] +-*/ [2], answer+=n*(10**k) for _ in range(k):
      [k-i] +-*/ [i] (i>0)

"""

def solution(N, number):
    if number == N: return 1
    answer = -1
    dp = list()
    dp.append(set())
    dp.append(set())
    dp[1].add(N)
    #print(dp[1])
    
    for k in range(2,9):
        dp.append(set())
        for i in range(0,k):
            for x in dp[k-i]:
                for y in dp[i]:
                    dp[k].add(x + y)
                    if x-y>0:
                        dp[k].add(x - y)
                    dp[k].add(x * y)
                    if y>0:
                        dp[k].add(x // y)
        a = 0
        for _ in range(k):
            a+=N*(10**_)
            #print(answer)
        dp[k].add(a)
        #print(dp[k])
        if number in dp[k]:
            answer = k
            break
    
    return answer
```

## 수정한 내용 (처음 제출 코드 → 수정본)

| 항목 | 처음 코드 | 수정본 |
|---|---|---|
| 뺄셈 | `x - y`를 그대로 저장 (0, 음수 포함) | `x - y > 0`일 때만 저장 |
| 나눗셈 | `int(x / y)` (실수 나눗셈 후 변환) | `x // y` (정수 나눗셈) |
| 덧셈, 곱셈 | `int(x + y)`, `int(x * y)` | `x + y`, `x * y` (불필요한 `int()` 제거) |
| 설계 메모 | `[k-1] ○ [1]`, `[k-2] ○ [2]` 일부만 적혀 있었음 | `[k-i] ○ [i] (i>0)`로 일반식 추가 |

## 비교

| 구분 | 과거 풀이 (Java) | 오늘 풀이 (Python 수정본) |
|---|---|---|
| 핵심 알고리즘 | 사용 횟수별 `Set` DP, 모든 분할 조합 | 동일 |
| 분할 순회 | `i = 1 ~ index-1`, `j = index-i` | `i = 0 ~ k-1`, `dp[k-i]` × `dp[i]` (`i=0`은 빈 집합이라 낭비되는 반복) |
| 뺄셈 처리 | `a-b > 0`인 경우만 저장 | `x-y > 0`인 경우만 저장 (동일) |
| 나눗셈 처리 | `b > 0`일 때 정수 나눗셈 `a/b` | `y > 0`일 때 정수 나눗셈 `x // y` (동일) |
| `NN…N` 생성 | `duplicate = duplicate*10 + 1`을 반복해 `11…1`을 만든 뒤 `N`을 곱함 | `N*(10**_)`를 `k`번 누적해서 더함 |
| 구조 | 클래스 필드(`N`, `number`, `dp`) + 보조 메서드 `calculate` | 함수 하나에 모두 작성 |
| 조기 종료 | `dp[i].contains(number)`이면 `break` | `number in dp[k]`이면 `break` |
| 집합 크기 | 양수만 저장 | 양수만 저장 (동일 수준) |

수정 후에는 두 풀이의 연산 규칙이 사실상 같아졌고, 남은 차이는 구조(클래스 vs 함수)와 `N…N` 생성 방식, 순회 범위 정도다.

## 남은 개선점
- `range(0, k)`는 `dp[0]`이 빈 집합이라 `i = 0` 반복이 아무 일도 하지 않는다. `range(1, k)`로 쓰면 의도가 분명하다.
- 반복 변수 `_`를 실제로 값을 쓰는 곳에서 쓰고 있다. `_`는 "값을 안 쓴다"는 관례이므로 `for d in range(k)`처럼 이름을 주는 게 좋다.
- `dp[0]`은 자리만 차지하는 빈 집합이다. 인덱스를 `k`와 맞추려는 의도로는 괜찮지만 순회에서는 빼는 게 낫다.
- 주석 처리된 `print` 디버깅 줄(`#print(dp[1])`, `#print(answer)`, `#print(dp[k])`)은 제출 전에 지우면 깔끔하다. `#print(answer)`는 변수명도 실제 의도(`a`)와 다르다.

## 배운 점
- 과거에 자바로 풀었던 문제를 시간이 지나 파이썬으로 처음부터 다시 풀어도 같은 구조(사용 횟수별 집합 DP)에 도달했다. 이 문제의 핵심은 "`N`을 정확히 `k`번 쓴 결과 집합 = 작은 두 집합의 모든 조합 + 이어 붙인 수"로 굳어졌다.
- 이 DP는 `N`을 `k`번 쓴 결과를 `k`보다 작은 두 결과로 쪼갤 수 있다는 점(부분 문제 분해)과, 같은 값을 `Set`으로 합쳐 중복 계산을 줄인다는 점이 포인트다.
- 같은 알고리즘이라도 "불필요한 값(0, 음수)을 걸러내는 한 줄"의 차이가 집합 크기와 연산량을 좌우한다. 자바 풀이의 `if(a-b>0)`처럼 정답에 영향을 주지 않는 값은 미리 버리는 습관이 도움이 된다.
- 정수끼리의 나눗셈은 `int(x / y)`처럼 실수를 거치지 말고 `//`를 쓰는 편이 정확하고 의도도 분명하다. 음수가 없도록 미리 걸러두면 `//`의 버림 방향 문제도 생기지 않는다.
- 설계 메모(주석)와 실제 코드가 어긋나지 않도록, 코드를 완성한 뒤 메모를 다시 맞춰 두면 나중에 복습할 때 헷갈리지 않는다.
