# 프로그래머스 - 숫자 변환하기 (154538) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/154538

## 문제 요약
- 시작 숫자 `x`를 목표 숫자 `y`로 만들어야 한다.
- 한 번의 연산으로 `x`에 `n`을 더하거나, `2`를 곱하거나, `3`을 곱할 수 있다.
- `x`를 `y`로 만들기 위한 **최소 연산 횟수**를 구한다. 만들 수 없으면 `-1`을 반환한다.

## 아이디어
- 매 턴마다 가능한 모든 값으로 동시에 뻗어나가는 **BFS**로 접근한다. BFS는 먼저 도달한 경로가 항상 최단 경로라는 성질(FIFO 큐 특성)을 가지므로, "최소 연산 횟수"를 구하는 문제에 적합하다.
- 큐에서 값을 하나씩 꺼내 `dp+n`, `dp*2`, `dp*3` 세 가지 다음 값을 계산하고, 그 값이 `y`와 같으면 현재 턴(`answer`)을 반환한다.
- 값이 `y`를 넘어서면 더 이상 줄어들 방법이 없는 연산(전부 증가 방향)이므로 그 값은 버린다.

## 발생했던 문제 — 중복 방문으로 인한 시간초과
초기 코드는 "이미 방문한 값을 다시 방문하지 않도록 막는 장치"가 없었다. 매 턴마다 값 하나당 3개씩 자식을 새로 만들다 보니, 서로 다른 연산 경로로 **같은 값에 여러 번 도달**하는 경우가 걸러지지 않고 큐에 계속 중복으로 쌓였다. 그 결과 큐의 크기가 턴이 깊어질수록 최대 `3^턴`에 가깝게 기하급수적으로 불어나, 실제로 검토해야 할 서로 다른 값의 개수(`y` 이하로 한정됨)보다 훨씬 많은 연산을 하게 되어 시간초과가 발생했다.

## 해결 방법
값을 큐에 넣을 때마다 `set`(`recoreds`)에도 함께 기록해서, **이미 방문한(또는 큐에 넣은 적 있는) 값은 다시 큐에 넣지 않도록** 했다.

```python
if dp+n <= y and dp+n not in recoreds:
    dps.append(dp+n)
    recoreds.add(dp+n)
```

또한 `dp+n <= y`처럼 각 연산의 결과가 `y`를 넘는지 개별적으로 확인해서, 넘는 값은 애초에 큐에 넣지 않는 가지치기도 함께 적용했다.

이렇게 하면 한 번 방문한 값이 다시는 큐에 들어가지 않으므로, 전체적으로 큐를 거쳐가는 값의 개수가 최대 `y`(도달 가능한 값의 범위)로 제한된다.

## 복잡도
- 방문 가능한 서로 다른 값의 개수는 최대 `y`개로 제한되고, 각 값마다 3가지 연산을 O(1)에 처리하며 `set` 조회/삽입도 평균 O(1)이다.
- 전체 시간복잡도: **O(y)**
- 공간복잡도: O(y) (`recoreds` set과 `dps` 큐가 최대 `y`개의 값을 담을 수 있음)

## 배운 점
- BFS로 "최소 횟수"를 구하는 문제에서는, 가지치기(여기선 `dp <= y` 조건) 못지않게 **중복 상태 재방문을 막는 `visited` 처리**가 시간복잡도를 좌우하는 핵심이다. 이게 빠지면 트리 형태로 경우의 수가 기하급수적으로 불어나는 구조가 되어버린다.
- "같은 값에 여러 경로로 도달할 수 있는 문제"에서는, 값 자체를 상태로 보고 `set`으로 방문 여부를 관리하는 패턴이 트리형 완전 탐색을 그래프형 BFS로 바꿔주는 핵심 장치다. 이전에 봤던 그래프 최단거리(BFS) 문제들과 같은 원리다.
- 값이 목표를 넘어서는 순간 더 이상 유효하지 않은 연산(이 문제처럼 모든 연산이 증가 방향인 경우)은, 굳이 큐에 넣지 않고 그 자리에서 걸러내는 것도 불필요한 탐색을 줄이는 데 도움이 된다.

## 최종 코드

```python
"""
bfs + dp
x+n , x*2, x*3
각 연산 후 결과가 dp == y return 현재턴
dp > y 이면 dp에 저장 X
dp < y 이면 dp에 저장 O
"""
from collections import deque
def solution(x, y, n):
    answer = 0
    dps = deque()
    dps.append(x)
    recoreds = set()
    recoreds.add(x)

    while dps:
        length = len(dps)

        for k in range(length):
            dp = dps.popleft()
            if dp == y:
                return answer

            elif dp < y:
                if dp + n <= y and dp + n not in recoreds:
                    dps.append(dp + n)
                    recoreds.add(dp + n)
                if dp * 2 <= y and dp * 2 not in recoreds:
                    dps.append(dp * 2)
                    recoreds.add(dp * 2)
                if dp * 3 <= y and dp * 3 not in recoreds:
                    dps.append(dp * 3)
                    recoreds.add(dp * 3)

        answer += 1

    return -1
```
