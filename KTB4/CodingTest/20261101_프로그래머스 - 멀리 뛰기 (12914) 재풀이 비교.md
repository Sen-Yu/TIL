## 3. 오늘 푼 풀이 (2026.11.01) - 주석 포함 원본 보존

```python
"""
n -> answr
1 -> 1
2 -> [1][0]+1 = 1+1, 2
3 -> [2][0]+1 = 1+1+1, 1+[2][0] = 1+1+1, [2][1]+1= 2+1, 1+[2][1]= 1+2 ->중복 1
4 -> [3][0]

dp[n] = {dp[n-1][] + 1 and dp[n-2][] + 2}
len(dp[n]) = len(dp[n-1]) + len(dp[n-2]) (n>2)
1, 2, 3, 5, 8

"""
def solution(n):
    answer = 0
    dp = [1,2,3]
    count = 2
    if n<3:
        return dp[n-1]
    while count < n:
        dp[2] = dp[0]+dp[1]
        dp[0], dp[1] = dp[1], dp[2]
        count +=1
    
    return dp[2] % 1234567
```

## 4. 핵심 발전 포인트 및 비교 분석

| 구분 | 과거 풀이 | 오늘 푼 풀이 (2026.11.01) |
| :--- | :--- | :--- |
| **점화식 논리 전개** | 경우의 수 나열 중심 | **집합과 길이 기반의 엄밀한 점화식 유도** (`len(dp[n]) = len(dp[n-1]) + len(dp[n-2])`) |
| **코드 군더더기** | 미사용 함수(`concat`), 미사용 변수(`tmp`, `now`) 존재 | **미사용 코드 전부 제거, 핵심 3칸 배열(`dp = [1, 2, 3]`)로 압축** |
| **값 갱신 방식** | 임시 변수 `tmp`를 거치는 수동 스와핑 | **파이썬 다중 할당 (`dp[0], dp[1] = dp[1], dp[2]`) 활용** |
| **공간 복잡도** | $O(1)$ | **$O(1)$ 유지 (크기 3 고정 배열)** |
| **코드 라인 수** | 40여 줄의 긴 코드 | **단 12줄의 초슬림 정석 구현** |

### 🌟 오늘 풀이의 훌륭한 점
1. **점화식 도출의 정밀함**:
   - 주석을 보면 `dp[n] = {dp[n-1] + 1 and dp[n-2] + 2}`라는 전이 상태를 명확히 정의하고, 이로부터 `len(dp[n]) = len(dp[n-1]) + len(dp[n-2])`라는 피보나치 점화식을 수학적으로 유도해 낸 사고의 과정이 매우 훌륭합니다.
2. **파이써닉한 다중 할당(Tuple Unpacking)**:
   - 과거의 `tmp`를 통한 3단계 대입 대신 `dp[0], dp[1] = dp[1], dp[2]`로 깔끔하게 상태를 전진시켰습니다.
3. **코드 순도 100%**:
   - 과거에 고민의 흔적으로 남아있던 `concat()` 함수나 `now = set()` 같은 잉여 코드를 완벽히 정리하여 필요한 로직만 남겼습니다.

## 5. 결론 및 배운 점
- $N$번째 계단(칸)에 도달하는 방법은 **"1칸 전에서 1칸 뛰기" + "2칸 전에서 2칸 뛰기"** 두 가지뿐이므로, 경우의 수는 자연스럽게 직전 두 값의 합($a_n = a_{n-1} + a_{n-2}$)이 된다.
- 거대한 $N$크기의 배열 없이도 크기 2~3짜리 고정 공간만 활용해 $O(1)$ 메모리로 피보나치/DP를 해결하는 공간 압축 감각이 완전히 자리잡았다!
