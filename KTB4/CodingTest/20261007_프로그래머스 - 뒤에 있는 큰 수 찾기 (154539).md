# 프로그래머스 - 뒤에 있는 큰 수 찾기 (154539) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/154539

## 1. 문제 요약
- 정수 배열 `numbers`가 주어질 때, 각 원소들에 대해 "자신보다 뒤에 있으면서 가장 먼저 만나는 자신보다 큰 수(오큰수)"를 찾는 문제.
- 만약 뒤에 자신보다 큰 수가 없다면 `-1`을 담는다.
- 배열의 길이가 최대 1,000,000이므로, 이중 반복문($O(N^2)$)으로 찾으려고 하면 무조건 **시간 초과**가 발생하는 전형적인 함정 문제다.

## 2. 아이디어 및 최적화 로직
- "자신보다 큰 수가 나타날 때까지 기다린다"라는 관점으로 접근하여 **스택(Stack)**을 활용한 아주 완벽한 $O(N)$ 풀이다. 
- 이 기법을 알고리즘에서는 **단조 스택(Monotonic Stack)** 기법이라고 부른다.
- **핵심 로직:**
  1. `answer` 배열을 모두 `-1`로 초기화해둔다. (자신보다 큰 수를 못 찾은 녀석들의 기본값)
  2. 배열을 순회하면서, 아직 자신보다 큰 수를 찾지 못한 원소들의 **인덱스(`idx`)**를 스택에 차곡차곡 쌓아둔다.
  3. 새로운 숫자 `n`이 나타날 때마다, 스택의 맨 위(가장 최근에 쌓인 원소)부터 검사한다.
  4. 만약 스택에 대기 중인 원소(`numbers[stack[-1]]`)보다 현재 숫자 `n`이 더 크다면? **드디어 오큰수를 찾은 것이다!**
  5. 스택에서 뽑아낸(`pop`) 뒤, 해당 인덱스의 정답을 `n`으로 갱신(`answer[stack.pop()] = n`)한다. 이를 조건을 만족할 때까지 `while`문으로 반복한다.

## 3. 배운 점
- 오늘 낮에 "햄버거 만들기" 문제에서 **스택(Stack)의 위력**을 체감하신 뒤, 곧바로 이 문제에서 가장 완벽한 형태로 스택을 응용해 내셨다!
- 단순히 값을 스택에 넣는 것이 아니라, 나중에 정답 배열의 정확한 위치를 업데이트하기 위해 **인덱스(`idx`)를 스택에 넣는다**는 아이디어가 매우 훌륭하다.
- 이중 반복문 없이 `while`문과 `pop`을 결합해 배열을 단 한 번만 순회($O(N)$)하도록 만든 군더더기 없는 정석 코드다.

## 4. 최종 코드
```python
def solution(numbers):
    # 정답 배열을 모두 -1로 초기화
    answer = [-1] * len(numbers)
    stack = list()
    
    for idx, n in enumerate(numbers):
        # 스택에 대기 중인 숫자들 중 현재 숫자(n)보다 작은 녀석들은 모두 구제(pop)해줌
        while stack and numbers[stack[-1]] < n:
            answer[stack.pop()] = n
            
        # 아직 오큰수를 찾지 못한 현재 숫자의 인덱스를 대기열(스택)에 추가
        stack.append(idx)

    return answer
```
