# 프로그래머스 - 할인 행사 (131127) 풀이 정리

문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/131127

## 문제 요약
- `want`, `number`로 구성된 구매 희망 목록과, `discount`라는 연속된 일별 할인 품목 리스트가 주어진다.
- `discount` 안에서 **연속된 10일** 구간을 슬라이딩하며, 그 구간 안의 품목 개수가 `want`의 요구 수량을 모두 만족하는 경우의 수를 센다.

## 접근 방식
- 슬라이딩 윈도우로 10일짜리 구간을 하나씩 이동시키면서, 구간에 새로 들어오는 품목은 카운트를 늘리고 구간에서 빠지는 품목은 카운트를 줄인다.
- 매 반복마다 "지금 구간이 조건을 만족하는가"를 처음부터 다시 계산하지 않기 위해, `dict_flag`(품목별 조건 만족 여부)와 `True_count`(조건을 만족하는 품목 수)를 별도로 유지했다.
- `True_count == len(want)`이면 그 구간은 유효한 구매 가능 구간이므로 `answer += 1`.

## 발생했던 문제

### 1차 시도: "시간초과"로 오인
처음에는 `dict_flag.values()` 안에 `False`가 있는지를 매 반복마다 `in`으로 검사했다. 이 방식은 매번 `want`의 길이만큼 순회하는 연산이라, 전체 복잡도가 O(n)이 아니라 **O(n × k)** (k = want 길이)가 되어 있었다. discount 길이가 크면 이 부분이 병목이 될 수 있는 구조였다.

**해결**: `True_count`라는 카운터를 따로 두고, 품목의 조건 만족 여부가 `False → True`로 바뀔 때 `+1`, `True → False`로 바뀔 때 `-1`만 해주는 방식으로 바꿔서 매 반복의 판정을 O(1)로 줄였다.

### 2차 시도: 여전히 시간초과 발생
`True_count` 최적화를 적용했음에도 문제가 해결되지 않았다. 원인을 다시 살펴보니 실제로는 시간초과가 아니라 **오타로 인한 런타임 에러**였다.

- 변수명 `discount`를 `dicount`로 잘못 입력
- 변수명 `expired`를 `expried`로 잘못 입력 (철자 순서 오류)

이 두 오타 때문에 정의되지 않은 변수를 참조하게 되어, 윈도우가 10일(또는 당시 설정이던 15일)을 넘어가는 순간 예외가 발생했다. 채점 시스템에서 이 예외가 시간초과처럼 보였을 가능성이 크다.

### 부가 문제: 잘못된 윈도우 크기
윈도우 진입/만료 조건을 `idx >= 14`로 설정하고 있었는데, 이는 15일짜리 구간을 의미한다. 문제 조건은 **연속된 10일**이므로 `idx >= 10`, 그리고 만료되는 인덱스도 `idx - 10`으로 계산해야 했다.

## 최종 해결
아래 두 가지를 수정하여 문제를 해결했다.
1. 오타 수정: `dicount` → `discount`, `expried` → `expired`
2. 윈도우 크기 수정: `14` → `10` (진입 조건과 만료 인덱스 계산 모두)

## 배운 점
- "시간초과"라는 채점 결과가 항상 알고리즘 복잡도 문제를 의미하는 것은 아니다. 오타로 인한 예외가 특정 조건(예: 반복문 후반부)에서만 발생하면, 실제로는 런타임 에러인데 시간초과로 보일 수 있다.
- 상태 전체를 매번 다시 스캔하는 대신, **상태가 바뀌는 시점에만 카운터를 갱신**하는 패턴은 보석 문제(슬라이딩 윈도우)에서 익힌 것과 동일한 원리이며, 이번 문제에도 그대로 적용되었다.
- 슬라이딩 윈도우 문제에서는 "윈도우 크기가 몇 일/개인지"를 조건식(`idx >= N`, `idx - N`)에 정확히 반영하는 것이 매우 중요하다.

## 최종 코드
~~~

def solution(want, number, discount):
    answer = 0

    dict_discount = dict()
    dict_want = dict(zip(want, number))
    #print(dict_want)
    
    for idx in range(len(discount)):
        if discount[idx] in dict_discount:
            dict_discount[discount[idx]] += 1
        else:
            dict_discount[discount[idx]] = 1
    #print(dict_discount)
    def check_dict(new_dict):
        ## 세일품목에 있는지와 세일 품목수가 구매수량보다 적은지 판단
        for idx, product in enumerate(dict_want):
            if product in new_dict:
                if dict_want[product] > new_dict[product]:
                    #print("수량부족")
                    return False
            else:
                #print("물품없음")
                return False
        return True
      
        
    dict_14days = dict()
    dict_flag = dict(zip(want,[False]*len(want)))
    True_count = 0
    for idx, prod in enumerate(discount):
        ## 구매 불가능 물품 갱신
        if idx >= 10:
            expired = discount[idx-10]
            dict_14days[expired] -= 1
            ## 갱신하면서 구매요구 수량 축족여부판다
            if expired in dict_want.keys() and dict_flag[expired] and dict_want[expired] > dict_14days[expired]:
                dict_flag[expired] = False
                True_count -= 1
        ## 구매 가능 물품 갱신
        #print(prod)
        
        if prod in dict_14days:
            dict_14days[prod] += 1
        else:
            dict_14days[prod] = 1
        
        if prod in dict_want.keys() and not dict_flag[prod] and dict_want[prod] <= dict_14days[prod]:
            dict_flag[prod] = True
            True_count += 1
        
        if True_count == len(want):
            answer+=1
    
        
    return answer
~~~
