# 나의 코테 공부 규칙
## 첫 테스트
- 인터넷 검색없이 실제 코딩테스트 환경처럼 진행
## 첫 테스트 이후
- 기억 안나거나 헷갈리는 라이브러리 서치 및 암기
## 테스트 결과
### 일부 문제 틀림
- 알고리즘 재체크, 반례 생각하기
- 생각 시간 10분 넘어가면 질문하기 또는 인터넷 검색
### 시간 초과 문제
- 즉시 질문하기 또는 인터넷 검색
- 알고리즘은 맞으나 일부 개선이 필요한 경우 AI 도움 받기
## AI 사용
- 2단계는 첫테스트 이후 1시간 초과, 3단계는 1시간 20분 초과하면 내코드 주고 물어보기

## 문제 정리 파일
- AI에게 내 풀이과정을 이야기하고 만듬
