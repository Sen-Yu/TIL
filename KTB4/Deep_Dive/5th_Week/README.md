### 정규화(Normalization)
- AI 모델에서 **과적합**을 줄이기 위한 **스케일링 기법**
- 예측의 정확도를 떨어트림 성능 최적화는 아니다.
- 스케일링
  - min-max 정규화 : 모든 데이터를 0 ~ 1 사이로 변환    

$$
X_{norm} = \\frac{X-X_{min}}{X_{mamx}-X_{min}}
$$

### 배치(Batch)
- 한번에 모델이 학습하는 데이터 샘플의 수 묶음
- batch size: 1 batch에 속한 샘플 데이터 수
예) 총 데이터 1000개 batch size = 100 이면 batch = 10
  모델은 100개의 데이터 샘플 처리후에 가중치,편향 업데이트 진행  
- 문제점
  - Internal Covariant Shift : 학습과정에서 계층 별로 입력 데이터 분포가 달라지는 현상
    
    | 층(Layer)  |    입력층    |                     히든층                                 |     출력층    | 
    |-----------|-------------|----------------------------------------------------------|--------------|
    |           | 입력 데이터 분포| 1st Layer Feature 분포 ->  ...  ->  Nth Layer Feature 분포 | 출력 데이터 분포 |

     
    -1차 문제점: 히든층을 지날때 마다 **Feature 분포 변화율**은 **누적 증가**
      - 1차 해결책: 적절한 가중치(weight)의 초기화, 작은 학습률(learning rate) 세팅
        - 해결책의 문제점: 가중치 초기화는 어려운 방법이며, 학습률이 작으면 지역 극솟값(local minimum)에 빠짐
    - 2차 문제점: 하지만 배치 단위별로 데이터 분포에 차이가 발생
      - 2차 해결책: 배치 정규화

### 배치 정규화(Batch Normalization)
- 학습 과정에서 각층의 입력데이터 불균형을 평균과 분산을 동일하게 설정하는 기법
- 활성화 함수 전에 설정
- Forward

$$
BN(X) = \gamma(\\frac{X-\mu_{batch}}{\sigma_{batch}}) + \beta 
$$
$$
\mu_{batch} = \\frac{1}{B} \\sum_{i=1} x_i
$$
$$
\sigma_{batch} = \\sqrt{\\frac{1}{B} \\sum_{i=1} (x_i-\mu_{batch})^2}
$$


- 기호 설명
  - $B$: 배치 크기, $x$: 입력 데이터, $\mu_{batch}$: 배치 평균, $\sigma_{batch}$: 배치 분산
  - $\gamma$, $\beta$: BN(X)의 음수 결과값이 활성화 함수(Relu)에서 모두 0이 되지않게 방지하는 변수(학습되는 변수)
- Backforward

- 문제점
  - 배치 크기에 영향을 받음
