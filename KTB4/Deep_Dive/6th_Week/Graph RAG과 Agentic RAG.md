
# 주제2
- **벡터 DB에 기반한 RAG을 보완하는 Graph RAG과 Agentic RAG에 대해 조사하여 설명하고 가능하면 간단한 적용 코드 예제를 작성하시오.**


## 본문
### Vector RAG
- 한계점
  - 질문당 엔티티 수가 5개를 넘어가면 벡터 RAG의 정확도가 0에 가깝게 감소한다. 즉 "A와 B의 관계는?", "X를 거쳐 Y에 영향을 준 사건은?" 같은 관계 중심 질문에서 벡터 검색은 성능이 낮다.

### Graph RAG
- 검색 대상: 텍스트 청크 대신, 지식 그래프(엔티티와 관계)
  - 지식 그래프: 엔티티들의 관계를 선(엣지)으로 표현한 구조
  - 엔티티(노드): 개념
- 데이터셋을 여러 커뮤니티로 분할
- 흐름
  - 사용자의 질문 입력
    -> 질문과 관련된 엔티티를 식별
    -> 관련 엔티티를 시작점으로 삼아 지식 그래프를 순회하며 정보를 수집
